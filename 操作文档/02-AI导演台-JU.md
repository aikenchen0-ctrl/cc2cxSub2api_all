# AI 导演台（JU）测试操作手册

## 1. 基线、范围与测试口径

- 编写基线：2026-10-08 当前工作区源码；工作区包含近期未提交修改。
- 本文用于操作和验收用例，不代表所有用例已经执行，也不代表当前 Docker 镜像等同于源码。
- 不在本文中执行真实收费生成；需要上游调用时只用专用测试账号、短提示词和可追踪任务。
- JU 同时包含创作页、短剧项目、章节/分镜、项目画布、任务中心、素材库和 3D 导演台。
- P0 是登录/隔离/保存/费用归属，P1 是故事到镜头产物主流程，P2 是辅助格式和视图。
- 期望来自公共接入协议；源码存在入口不等于本地镜像已经发布或上游可用。

## 2. 入口与当前界面

| 项目 | 地址/路径与观察点 |
| --- | --- |
| 主站 | `http://localhost:18080`，登录后从菜单进入“AI 导演台” |
| JU 本地入口 | `http://localhost:3000`；受保护路由由 JU Session 控制 |
| 创作页 | `/create`：文本/图片/视频生成、对话、上传资产、转入画布 |
| 项目中心 | `/projects`：创建空白项目、导入小说/文本、AI 生成章节、筛选和删除 |
| 项目详情 | `/projects/{id}/overview`：制作概览、剧情章节、分镜制作、项目画布、剪辑成片、角色与资产、项目设置 |
| 画布中心 | `/canvas`：自由画布和项目画布，支持搜索、筛选、排序、导出、加入项目 |
| 导演台 | 从画布节点打开工作台；顶部模式“摆场/姿态/动画/摄影机” |
| 任务中心 | `/tasks`：查看排队、运行、成功、失败和任务恢复 |

## 3. 模型和版本差异

公开模型目录约定：文本 `gpt-5.6-sol`，图片 `gpt-image-2`，视频默认 AutoDL `minimax_h3_z0901`。
但当前工作区 `ju/web/src/stores/use-config-store.ts` 的前端 `DEFAULT_TEXT_MODEL` 已改为 `gpt-6-astra`，而 `ju/backend/internal/app/sub2api_integration.go` 的后端无环境变量回退仍为 `gpt-5.6-sol`。
因此测试必须记录三项：模型选择器显示值、网络请求的公开模型名、服务端实际渠道；不能把文档默认值当作通过证据。

视频目录首项是 `minimax_h3_z0901`（H3 文生视频，高质量创意直出），并开放 16 个 AutoDL 工作流。中文显示名是展示值，调用和保存必须保留英文 ID。
不同工作流的提示词、图片、音频、首尾帧、时长和分辨率约束不同；从当前工作流能力面板确认，不用统一模板代替。

## 4. 测试数据和身份准备

准备主站普通账号 A、B，各自独立浏览器配置文件；另准备同一浏览器 A→B→A 切换路径。
账号 A 使用小额测试余额，B 用于隔离；另备零余额账号或禁用渠道夹具，不操作真实充值。

准备以下材料：

- `story-qa.txt`：两段含人物、场景、动作和对白的短剧文本；另准备一篇 3 章短小说。
- `character.png`、`location.png`：无隐私角色和场景参考图；`product.glb`：小于限制的 GLB 模型。
- `first.png`、`last.png`：同一主体首尾画面；`voice-5s.wav`：测试音频。
- `bad.glb`（文本伪装 GLB）、超大图片和空文本，用于负向用例。

所有项目名前缀使用 `QA-JU-A-日期` 或 `QA-JU-B-日期`。执行记录只保留匿名账号编号，不记录 Cookie、票据或密钥。

## 5. 主流程：从故事到镜头视频

该流程分阶段执行。每一步先确认上一步已保存，再继续，避免把失败结果误当成下一阶段输入。

1. A 从主站菜单进入 JU，打开“项目”并点击创建项目。
   - 填 `QA-JU-A-短剧01`，选择 9:16，内容来源“空白开始”，可选一个项目画风后创建。
   - 预期：进入项目概览；项目卡显示 0 章节、0 画布、0 资产或实际初始化值。
2. 在“剧情章节”点击添加章节，填标题 `雨夜归城` 和 `story-qa.txt` 第一段，点击创建/保存。
   - 预期：章节状态、字数、更新时间刷新；离开章节前显示已保存。
3. 再添加第二章，或在项目中心用“导入小说”导入 3 章文本。
   - 预期：章节顺序可见，搜索标题/序号可用；已有章节不被导入覆盖，除非明确确认替换。
4. 选择一章，点击“提取角色、场景与道具”，选择当前可用文本模型并开始。
   - 预期：任务进入队列/运行；完成后资产候选可见；失败时保留可重试的错误状态。
5. 章节无未保存修改时，点击“生成到分镜制作”，选择模型和至多 4 个 Skill（可不选）。
   - 预期：生成任务开始；成功后分镜数量和镜头列表出现；若已有分镜，先生成新结果，确认后整体替换旧镜头。
6. 进入“分镜制作”，选择一个镜头。填写画面、提示词、排除内容、接戏备注，选择景别、机位角度、运镜方式、比例、时长和分辨率。
   - 预期：表单值与镜头预览一致；点击“保存脚本”后保存状态为成功，失败时按钮可重试并保留草稿。
7. 在右侧“产物预览”先选择“分镜图”，点击“生成分镜图”。
   - 预期：任务按镜头 ID 关联；成功结果可放大预览，历史列表出现版本；下载按钮只在有资源时可用。
8. 切换“动作预演”，生成黑白预演并检查人物动作、镜头节拍和首尾衔接。
   - 预期：预演和分镜图是不同产物类型，不覆盖原图；历史版本可切换。
9. 切到“镜头视频”，选 `minimax_h3_z0901` 或当前可用视频模型，点击“生成镜头视频”。
   - 预期：显示运行时间/状态；成功后可播放并下载视频；失败显示原因并支持重新生成。
10. 点击下载视频，用独立播放器检查文件非空、时长、画幅和声音；刷新项目后再次打开镜头。
    - 预期：最新产物和历史仍可见，下载按钮可用；不会因刷新重复提交任务。
11. 在“项目画布”新建当前章节画布或项目画布，确认章节/镜头关联。
    - 预期：项目关联保存；画布列表显示所属项目；独立画布和项目素材不因解除关联而被错误删除。

## 6. 导演台工作流

### 6.1 新建场景

1. 在画布工具栏添加“导演台”节点并打开。
2. 在“选择镜头模板”中选择其一：空场景、单人对白、双人对话、人物走位、产品/道具镜头。
3. 预期：空场景只有摄影机和三点布光；其他模板按描述预置演员/道具，不强行添加默认演员。
4. 修改顶部镜头标题；检查对象列表、摄影机、灯光列表和预览视图。
5. 添加演员、立方体、球体、圆柱、灯光或上传 `.glb/.gltf` 模型；选择对象后移动、旋转、缩放。
6. 上传模型失败时不要把伪文件当成可用对象；成功后素材列表能复用同一模型。

### 6.2 四种模式和保存

| 模式 | 应显示能力 | 测试操作 |
| --- | --- | --- |
| 摆场 | 演员/道具/灯光布局，预览和彩色白膜 | 拖动物体，检查不重叠和撤销 |
| 姿态 | 骨骼/姿势；不显示时间轴关键帧入口 | 选演员，选站立/T 型/行走/跑步等姿势，检查局部骨骼 |
| 动画 | 时间轴、Auto Key、吸附、记录/删除关键帧 | 开 Auto Key，改变姿态和机位，播放并回到指定帧 |
| 摄影机 | 机位、焦点、焦距、光圈、运镜、深度/法线 | 对齐视图、生成运镜轨迹；需要手动关键帧时切动画模式 |

模式切换时预期：离开动画会停止播放并关闭 Auto Key；不允许隐藏状态继续写关键帧。
顶部保存状态可能为“保存中/已保存/未保存/远端保存失败”；出现错误不能关闭后宣称完成。
点击“重试保存”后再确认状态。关闭工作台会先做保存检查，失败时应留在工作台。

### 6.3 输出到画布

1. 在摄影机模式调整主摄影机和镜头，选择“预览/彩色白膜/骨骼/深度/法线”中当前模式允许项。
2. 点击“导出白膜”，等待录制完成。
   - 预期：浏览器录制白膜并上传，构图图片与白膜视频回写画布；这不是 AI 视频生成任务。关闭工作台后从视频节点下载并检查能播放。
3. 点击“应用到镜头”。
   - 预期：导演台构图图片节点写回当前画布，若有白膜则生成“导演台白膜视频”节点并建立引用连接。
4. 切换项目/镜头或删除节点后再让旧输出完成。
   - 预期：旧输出被拒绝，不能写入新项目、替代新镜头或覆盖并发编辑。

### 6.4 剪辑成片与创作对话

1. 在项目详情进入“剪辑成片”，从项目素材/就绪镜头添加至少两段视频到时间线。
2. 调整片段顺序/长度，在预览检查画面；观察“未保存/保存中/已保存/保存失败”。
3. 刷新重新进入，确认时间线实际恢复；保存失败时仍应保留脏状态，不把旧版本当新版本。
4. 打开右侧“导出”，看渲染计划和渲染源数量；有有效媒体源时点“渲染成片（服务端）”。
5. 预期创建服务端渲染任务，完成后返回资源并提供预览/下载；独立播放器检查 MP4 的镜头顺序、黑帧、时长和声音。
6. “本地导出（ffmpeg.wasm）”是另一条路径；需浏览器能加载同源 FFmpeg 和素材，不保证无资源时可离线完成。
7. 本地字幕烧录不可用时源码会提示并回退无字幕导出，必须检查成片字幕，不能仅凭下载成功判合格。
8. `/create` 的文本/图片/视频能力可先生成一项结果；对话菜单“导出对话”输出 Markdown，图片/视频文件另行下载。
9. 点击生成结果转入画布，预期等全部结果素材保存后再跳转，失败时保持可重试；删除对话只删除历史记录，不等于删除素材。

## 9. 账号、会话、余额与费用

- 公共期望：卫星请求由当前 HttpOnly Session 代表主站用户调用 Relay；浏览器不保存 SuperKey、用户 Key 或主站 JWT。
- JU 服务端认证代码固定 `sessionMaxAge = 3 * 24 * time.Hour`，SSO 票据仍是短时一次性票据；验收时检查 Cookie/JWT exp 为 259200 秒。
- A 创建的项目、章节、画布、资产、任务和对话不能在 B 显示；同浏览器切号后检查应用是否自动清理 React Query、localforage 和配置缓存。先观察原状态再取证，不在用例前手动清缓存来掩盖串号。
- 余额组件每 60 秒刷新；余额小于等于 0 应标红并提示充值，不能以读取失败推断余额为零。
- 生成前后记录主站余额、任务 ID、模型、规格和 usage；失败是否收费以实际网关账单为准。
- 测试时不得用管理员注册密钥调用模型；不得把 `sk-super-*` 当 Bearer 发送。

## 10. 执行记录和缺陷证据

| 字段 | 内容 |
| --- | --- |
| 环境 | 源码提交、镜像标签、浏览器、主站/JU 地址、时间 |
| 身份 | A/B 匿名编号、SSO/密码登录、Session 签发与到期摘要 |
| 业务 | 项目/章节/镜头/场景/任务 ID、模型公开名、参数和材料校验值 |
| 结果 | 用例状态、实际页面提示、生成/保存/刷新/下载结果 |
| 费用 | 生成前后余额、usage/账单 ID、是否发生重复任务 |
| 证据 | 截图、脱敏状态码/业务码、任务日志和文件解码结果 |

执行状态统一填写“未执行 / 通过 / 失败 / 阻塞”，初始均为未执行。渠道未配置、额度或测试素材不足写具体阻塞原因；任务完成但产物、保存或隔离不符合预期仍应记失败。

缺陷格式：`JU-缺陷编号 / 标题 / 前置 / 步骤 / 预期 / 实际 / 影响 / 复现证据 / 版本`。
不上传 Cookie、票据、项目密钥、真实账号、带签名资源 URL 或整段请求头。

## 11. 测试结束清理

先保存项目/章节/镜头/场景/任务 ID、脱敏证据、导出文件和费用对照，再清理本轮 `QA-JU` 测试作品。
删除项目、章节、画布前再次阅读删除提示，核对关联数据与独立素材保留范围；无引用测试素材才通过素材库删除。
生成中的任务先确认最终状态；删除节点/章节/任务记录不等于上游取消，不能据此判定停止计费。
任务记录仅按现有界面提供的删除入口处理；没有入口时记录残留 ID，不直接清数据库。
退出测试账号、关闭专用浏览器；保留失败现场需要时在执行记录说明。
