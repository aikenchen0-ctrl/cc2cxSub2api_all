# 图生 3D（AI3D）测试操作与验收手册

## 1. 文档基线与测试范围

- 源码核对日期：2026-10-08，依据当前工作区 `ai3d/`，包含尚未提交的更新。本文件是测试执行手册，所有用例初始状态为“未执行”，不是已通过的测试报告。
- 本地入口：<http://localhost:5174>；推荐从 <http://localhost:18080> 登录后点击“图生 3D”进入，应用标识为 `ai3d`。
- 覆盖登录、普通图片/线稿生成、任务队列、已有模型导入、3D 交互、作品集/笔记/项目、本地持久化、导出、失败恢复和用户隔离。
- 开始前记录源码版本、容器镜像/构建时间、浏览器和实际服务地址。若运行界面缺少本文件描述的入口，先确认镜像是否包含当前源码，再记录版本差异；不要把旧镜像的测试结果归给新源码。
- P0 是阻断主流程或数据安全的问题；P1 是重要分支与恢复；P2 是兼容性和展示。涉及云端生成的用例需要已配置 Provider 和测试额度。

## 2. 环境与测试数据

| 准备项 | 测试人员操作 | 核对标准 |
| --- | --- | --- |
| 账号 A、B | 用两个独立浏览器配置文件从主站分别登录 | 两个不同用户，不共享浏览器 Cookie；另备匿名窗口 |
| 服务状态 | 打开应用，在“设置”查看 Provider 状态，记录可用项 | 未配置的 Provider 明确提示缺少配置；服务端 API 内部端口默认 8787，不等同于浏览器入口 |
| 普通图片 | 准备一个白底单物体 PNG/JPEG，如无品牌陶瓷杯 | 能识别主体；记下文件名、尺寸、大小，不用敏感产品资料 |
| 线稿 | 准备杯子的黑白轮廓图和一张普通照片作为反例 | 两者可区分，用于草图确认与失败测试 |
| 模型 | 准备已知可打开、带材质的自包含 GLB，以及自包含 GLTF、损坏文件和带外部引用的 GLTF | 有独立查看器作为对照；不要仅把图片改扩展名当正常模型 |
| 浏览器 | 桌面 1440×900、手机 390×844，支持 WebGL | 浏览器存储可用；另备关闭 WebGL/受限存储的异常环境 |
| 费用 | 记录测试前余额、Provider 额度和任务数 | 图片理解与 3D Provider 可能分别计费，不能只查主站余额 |

图片理解由服务端托管，当前配置默认 `gpt-5.5`；混元、Tripo、Fal、Hyper3D 等是独立的 3D 服务。普通图片生成也可能先调用图片分析。“Provider 对比”会启动多家生成请求，应作为单独的计费测试。浏览器不得填写或持有 SuperKey。

## 3. 首次进入与无生成冒烟

### 3.1 登录与首屏（3D-001，P0）

1. 用 A 登录 Sub2API，从菜单打开图生 3D。
2. 确认无需再输入 API Key，页面能识别当前身份，3D 场景有实际模型。
3. 依次打开“作品集、模型库、笔记、日志、设置”，关闭后回到场景。
4. 在匿名窗口直接访问入口，再尝试受保护的资料/模型接口。

预期：登录用户可正常进入；匿名访问受保护接口被拒绝或引导重新登录，不能获取 A 的模型。首次场景非空白，菜单切换不使画布消失。界面主要为中文；记录实际语言和任何遮挡。

### 3.2 导入已知模型（3D-002，P0）

1. 点击“导入 GLB”，选择已知有效的自包含 GLB，不点击云端生成。
2. 等待模型加载，检查模型库中的新资产及来源标记。
3. 拖动旋转、滚轮缩放、重置视角，再截图。
4. 刷新同一浏览器，重新在模型库选择该模型。

预期：模型可见、材质完整、比例与对照一致；来源为本地导入，不创建云端生成任务。刷新后在同一用户、同一浏览器下能恢复。图片占位、纯色画布或加载错误不算导入通过。

## 4. 云端生成主流程

### 4.1 普通图片确认与取消（3D-003，P0，无生成提交）

1. 保持默认混元普通模式，点击“上传图片并生成 3D”，选择测试 PNG。
2. 检查“确认生成 3D？”弹窗：文件名、预览、“预计 2–8 分钟”“会消耗积分”和 GLB 输出信息。
3. 点击“取消”，检查左侧任务队列和网络记录。
4. 再次选择相同图片，检查文件选择仍能触发预览。

预期：确认前没有生成任务或云端生成请求；取消不新增任务，不以取消为由扣生成费用。再次选择同一文件可用，预览与选中文件一致。取消不等于取消已经提交的远程任务。

### 4.2 普通图片生成（3D-004，P0，计费）

1. 记录 Provider、余额和队列数量。默认混元为 Hunyuan 3.1 Normal，普通模式不附带草图提示词。
2. 上传测试 PNG，在弹窗点击一次“确认并生成”。
3. 立即检查左侧队列：在解码/分析完成前即应出现任务；选择运行中的任务，确认可看到源图和状态。
4. 持续观察“准备图片中→分析图片中→上传中→生成中→就绪/失败”，记录任务 ID、耗时和原始错误；实际阶段可因 Provider 略有不同。
5. 就绪后打开模型，从正面、背面和底部旋转检查，核对来源 Provider、模型 URL 和日志。

预期：确认一次对应一个逻辑任务；队列不静默等待，进度与最终结果对应同一源图。成功必须能加载实际 3D 几何并旋转，不以源图回退或状态文字代替。失败保留任务和源图，有可诊断错误，不能伪装成浏览器深度预览成功。

前端约每 3.5 秒轮询，等待上限为 8 分钟；弹窗预计时间不是服务承诺。超时后先查任务/Provider 状态，超时不证明远程任务已取消，立即重试可能重复计费。

### 4.3 草图加提示词（3D-005，P1，计费）

1. 选择“混元 · 草图+提示”，确认出现草图说明和 1024 字符计数框。
2. 输入：`一个直立陶瓷杯，圆柱形杯身，右侧单把手，杯底平整，表面光滑。`
3. 点击“添加草图”，选择线稿，检查“确认这是线稿吗？”弹窗，再确认生成。
4. 核对请求模式、最终模型和日志；用普通照片做一次反例测试时记录 Provider 原始拒绝原因。
5. 单独检查空提示词与 1024/1025 字符边界；不必为每个输入边界实际提交生成。

预期：草图模式走 Hunyuan 3.0 Sketch，并将中文提示词与线稿一起发送；输入不超过 1024 字符。空值有源码设定的细胞描述兜底，应记录这一行为，不能解释成模型理解了空输入。额度/输入类错误可能分别显示“腾讯云充值”“需要线稿”，须保留底层错误验证映射是否准确。

### 4.4 Provider 与自动回退（3D-006，P1，计费）

1. 检查主要选项中的混元、Tripo、草图模式，以及“高级设置”实际开放的 Hyper3D、Fal、Auto、Local GLB。
2. 在隔离测试配置中让首选 Provider 返回可控失败，再选 Auto 提交一张测试图。
3. 查看日志中的尝试顺序、实际成功 Provider 和最终失败原因。

预期：选项与服务健康配置一致。Auto 按 Hunyuan→Tripo→Fal→Rodin 尝试可用服务，结果能追溯到实际 Provider；全部失败时显示失败，不以 JS Depth 当作云端重建成功。代码中存在 JS Depth 预览，但当前主要/高级选择器排除了该项，不按可见功能验收。

## 5. 检查、演示与导出

### 5.1 3D 交互与抽屉（3D-007，P0）

1. 对成功生成或导入的模型单击、拖动，放大/缩小，切换自动旋转后重置。
2. 明确点击“信息”或“检查”，核对抽屉中的来源、Provider、模型信息。
3. 对内置结构模型尝试部件聚焦/隐藏；对生成模型仅验证实际提供的结构能力。

预期：拖动旋转、单击模型不会自动弹出遮挡场景的信息层；明确操作才打开抽屉。操作后模型仍可见，重置能恢复可用视角。生成网格不一定有可识别的语义部件，不能把内置模型的结构功能当作所有模型的承诺。

### 5.2 演示与截图（3D-008，P1）

1. 点击“演示”，观察多个连续画面，再退出。
2. 在桌面和手机尺寸重复，检查工具栏、确认弹窗、队列与模型不互相遮挡。
3. 下载截图 PNG，用图片查看器确认尺寸、模型、背景及画面完整性。

预期：演示有实际运镜，画布非空白；退出恢复工作区。不能仅凭页面有 Canvas 标签判定通过，应保留前后截图或短录屏，确认像素和视角发生变化。截图是图片，不是可旋转模型。

### 5.3 GLB 导出（3D-009，P0）

1. 模型尚未加载时检查导出按钮；加载完成后选择“导出 GLB”。
2. 记录下载文件名、大小和真实类型，用独立查看器重新打开。
3. 检查材质、贴图、透明部分、朝向，以及隐藏/展示状态是否符合实际导出约定。
4. 在 WebGL 不可用或导出失败环境重复，查看错误与下载内容。

预期：导出器未就绪时按钮禁用并说明原因；正常下载为可打开的 GLB。源码在失败时可能下载 `*-model-export.json` 元数据，必须登记为“GLB 导出失败/元数据回退”，不能因为下载成功而判定 GLB 通过。

## 6. 项目与持久化

### 6.1 项目保存、载入与浏览器存储（3D-010，P1）

1. 用右上角项目图标（立方体加下拉箭头）打开项目管理，保存为 `QA-3D-日期-A`。
2. 增加一条测试笔记、截图作品和设置变更，保存后刷新并载入项目。
3. 导出项目，检查 `.modelstudio.json` 中的名称、模型引用和快照信息；仅在保存证据后删除本次测试项目。
4. 在 B 的独立浏览器以及 A 的另一台设备检查列表；在受限存储环境观察提示。

预期：模型、笔记、设置、作品集和项目按用户命名空间保存在本地 IndexedDB/localStorage；同一浏览器可恢复，切换用户不混入他人数据。它们不是跨设备云同步承诺。当前有项目 JSON 导出，未发现对应的项目 JSON 导入 UI，不把文件导出当成已验证的可恢复备份。

源码最多保留 8 个自定义资产和 40 条生成历史。边界测试先准备证据，再添加超过上限的数据检查保留顺序；隐私模式、存储配额不足或清理浏览器数据可能使本地资料无法恢复，应有提示，不能错误声称已持久化。

## 7. 异常与隔离回归用例

| 用例 | 优先级 | 输入与操作 | 预期结果与取证 |
| --- | --- | --- | --- |
| 3D-011 文件校验 | P1 | 选择损坏 GLB、伪造扩展名、自包含 GLTF及外部引用 GLTF | 正常自包含文件可导入；异常文件有明确失败，不无限加载。服务端默认上限 180 MiB，记录边界配置与响应；外部资源无法加载时不能算导入成功 |
| 3D-012 失败重试 | P1 | 在隔离环境模拟 Provider 失败，选择失败任务再重试一次 | 源图、错误保留；新执行可追溯，重复点击受控；重试可能再次计费，核对两次任务和账单 |
| 3D-013 网络中断 | P1 | 任务运行时断网，恢复后查询同一任务 | 页面不伪造成功；能恢复已有结果或明确说明状态，不能无提示再提交；留存网络错误与任务 ID |
| 3D-014 大模型/WebGL | P1 | 导入压力模型或关闭 WebGL | 有可理解错误/回退；源图回退不算实际 3D 成功；其余菜单仍可操作 |
| 3D-015 用户隔离 | P0 | B 使用 A 的任务 ID、模型/日志 URL访问受保护接口 | 不返回 A 的模型、源图和日志；按接口返回拒绝（模型/任务所有权拒绝通常为 403），匿名身份接口为 401；不以隐藏菜单代替服务端鉴权 |
| 3D-016 会话过期 | P0 | 过期会话访问生成/模型接口，重新从主站进入 | 提示重新登录；不沿用其他用户身份、不泄露服务凭据；重新进入后任务归属正确 |
| 3D-017 凭据与费用 | P0 | 检查 URL、浏览器存储、脱敏网络响应和主站/Provider账单 | 无 SuperKey、供应商密钥；分析与生成费用能关联实际任务，B 不承担 A 的调用费用；错误/取消的扣费按服务实际规则核对 |
| 3D-018 删除一致性 | P1 | 删除本次测试资产/作品/项目后刷新 | 对应列表与本地状态一致；已经远程生成的任务/费用不因删除前端记录自动撤回 |

公共会话约定：新签发/续签的 `ai3d_session` 和服务端会话均为 3 天（259200 秒），Cookie 为 HttpOnly；SSO ticket 约 2 分钟且只用一次。分别测试票据重放和会话过期，不要求为 TTL 校验实际等满 3 天；旧会话按原有效期自然结束。

余额用同源 `/api/sub2api/balance` 读取，成功响应应 `Cache-Control: no-store`。使用专用零余额用户检查红色充值提示，目标仅为公开主站 `http://localhost:18080/purchase`；公开 LINK 缺失时应禁用跳转，不能返回 Docker 内部中转地址。支付是否可用是独立环境项，本手册不通过付款来验证跳转。

## 8. 执行记录、缺陷与清理

每项填写：`用例ID｜未执行/通过/失败/阻塞｜环境/版本｜输入文件摘要｜Provider/模式｜任务ID｜耗时｜预期｜实际｜证据路径｜缺陷ID`。外部服务未配置或额度不足记“阻塞”，另记配置提示是否合格；模型已生成但查看器空白仍应记录应用失败。

缺陷证据至少包含复现步骤、确认弹窗/队列/3D场景截图、脱敏请求状态码、错误原文、任务和 Provider ID、下载文件。模型质量用正面/背面/底面对照判断；背面与尺寸属估算结果，不能代替实测或生产级 CAD 精度验收。禁止在报告中粘贴 Cookie、SSO ticket、SuperKey、完整供应商 Token。

测试结束：先保存必要截图和导出文件，再删除自己建立的测试资产、笔记、作品和项目；记录云端任务是否还在运行及费用。仅清理自己的浏览器测试数据，不清空共享服务存储或其他用户模型。
