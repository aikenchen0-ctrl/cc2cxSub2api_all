# AI 生图生视频（Canvas）测试操作手册

## 1. 测试基线与判定口径

- 编写基线：2026-10-08 当前工作区源码，包含尚未提交的修改。
- 本文是操作步骤和验收用例，不是“测试已通过”报告；未实际执行全部用例，未调用收费模型。
- 本地已运行的 Docker 镜像可能早于当前源码。执行前记录镜像、源码版本、浏览器和模型目录；界面缺项先核对版本。
- 本应用负责无限画布、参考关系、图片/视频/文本创作，以及素材和画布归档。音频、全景图、导演台入口也在当前画布工具栏中。
- P0：登录、身份隔离、核心保存及计费归属；P1：主要业务回归；P2：辅助交互与边界。
- “源码可见”只表示有实现入口；“公共规范期望”是验收标准，两者都不能替代实际执行结果。

## 2. 入口、界面和模型

| 项目 | 当前使用方式 |
| --- | --- |
| 主站 | `http://localhost:18080`，先登录，再点击“AI 生图生视频” |
| 卫星地址 | `http://localhost:3522`；画布库路径 `/canvas`，画布详情 `/canvas/{id}` |
| 画布库 | 新建画布、单项重命名/导出/删除、勾选后导出选中、导入画布 ZIP |
| 画布工作区 | 节点、连接线、左侧面板、助手面板、缩放/小地图、底部图标工具栏 |
| 底部工具栏 | 选择/移动、撤销/重做、文本、图片、视频、音频、全景图、导演台、生成配置、上传素材、素材库、我的素材、外观 |
| 图片悬浮工具 | 下载、保存素材、反推提示词、替换、局部编辑、裁剪、切图、放大；部分工具须在快捷工具配置中启用 |

当前源码默认文本是 `gpt-6-astra`，图片是 `gpt-image-2`，视频是 `grok-imagine-video-1.5`。
图片默认质量 `auto`、比例 `1:1`、画布图片数量 `1`。
配置中的初始视频值是 6 秒、720、`1280x720`；切换工作流后必须以该模型实际允许的参数为准。

托管 Sub2API 目录默认还有 `grok-imagine-image-1.5`、`seedance-2.0`、`kling-v3`。
服务端会补齐 16 个 AutoDL 视频工作流，已有环境变量只列旧视频模型时也会补齐。
界面显示中文工作流名称，保存值/调用值必须仍是英文 ID。
环境变量、账号以前保存的配置和渠道目录会影响实际选中项，测试记录不能只抄默认值。

| AutoDL 用例模型 | 使用重点 |
| --- | --- |
| `minimax_h3_z0901` | H3 文生视频；需要提示词，不接受任意参考图字段；默认 5 秒，范围 1-15 秒 |
| `minimax_h3_z0902` | H3 六图视频；至少 1 张、最多 6 张图片参考 |
| `minimax_h3_z0903` | H3 六图三音频；至少 1 图和 1 音频，最多 6 图和 3 音频 |
| `minimax_h3_b99_002` | 首尾帧工作流；按当前必填规则绑定首帧/尾帧 |
| `wan2.2animate-v4-motion_retargeting` | 动作迁移；按目录准备图片/视频，不按文生视频规则强填提示词 |

其他模型的分辨率、时长、图片/音频/视频数量从当前能力面板核验，不能照搬上表。
音频工具栏存在，但公共文本/图片/视频模型契约不等于已配置音频服务；没有音频渠道时记“环境阻塞”。

## 3. 账号、材料与开始前检查

使用两个普通主站测试账号 A、B，分别开独立浏览器配置文件；同浏览器切号另做一次隔离用例。
账号 A 有小额测试额度，账号 B 用于隔离；零余额另使用专用测试账号，不修改真实用户余额。
从主站进入后核对当前用户与余额，记录跳转完成的最终 URL，避免把一次性票据保存到截图或报告。

准备以下不含隐私的本地材料，并在执行记录填真实尺寸、字节数和校验值：

- `cup-base.png`：1024×1024，白色杯子、灰桌面，杯身有“QA-CUP”标识。
- `style-blue.jpg`：1024×768，蓝色摄影棚背景，只用作背景参考。
- `first.png`、`last.png`：同一主体的起止构图，用于首尾帧绑定。
- `voice-5s.wav`：5 秒自录测试音频；`motion-5s.mp4`：无隐私动作片段。
- `broken.png`：有 PNG 后缀但非图片内容；另准备一个不含 `projects.json` 的 ZIP。
- 项目命名：`QA-Canvas-A-日期-序号`，B 的项目加 `B`，避免误删已有作品。

先跑上传、布局、刷新和导出路径；真实生图/视频单独执行并记录预算。
模型可选不代表上游可调度；未配置渠道、参考材料不齐或额度不足时记录阻塞原因。
本次操作文档工作不要求重建镜像、修改配置或清空任何数据。

## 4. 主流程：一张图的画布保存与可编辑备份

本流程不需要生成调用。预期须同时检查界面和文件，不能只看“成功”提示。

1. 在主站用 A 登录并从菜单进入 Canvas，再打开 `/canvas`。
   - 预期：画布库加载完成；有“新建画布”和“导入画布”；不要求填写模型 Key。
2. 点击“新建画布”，返回画布库后用项目卡片铅笔按钮改名为 `QA-Canvas-A-日期-01`。
   - 预期：项目有独立 ID，名称更新；名称确认和取消按钮可用。
3. 打开项目，悬停底部图标找到“上传素材”，上传 `cup-base.png`。
   - 预期：得到可预览图片节点，主体完整，比例正确；不是仍在加载的占位节点。
4. 添加文本节点，输入 `QA-CUP：保留标识，仅测试裁剪`，拖到原图左侧。
   - 预期：文本可编辑；拖动只改变当前节点，其他节点不跟着跳动。
5. 选中图片，点击悬浮“裁剪”，选取包含杯身标识的中央区域并确认。
   - 预期：生成新的裁剪节点，原图仍在；裁剪图内容和边界对应预览，图片不被拉伸。
6. 拖动新图；点“撤销”，再点“重做”。
   - 预期：恢复的是这一次布局变化；节点和图片内容仍在，没有重复生成请求。
7. 在“画布外观”切换点网格为线网格，调整缩放，再停留至少 2 秒。
   - 预期：项目持久化队列有时间完成；画布结构不是只存在于当前鼠标操作中。
8. 刷新详情页，回画布库，再重新打开该项目。
   - 预期：名称、原图、裁剪图、文本、节点位置、外观和可用图片恢复；记录节点数。
9. 在裁剪图悬浮工具中点击“下载图片”，用本地图片查看器打开。
   - 预期：文件非空且能解码，下载内容是裁剪结果；与画布缩略图的尺寸分别记录。
10. 回画布库点项目卡片“导出”，保存 ZIP，解压检查。
    - 预期：有 `projects.json`；本地可取得的图片/媒体放在项目文件目录；JSON 包含节点和连线。
11. 在同账号点击“导入画布”，选择刚导出的 ZIP。
    - 预期：提示导入数量；生成导入项目后打开，文本、节点、裁剪图仍可继续编辑。
12. 刷新导入项目，并将新增测试项目 ID 写入执行记录。
    - 预期：导入不只是一次性预览；原项目与导入项目均可打开，未覆盖非测试作品。

保存边界：未登录的画布保存在浏览器本地；登录且账号同步启用时才同步到服务端。
同浏览器刷新成功只证明本地恢复，不证明云端保存成功。
需要云端验收时，用 A 的另一浏览器会话重新进入，确认服务端列表能恢复相同项目。
当前远端自动保存失败有静默捕获路径，不能凭界面未报错认定云端已保存。
ZIP 导出只打包能从本地存储取出的 Blob，远程 URL 媒体是否齐全必须解压核对。

## 5. 生成业务操作

### 5.1 文生图与参考改图

1. 在测试画布添加“图片”节点，选择 Sub2API 托管图片模型 `gpt-image-2`，1 张、1:1。
2. 输入：`白色保温杯放在浅灰桌面，柔和左侧光，完整居中，无新增文字和水印。`
3. 提交一次。预期先出现运行状态，再出现可预览结果或明确失败信息；记录任务/节点 ID。
4. 要改图时把底图连接到生成目标，或在支持的引用面板选择正确资源；核对引用栏缩略图。
5. 输入：`以杯子图为底图，仅将背景改为蓝色摄影棚，保留 QA-CUP 标识、杯体形状和位置。`
6. 完成后逐项检查标识、结构、背景和未要求区域；下载结果，刷新检查引用与产物仍可追溯。

图片只是摆在目标附近不构成参考输入。连接方向、引用选择和生成配置须有截图证据。
蒙版编辑要先涂抹区域再提交；裁剪/切图属于媒体处理，不能与 AI 重绘混为一条计费预期。

### 5.2 H3 视频操作

1. 添加“视频”节点，选 `minimax_h3_z0901`（中文 H3 文生视频），初始测试选 5 秒。
2. 选择该模型提供的分辨率/竖横选项；不要沿用 Grok 的 6 秒、720 参数作为固定规则。
3. 提示词：`白色杯子静放灰桌面，镜头缓慢推近，光线稳定，不增加人物，单镜头。`
4. 提交一次并记录 ID；等待完成，检查可播放、实际时长、画幅、首尾帧和声音状态。
5. 下载视频，用独立播放器验证非空、非静态黑屏；刷新画布再播放同一产物。
6. 换 `minimax_h3_z0903`，先故意缺音频，检查必填反馈；补 1 图和 1 音频后再执行收费路径。
7. 切换首尾帧模型，分别绑定 `first.png`/`last.png`，确认未把二者误当普通多图参考。

刷新、关闭面板、删除节点不等于上游任务已取消。没有看到取消实现时不要以“取消成功”为验收项。

## 7. 负向、故障与恢复

| ID | 优先级 | 前置条件 | 操作 | 可观察预期 |
| --- | --- | --- | --- | --- |
| CAN-N01 | P1 | 无提示词/必填参考 | 点击生成 | 本地或服务端校验失败，不出现假成功产物 |
| CAN-N02 | P1 | H3 多模态节点 | 去掉必需音频；输入第 7 图或第 4 音频 | 按能力限制拒绝或收敛；实际提交值有证据 |
| CAN-N03 | P1 | H3 文生视频 | 试 0/1/15/16 秒与超长提示词 | 边界 1-15 按规则校验；超界不静默提交错误值 |
| CAN-N04 | P1 | 上传入口 | 上传损坏图、错误文件类型 | 明确失败；不留下可下载的“成功”空图 |
| CAN-N05 | P1 | 画布库 | 导入普通 ZIP/损坏 JSON | 提示有效画布包要求；不破坏已有项目 |
| CAN-N06 | P0 | 测试浏览器可断网 | 修改后短暂断网并刷新 | 明确区分本地/远端恢复；不误报云端成功 |
| CAN-N07 | P1 | 专用测试环境上游失败 | 观察 401/429/5xx/超时任务 | 能保存错误和任务 ID；不无限旋转或偷偷重复提交 |
| CAN-N08 | P1 | 生成进行中 | 刷新后等待原任务 | 按已提交任务恢复；不因刷新新建重复计费任务 |
| CAN-N09 | P1 | 仅测试项目 | 删除单项/选中项目后刷新 | 删除范围正确；已删除项目不被迟到保存复活 |

故障注入只在专用测试环境使用响应夹具或浏览器网络控制，不停共享容器、不改线上渠道。
保留失败前输入、引用、模型和任务 ID；先查原任务再决定重试，避免重复消费。

## 8. 账号隔离、会话与费用

- 公共规范期望：A、B 的项目、素材、任务、余额和用量分别归属，管理员进入卫星仍是普通用户。
- A 创建项目和素材后，B 的独立浏览器不应列出；B 访问 A 的测试项目/资源请求不得获得内容。
- 再在同一浏览器按 A→退出→B→A 切换，检查画布列表、素材缩略图、助手历史和生成配置是否串号。
- 当前 Canvas 本地画布存储使用固定存储键且有本地/远端合并逻辑；同浏览器切号是必须执行的风险用例，不能仅用独立浏览器通过代替。
- SSO 源码有一次性短期 handoff Cookie 和最终 HttpOnly Session；`cookie:` 身份提示不是真实模型 Key。
- 新会话公共期望为 3 天（259200 秒），检查新 Cookie Max-Age 与服务端到期；约 2 分钟票据期限是另一项。
- 重放已使用票据、无 Session、过期 Session 应被拒绝；重新从主站菜单进入恢复身份，不手工写入 Key。
- 公共期望：浏览器请求不携带服务端项目凭证、代办身份头、SuperKey 或主站 JWT。
- 余额组件按当前用户读取；零余额标红/提示充值，公开充值目标应为 `http://localhost:18080/purchase`。
- 充值 URL 缺失时不得跳转 Docker 内部地址；余额读取失败不能当作余额为零的证明。
- 真实生成前后记录 A/B 主站余额与用量，确认只归属实际发起者；失败是否收费按实际 usage 与网关规则核对，不预设“失败免费”。

## 9. 执行记录与缺陷证据

| 字段 | 填写内容 |
| --- | --- |
| 环境 | 执行时间、源码提交/未提交差异、容器镜像/创建时间、浏览器、入口 |
| 身份 | A/B 匿名编号、是否 SSO、会话新签发时间，不写 Cookie/密码 |
| 用例 | ID、实际模型英文 ID、提示词、规格、素材尺寸/校验值 |
| 结果 | 通过/失败/阻塞/未执行；实际与预期差异；项目/节点/任务 ID |
| 保存 | 同浏览器刷新、另一会话恢复、导入恢复分别填结果 |
| 文件 | 下载文件名、格式、尺寸/时长、能否解码、ZIP 项目与资源数量 |
| 费用 | 生成前后余额、主站用量记录 ID、是否重复任务 |

缺陷记录采用：`CAN-缺陷编号 / 标题 / 前置 / 最短步骤 / 预期 / 实际 / 影响 / 证据`。
附件至少包含关键界面截图、脱敏请求路径/状态码/业务码、任务 ID、下载文件信息和控制台时间。
不贴完整 ticket、Cookie、API Key、服务端凭证或带秘密参数的资源 URL。

## 10. 测试结束清理

先保存执行记录、脱敏截图、原始任务 ID、下载文件和 ZIP 清单，再清理本轮 `QA-Canvas` 项目及无引用测试素材。
只删除明确属于测试账号的作品，保留非测试数据；删除任务记录仅在界面提供对应入口且不影响证据时执行，否则登记残留任务 ID。
生成中的任务先查其最终状态；删除节点、画布或任务记录不代表上游请求被取消，也不代表费用回滚。
最后退出测试账号并关闭专用浏览器会话，不清空全站缓存、数据库或共享容器。
