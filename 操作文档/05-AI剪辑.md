# 05 AI 剪辑：测试操作手册

> **基线**：2026-10-08 当前工作区源码（含未提交改动）。本文按 OpenChatCut 门户模式编写，未在本轮运行收费聊天、生图、生视频、云端转写或全部导出。本地 Docker 镜像可能落后于源码，执行时先记录实际版本。

## 1. 入口与工作区

| 项目 | 当前值 |
| --- | --- |
| 主站 | http://localhost:18080 |
| AI 剪辑 | http://localhost:5199 |
| 进入方式 | 主站登录后点“AI 剪辑”，通过 SSO 建立应用会话；门户直达也有主站账号登录门 |
| 工程路由 | `#/editor/<工程 id>` |
| 会话 | `occ_session`，新发/续签 3 天 |
| 默认聊天 | OpenAI preset 更新为 `gpt-6-astra` |
| 图片 / 视频 | `gpt-image-2` / `grok-imagine-video-1.5`；其余选项需管理员实际可用配置 |

“我的工程”提供新建、搜索、重命名、复制、删除、导出/导入工程、素材清理和数据存储入口。编辑器包含顶部工具栏、Agent 聊天、素材/资源库、预览和属性、时间线。**新建工程当前直接创建空工程，画幅比例在时间线工具栏；不要沿用旧文档“新建时必须先弹比例选择”的步骤。**

资源主标签：我的素材、序列、资源库、文字稿、字幕、技能。资源库子标签：MG 动画、音效、转场、特效、缩放、LUT。

## 2. 测试准备

使用普通主站账号 A/B，分开浏览器配置文件。记录应用版本、存储模式、浏览器、GPU/内存、镜像标签、余额，门户模式无需输入 API Key。

| 素材 | 固定内容 |
| --- | --- |
| `qa-talk.mp4` | 20 秒横屏，开头 2 秒静默，中文讲话，末尾 2 秒静默 |
| `qa-portrait.mp4` | 10 秒竖屏，含一次镜头变化 |
| `qa-image.png` | 清晰图片、人物和文字均不靠边 |
| `qa-music.mp3` | 15 秒音乐，可辨识首尾 |
| `qa-subtitle.srt` | 3 条中文字幕，时间合法 |
| 边界素材 | 损坏视频、无声音视频、长文件名、大文件、缺失素材工程包 |

先创建 `QA-A-日期` 工程，复制为测试副本。测试删除、清理、YOLO 和重新转写只针对测试副本，不操作用户正式工程。

### 当前能力与未验证项

源码存在手动剪辑、字幕/文字稿、本地/云端转写、Agent Ask/YOLO、计划模式、自主验收、生成素材、版本历史、工程包、后台导出及质量检查。真实转写速度/准确率、外部模型、所有插件、跨软件 XML 和剪映草稿兼容性未在本轮实测。

桌面原生路径、ProRes、剪映本机草稿库和 MCP 可能有宿主依赖。Docker 浏览器模式中出现入口不代表可写入 Windows 用户的剪映目录。

## 3. 登录与工程生命周期

1. A 从主站菜单进入应用。
   预期：看到“我的工程”，账号属于 A；余额入口/用户身份稳定。
2. 点“新建工程”，双击顶部名称改为 `QA-A-日期`。
   预期：进入空工程路由，工程 id 固定，重命名后返回列表可搜索到。
3. 返回列表搜索关键词，清除搜索。
   预期：数量与结果同步；无匹配时显示空结果，清除恢复全部。
4. 复制工程，打开副本修改名字。
   预期：副本有独立 id，修改不影响原件。
5. 将副本导出为 `.ccproj`，记录“含素材”或“缺素材”的提示；导入该文件。
   预期：工程、时间线和可找到的素材恢复；缺素材必须有明确报告。
6. 删除测试导入副本，观察二次确认。
   预期：确认才删除，正式原件保持；共享素材不应被错误清理。

## 4. 主流程：手动剪出 15 秒成片

1. 打开测试工程，在时间线工具栏“画幅比例”下拉选择本用例需要的横屏/竖屏。
   预期：预览比例变化，画布数据保留；片段属性的“画布”是背景填充，不能当作比例入口。
2. 在“我的素材”导入视频、图片和 MP3。
   预期：上传进度、缩略图/波形或错误可见，导入只进素材池，不自动证明已入成片。
3. 把 `qa-talk.mp4` 落到视频轨，将图片放在后段；音乐落到音频轨。
   预期：时间线出现片段，预览在对应时间显示画面和声音。
4. 使用播放头和切分按钮（C）把讲话开头/末尾静默分开，删除静默片段。
   预期：选中片段被切分，保留讲话；检查是否留下空隙。
5. 使用选择模式（V）拖动/裁首尾，修剪模式（N）验证波纹合缝，滑移模式（U）验证位置/时长不变但源区间变化。
   预期：每个模式作用符合工具提示，撤销能恢复前一步。
6. 使用比率拉伸或速度控制缩短一个测试片段。
   预期：片段时长和播放速度同步，不出现负时长。
7. 调低音乐音量，给音频添加淡入/淡出；检查独听、静音和轨道状态。
   预期：讲话可听清，静音轨不进混音，参数在属性里可观察。
8. 从资源库给相邻视频加转场，再加一个特效或 LUT。
   预期：预览看到效果；选错片段时不能静默应用到另一轨。
9. 检查预览画质“自动 / 高清 / 流畅”，拖动播放头，比较代理和原始素材。
   预期：只改变预览策略，不应改变成片引用或工程剪辑点。
10. 返回列表并重开工程。
    预期：素材、剪辑点、效果和画布仍在；保存失败时应用提示并阻止切换工程。

## 5. 字幕与文字稿

1. 对含人声素材发起转写，记录选用的本地/云端服务、语言、首次下载与模型准备状态。
   预期：显示任务状态；未配置云端不能悄悄使用别的账号代付。
2. 打开“文字稿”，核对人名、数字、停顿和轨道。
   预期：文字与音频可对应，点击词可定位/操作。
3. 在复制工程上删除一个词，或执行去口头词/静默清理。
   预期：核对该操作是否同时改变音频与片段时序；不能按纯文本编辑验收。
4. 打开“字幕”，建立手动字幕或导入 `qa-subtitle.srt`，调整样式、位置和时间。
   预期：字幕在指定时间显示；安全区内可读，长句换行不遮挡人脸。
5. 导出 SRT 和 TXT，重新导入 SRT。
   预期：SRT 有合法时间与条目，TXT 只有文字；导入后轨道数量和内容可核对。
6. 无声素材/不支持语言/中断转写各测试一次。
   预期：空结果或失败可解释，原有字幕和剪辑不会被清空。

## 6. Agent 对话剪辑与生成素材

1. 开启聊天设置，先选择 Ask 模式，关闭计划模式，用简单请求：
   > 仅把当前选中片段音乐音量减半，保持其余片段不变。
   预期：出现提案时等待人工应用；**Ask 不是所有工具都等待确认，源码说明工具可直接执行**。
2. 审查修改列表/预览，拒绝一次，再提交并应用一次。
   预期：拒绝不改时间线；应用后目标参数改变，可撤销。
3. 开启计划模式，要求“先列出剪成 15 秒的步骤”。
   预期：先编号计划，确认后再动手；没有确认不得把计划当成已执行。
4. 在副本切为 YOLO，执行同一简单修改。
   预期：提案自动应用，任务/变化记录可追溯；本模式可能直接改工程。
5. 开启自主验收并设置轮次，观察 Agent 是否读最新工程、报告检查与失败。
   预期：有实际检查活动；“自主验收”不能替代人工播放成片。
6. 让 Agent 生成一张测试图片并放入素材池，再生成短视频（仅在批准的付费测试额度内）。
   预期：聊天、生图、视频任务分别有状态；完成素材入池且不重复添加。
7. 中断一个 Agent/视频任务，刷新重进同一工程。
   预期：观察运行恢复、失败提示、已入池素材是否重复；本轮未验证恢复成功率。

当前公共映射：Nano Banana 对应 `gemini-3.1-flash-image`，Seedance 对应 `seedance-2.0`，Kling 对应 `kling-v3`。下拉厂商选项不证明对应能力可用，不应把厂商显示名直接当公开模型 ID。

## 7. 导出与工程备份

1. 点顶部导出，视频选 MP4 (H.264)、1080p、30 fps、均衡/自动码率。
   预期：输出名称、尺寸/帧率可见；短边分辨率策略可能使竖屏尺寸不同，按显示实际值验收。
2. 开启“导出后自动质量检查”，执行导出。
   预期：显示浏览器/服务端渲染、进度、后台任务；质检有画面/声音/剪辑点/字幕结果或明确失败。
3. 关闭导出弹窗继续查看工程，再点顶部导出/历史。
   预期：能查看进行中任务；取消任务进入取消状态，不能显示成功成片。
4. 播放输出：检查首尾、时长、帧率、黑帧、转场、音画同步、音乐、字幕和分辨率。
   预期：与时间线一致；自动质检通过也须人工检查。
5. 视频格式再试 WebM (VP8)，ProRes 422 HQ 按环境能力单列。
   预期：不支持时明确错误；ProRes UI 声明仅本机渲染，Docker 浏览器未验证。
6. 音频页导出 MP3；字幕页导出 SRT/TXT；MG 页有 MG 才导出透明 MOV。
   预期：无相应轨道/MG 时提示空状态，不能输出伪成功文件。
7. XML 页选择 Premiere/达芬奇并检查素材重链接；剪映页仅用测试目标路径。
   预期：显示兼容性/离线素材提示；模糊背景不会完整还原为目标软件图层。
8. 最后从工程列表导出 `.ccproj`。
   预期：含素材工程可再次导入；MP4 是成片，`.ccproj` 才是可继续编辑的工程。

## 9. 边界、网络与隔离

损坏视频、缺失素材、超长文件名、不同帧率/旋转信息、无声片段、只有图片、空时间线都要分别打开/剪辑/导出。记录浏览器资源占用，大文件失败不能用小文件成功替代。

上传、自动保存、Agent 流、视频轮询和导出分别模拟超时/断网/401/500；检查可重试信息、任务是否重复、临时文件与素材是否残留。保存约 500 毫秒防抖且离开会 flush，不能凭“等待半秒”认定持久化成功。

A/B 分别建同名工程，验证工程文档、素材下载、转写、Agent 运行、导出历史与工程包隔离。账号切换后不能借浏览器缓存看到上个账号的内容。

## 10. 会话与用量

统一规范要求：新发/续签 Session 3 天；无身份 401；服务凭据未配置应拒绝；模型代调按当前主站用户记账；余额成功响应不缓存，充值地址指向公开主站。

记录操作前后余额、Agent/生成 id、主站用量 id 和费用。手动剪辑、导出、云端转写、图片、视频可能走不同链路，不能假设全部免费或按同一固定价收费。现有老 Session 依原到期时间自然结束。

## 11. 执行记录与缺陷模板

执行状态统一为“未执行 / 通过 / 失败 / 阻塞”，初始均为未执行。记录用例、浏览器/GPU、版本、存储模式、账号 A/B、素材大小、画布、fps、导出格式、耗时、结果、工程/运行/用量 id、截图和成片文件路径。依赖或额度不足写清阻塞原因；导出任务完成但成片内容不符仍记失败。

## 12. 测试结束清理

先保存执行记录、截图、导出文件、工程包、缺陷和费用证据，再检查生成、转写和后台导出是否仍运行。仅取消本人的测试任务；确认任务终态和工程已保存后，删除自己创建的测试副本与导入工程。素材清理会影响多个工程，先核对引用，不对正式素材执行全量清理。保留失败工程包供复现。
