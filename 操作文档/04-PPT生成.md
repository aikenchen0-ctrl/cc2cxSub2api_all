# 04 PPT 生成：测试操作手册

> **基线**：2026-10-08 当前工作区源码（含未提交改动）。本文是测试操作与验收依据，不是通过报告；本轮未执行收费生成和完整导出。本地 Docker 镜像可能落后于源码，差异应记录版本后再判定。

## 1. 入口与页面

| 项目 | 当前值 |
| --- | --- |
| 主站入口 | http://localhost:18080 |
| 应用入口 | http://localhost:8341 |
| 推荐入口 | 主站登录后点击“PPT 生成” |
| SSO 回调 | `/api/v1/auth/sso/callback` |
| 会话基线 | 新签发/续签 3 天（259200 秒），ticket 短时一次性 |
| 文本 / 图片 | 默认公开名 `gpt-5.6-sol` / `gpt-image-2` |

当前主要区域：创建页的提示词、附件、标准/智能模式、页数和语言；高级设置；标准模式大纲页与模板选择；演示编辑器的缩略图、页面画布、AI 聊天和插入面板；仪表盘、模板、社区、主题。

启动会先检查后端和实例配置，短暂显示“正在加载永恒 PPT...”。配置失败时应看到错误提示。门户用户无需填写模型密钥；页面若一直在主页/创建页循环跳转，应记录为启动问题。

## 2. 测试准备

准备两个独立普通主站账号 A/B，以不同浏览器配置文件登录。A 有余额，B 初始无作品；余额不足场景用专门测试账号或已配置的测试环境，不能修改真实用户资产。

准备固定素材：

| 素材 | 内容 / 用途 |
| --- | --- |
| `ppt-brief.txt` | 300 字中文简介，包含日期、3 个数字、“待确认” |
| `ppt-source.pdf` | 3 页：文字、表格、图片、页脚日期 |
| `ppt-source.docx` | 编号列表和表格 |
| `ppt-data.xlsx` | 10 行数据，含中文表头和百分比 |
| `ppt-image.png` | 16:9 清晰图片 |
| 边界素材 | 9 个合法附件、损坏 PDF、空文件、错误扩展名 |

记录浏览器、素材大小、主站用户标识（脱敏）、余额、镜像标签/源码版本、开始时间。生成案例使用独立标题 `QA-A-日期-序号`。

### 已从源码确认

- Standard（标准）先到 `/outline?id=...`；Smart（智能）直接到流式演示页。
- 提示词、附件、Smart 社区参考至少有一种输入才可提交。
- 附件最多 8 个，类型包含 Word、PPT、Excel/CSV/TSV、PDF、图片、TXT。
- 页数允许自动或自定义，上限 50；大纲内容前端按空白分词限制 100 词。
- 附件场景不能选择 Auto 语言。
- 高级设置支持说明、语气、详细程度、目录和标题页；另有网页搜索配置。
- 编辑器有重命名、撤销/重做、演示、导出、加页/复制/删页/排序；插入能力随页面编辑类型而异。

### 未实测

真实模型返回、不同模板兼容性、网页搜索、所有导出格式、字体覆盖、计费金额和中断恢复。功能在源码中存在不能证明当前镜像已包含，也不能证明执行成功。

## 3. 登录与基础检查

1. A 在主站登录，点击“PPT 生成”。
   预期：跳到本地应用并建立自己的会话，能够打开创建页，URL 不残留密钥。
2. 刷新应用，再访问 `/upload` 和仪表盘。
   预期：会话有效期间保持登录；不会不断返回配置首页。
3. 新浏览器直接访问应用。
   预期：未登录时进入登录/主站入口，收费接口不能匿名执行。
4. 在测试环境检查新发 Cookie 的 HttpOnly 和 259200 秒 TTL。
   预期：会话与短时 SSO ticket 分开；不需等待 3 天才能记录 TTL。
5. 重用一次旧 callback 或等待票据过期后再打开。
   预期：拒绝旧票据，回主站重新点击即可恢复。不得把票据 URL 写入公开缺陷附件。

## 4. 主流程：标准生成并编辑

1. 在创建页选择“标准 / Standard”、中文和 6 页。
   预期：当前设置明确显示，页数为 6。
2. 输入以下提示词：

   > 制作一份面向新员工的信息安全入门中文演示文稿，6 页：封面、密码、邮件、文件分享、设备、总结。只使用提供事实，未知制度标记待确认。每页不超过 3 个要点。

   预期：输入保留，附件为空时也可提交。
3. 打开高级设置，输入“面向非技术听众；语句简短；不要编造统计数据”，调整语气和详细程度，开启标题页，按保存。
   预期：保存关闭弹窗，再次打开时值一致；按关闭/Esc 放弃草稿不应误保存。
4. 点击生成一次。
   预期：显示加载状态，进入大纲页；记录 presentation id、耗时和错误提示。
5. 检查大纲页数和顺序，修改一个要点，添加或删除一个大纲项。
   预期：修改在列表中可见；长文限制明确，不静默丢失全部内容。
6. 选择模板并生成页面。
   预期：编辑器显示缩略图和页面；结束后可编辑，生成失败可观察到原因。
7. 选择第 2 页并修改一处文字。
   预期：修改出现在画布上，其余页不被覆盖。
8. 添加一页、复制一页、删除副本、拖拽排序。
   预期：数量及顺序同步，当前选择正确；最后一页删除行为需单独记录。
9. 双击/点击顶部标题，改为 `QA-A-标准版`，Enter 保存；另一次 Esc 取消。
   预期：保存和取消符合操作，不出现空白标题。
10. 等待保存转圈结束，返回仪表盘重开同一文稿。
    预期：标题、文字、页序均保留。

## 5. 主流程：附件与智能生成

1. 回到创建页选择“智能 / Smart”，选择中文和 8 页。
   预期：模式改变，不经过标准大纲审核。
2. 添加 PDF、Word 和 Excel，确认 3 个文件名；移除一个再添加。
   预期：列表/计数同步，移除文件不再上传。
3. 输入“以附件为唯一事实来源，保留原始日期、数字和单位，输出中文项目汇报”。
   预期：提示词和附件一起发送。
4. 选择一个社区设计参考（列表为空则标记环境未配置）；更换或取消参考。
   预期：选择状态清楚，取消后不会继续带旧参考。
5. 点击生成。
   预期：进入 `/presentation?id=...&stream=true&type=smart`，逐页流式显示，结束状态明确。
6. 检查来源数字、日期、表格和图片。
   预期：事实可追溯；偏差作为内容缺陷记录，不因“生成完成”判为通过。
7. 开启“选择后编辑”，点击页面元素，向 AI 聊天提交“仅把该标题改为测试标题”。
   预期：选中上下文进入聊天，目标页得到修改；按钮在部分较小宽度可能隐藏。
8. 对整稿重新生成前先导出，点击重新生成后先取消。
   预期：取消保持原稿；确认后有替换页面并清除撤销历史的警告。

## 6. 插入、演示与导出

1. 在支持的 V2 编辑页面打开文本、图表、信息图、表格、图片和元素面板，各插入一项。
   预期：当前页出现元素，位置和尺寸可观察；不支持的页面应提示限制。
2. 开启 AI 面板，提出单页修改，确认聊天过程和失败状态。
   预期：修改范围可核对；不把无响应当成已应用。
3. 点击演示，从当前页开始，测试前后翻页及退出。
   预期：页序与编辑器一致，退出回到正确页面。
4. 点击导出，按当前菜单选择 PPTX、PDF。
   预期：禁用状态/加载状态可见，生成期间不会重复导出。
5. 打开下载文件检查页数、中文字体、长标题、图片比例、表格宽度、图表标签。
   预期：无丢页/黑页/文字超框；内容与最新保存版本一致。
6. 修改一页文字等待约 1 秒自动保存完成后刷新。
   预期：服务器重新加载仍保留；自动保存失败不能仅凭当前画布判断成功。

注意：源码自动保存失败处主要写控制台错误。若 UI 没有清楚提示，需作为可用性风险记录。生成中的刷新/关闭可能中断前端流，不能承诺后台恢复。

## 8. 负向与恢复

- 损坏 PDF、空文件、未知类型、同名附件：查看拒绝提示及网络状态，已成功附件不能丢失。
- 大纲超过 100 个空白分隔词、页数超过 50：核对前端限制；中文长段落不要误当成“100 个汉字”。
- 生成中双击、断网、返回、刷新：记录是否重复创建文稿、是否能重开、是否产生重复用量。
- 自动保存阶段阻断保存请求，再恢复：对比刷新前后内容；记录控制台错误和是否有重试提示。
- 导出接口 500、超时、磁盘不足：预期有失败状态，不生成伪成功下载。
- 后端不可达/实例未配置：预期显示后端或配置错误，不陷入首页与上传页循环。
- 小屏 390×844、桌面 1440×900：检查缩略图、高级设置、插入面板和导出菜单可达，文字不遮挡。

## 9. 账号、会话和计费验收

A 创建 `QA-A`，B 创建 `QA-B`；分别在仪表盘、详情、模板、社区私有内容、附件和导出入口检查归属。公开社区数据应先确认公开属性，不能与私有文稿混淆。

规范要求新会话 3 天，HttpOnly Cookie 与服务端有效期一致。过期后收费调用应 401，回主站重新进入恢复；SSO 账号与历史本地账号不会自动保证合并，需记录实际映射。

收费前后记录余额、任务/presentation id、主站用量记录。文本、图片、网页搜索和重生成可能分别产生调用；不能要求每次点击固定扣同一金额。无会话/凭据未配置时应拒绝，不得回退共享用户。

## 11. 测试结束清理

先保存执行记录、截图、导出文件及用量证据，检查流式生成、图片和导出任务的最终状态。仅取消自己的测试任务；待保存完成后，从仪表盘删除自己的测试文稿、副本和测试模板。社区参考先确认是本人创建的测试内容再清理，不能删除公共示例或他人文稿。失败文稿的 id 和输入资料保留用于复测。
