# 06 AI 一键复刻网站：测试操作手册

> **基线**：2026-10-08 当前工作区源码（含未提交改动）。本文覆盖新中文界面、录屏采样、设计规范、版本与评测工具。本轮未执行收费生成、外部截图或全量评测；Docker 镜像可能旧于源码，执行前记录实际版本。

## 1. 入口、区域和模型

| 项目 | 当前值 |
| --- | --- |
| 主站 | http://localhost:18080 |
| 应用 | http://localhost:5173 |
| 登录 | 主站登录后点击“AI 一键复刻网站”，通过 SSO 建立应用会话 |
| 首屏输入 | 上传、网址、文字、导入 |
| 左侧工具条 | 新建、编辑器、版本、设置 |
| 输出 | 桌面端、移动端、代码、下载、新标签页 |
| 会话 | `screen2code_session`，新会话 3 天 |
| 默认文本模型 | `gpt-6-astra`；高/低思考通过参数区分 |

门户模式后端忽略浏览器中的 OpenAI/Anthropic/Gemini 密钥和模型地址，用当前 Session 用户代调主站。前端仍保留独立运行设置输入框，测试门户时保持空白，不要填 SuperKey。

创建截图/文字任务默认 4 个变体，门户当前使用 GPT 6 Astra 高/低轮转；更新任务 2 个，视频任务 2 个。模型下拉中的其他厂商名称不证明本部署可用，后端实际选择为准。

技术栈包括 HTML+Tailwind、HTML+CSS、React+Tailwind、Bootstrap、Vue+Tailwind（Beta）、Ionic+Tailwind（Beta）；默认 HTML+Tailwind。输出是前端页面，录屏中真实后端行为只能用模拟数据复刻。

## 2. 测试账号与素材

A/B 使用独立浏览器配置文件和普通主站账号。记录余额、浏览器、镜像/源码、语言、技术栈、设计规范、图像开关及 Chromium 截图预览能力。

| 素材 | 内容 |
| --- | --- |
| `web-desktop.png` | 1440 宽截图，导航、列表、表单、图片 |
| `web-mobile.jpg` | 同页面 390 宽截图 |
| `web-state.png` | 表单提交后的成功状态 |
| `web-recording.webm` | 15 秒：点击标签、输入、提交、结果 |
| `web-import.html` | 独立 HTML，含按钮、输入框、图片和中文 |
| 边界素材 | 6 张图、20MB 边界文件、损坏视频、超 3 分钟视频 |

所有输入都用测试内容，不使用生产账户、客户秘密或真实支付操作。页面复刻质量使用同一组截图、同一浏览器宽度比较；不要只看缩略预览。

## 3. 当前能力、限制与未验证

**源码已确认**：上传最多 5 张 PNG/JPG/JPEG 或单个 MP4/MOV/WebM；上传组件单文件 20MB；视频后端限制 100MB、3 分钟、最多采样 16 帧；有设计规范 CRUD、元素选择修改、手动代码编辑、版本切换、ZIP 导出和单 HTML 降级；有评测集、会话、智能体记录、提示词报告等页面。

**明确限制**：上传的视频与图片不能混合；Figma/file:// 不能通过网址标签直接导入；网址截图需 ScreenshotOne 密钥，门户模型凭据不能替代截图服务；作品/版本目前是 Zustand 内存状态，没有项目持久化承诺，刷新会丢失当前结果；设计规范写实例公共 JSON，不能承诺 A/B 隔离。

**未验证**：真实模型输出质量、费用、所有栈交互、浏览器录屏兼容、16 帧对复杂操作的还原程度、ZIP 所有资源和评测权限。本轮不把这些写成已通过。

## 4. 登录与首屏检查

1. A 登录主站，点击应用菜单。
   预期：进入中文输入界面，生成调用使用 A 的身份；无须再次输入模型密钥。
2. 查看余额组件和设置的服务能力状态。
   预期：余额可读取或显示明确失败；“截图预览”可用/不可用是后端探测结果。
3. 在新浏览器访问应用并尝试收费生成。
   预期规范：无 Session 拒绝，回主站重进；外壳能显示不等于可匿名生成。
4. 检查 Cookie HttpOnly 和 TTL 259200 秒；重放/过期票据。
   预期：旧 ticket 拒绝，新 Session 按 3 天签发；不保存/转发主站 JWT。
5. 设置主题和技术栈后刷新。
   预期：设置可保留；当前作品的刷新行为按第 9 节记录，不能混淆设置持久化与作品保存。

## 5. 主流程：截图复刻与迭代

1. 选择“上传”，添加桌面、移动端、成功状态 3 张图。
   预期：缩略图计数正确，点击可切换/放大；移除一张后剩余顺序正确。
2. 技术栈选择 HTML+CSS，暂不选设计规范。
   预期：当前栈明确显示。
3. 保持“提取素材”开关的当前值并记录；输入补充要求：

   > 按截图还原布局、文案、表单和提交成功状态。桌面列表保持多列，手机单列。按钮应可操作，使用模拟数据；不请求真实后台。

   预期：文字和全部参考图进入同一创建任务。
4. 点击生成一次。
   预期：显示编码/思考/工具活动和 4 个变体；每个变体有独立生成、完成或失败状态。
5. 等到至少一个变体完成，逐个切换比较。
   预期：预览、代码和模型标签一起切换，失败变体不伪装完成。
6. 桌面端选择“适应屏幕”和“100%”，检查滚动、首屏/底部；移动端检查 390 宽附近。
   预期：缩放只改变预览展示，布局没有文字重叠、横向溢出。
7. 实际点击按钮、切换标签、填表并提交。
   预期：可观察到状态变化，不能只生成静态像素外观。
8. 在修改框输入“仅把顶部标题改为 QA 标题，其他内容保持”，提交。
   预期：新版本有 2 个变体，修改范围可比较。
9. 用版本按钮/历史选择上一版本、下一版本。
   预期：对应代码和预览切换，不混用另一版本的聊天上下文。
10. 在预览点“选择并编辑”，选中具体按钮，再提交“只把这个按钮背景改为绿色”。
    预期：选中元素上下文进入修改；Esc 退出选择，退出后页面交互恢复。

## 6. 文字、导入与设计规范

1. 点“新建”返回输入，选择“文字”；输入“带筛选与表单验证的测试客户列表，使用 5 条模拟客户”。
   预期：文字生成仍显示变体，按钮/筛选不是只绘制外观。
2. 新建并选“导入”，粘贴 HTML 或拖入 `.html/.htm`，选择技术栈后导入。
   预期：无需 AI 创建即可预览，版本注明“已导入现有代码”。
3. 空代码、未选栈分别点击导入。
   预期：提示先粘贴代码/选择技术栈；仅空白代码的实际行为需记录。
4. 打开代码标签，修改标题，再回预览。
   预期：当前代码可编辑，修改在当前变体显示；复制代码按钮复制的是当前结果。
5. 在设计规范选择器点新增/管理，创建 `QA-规范-A`：
   > 正文 14px；标题 24px；主按钮绿色；表格有明确表头；窄屏单列。
   预期：名称、内容保存，再打开仍一致；空名称保存拒绝。
6. 选择此规范生成并更新，观察模型是否遵循；删除前取消一次，再确认删除测试规范。
   预期：取消不删，确认后选择清空/切换；规范遵循程度按页面对比记录。
7. 用 B 打开设计规范列表。
   预期规范：私有规范应隔离；**当前源码实例共用文件，无 owner 字段，看到 A 规范须记录为隔离风险，不能写通过**。

## 7. 网址、录屏与视频输入

1. 网址标签填一个已授权公开测试页面，先不配置 ScreenshotOne。
   预期：提示先填截图密钥，不向模型直接发送网址代替截图。
2. 有测试截图服务时再截取公开网址。
   预期：先截图后生成；失败提示检查网址/截图服务，不重复创建任务。
3. 输入 Figma URL、file://、不可达网址。
   预期：Figma/file:// 明确拒绝；不可达请求有失败提示。
4. 上传 `web-recording.webm`（小于 20MB）。
   预期：作为视频模式，不能再混入截图；创建 2 个变体。
5. 点“录制屏幕”，选择测试标签，演示 15 秒操作，点“结束录制”。
   预期：浏览器共享停止，出现录屏预览、重新录制与生成按钮。
6. 审查录屏内容，选栈/设计规范，点生成。
   预期：后端先抽取按时间排序的图片帧，再调用 GPT 6 Astra 高/低；不能要求每个瞬间都被识别。
7. 拒绝录屏权限、损坏视频、超 3 分钟、录屏超 100MB分别测试。
   预期：有明确错误；上传文件还会先受 20MB 前端限制，后端 100MB 不代表 UI 可上传 100MB。

图片素材提取工具当前需要 Gemini 配置，而门户生成参数会清空 Gemini 凭据；勾选开关不证明该工具实际执行。图片生成/编辑和去背景仍依赖 Replicate 服务配置，不能按“gpt-image-2 已可用”验收。

## 8. 下载与独立运行

1. 在完成变体点下载。
   预期：通常下载 ZIP；解压保留 `index.html` 与资源相对目录。
2. 在下载目录打开或通过本地静态服务器运行，复测表单、图片、桌面/手机布局。
   预期：图片资源可找到，交互与应用预览一致。
3. 阻断导出接口后再下载。
   预期：前端降级为 `index.html`，这是源码明确行为；记录降级，不能误记“ZIP 成功”。
4. 点“在新标签页打开”，比较图片路径和代码。
   预期：新标签预览可见；带主站相对资源的 HTML 不保证永久独立可用。
5. 代码复制后和当前变体源码比较。
   预期：内容一致；CodePen 按钮会把代码发送外部服务，本轮未执行。
6. 下载包检查字体、脚本和外部 CDN。
   预期：资源不足须记录；后端主要打包图片，最多 50 个、单个 20MB，不是完整工程依赖打包器。

## 9. 保存、刷新与版本限制

当前 `project-store.ts` 没有 persist；作品、参考图、Agent 活动和版本树在内存中。**刷新前先下载/复制当前代码。** 刷新后工作区清空是当前实现限制，不能写“自动保存到账号作品库”。

设置和主题通过 localStorage 保留；设计规范通过后端 JSON 保留；Agent 运行/评测报告另有实例级日志。它们都不等于可恢复编辑项目。测试用“下载后导入代码”验证继续编辑，原历史树不承诺恢复。

## 10. 评测工具操作

测试工具入口是应用路径，不是业务作品列表。先用已有脱敏测试集，只读浏览；收费运行在额度批准后执行，清理按钮只对明确的测试报告使用。

| 页面 | 路由 | 主要用途 |
| --- | --- | --- |
| 评测首页 | `/evals` | 输入/输出查看 |
| 任务 | `/evals/run` | 选模型、栈、旧目录或评测集、文件、差异运行 |
| 多方案对比 | `/evals/best-of-n` | 并排比较输出 |
| 输入对比 | `/evals/openai-input-compare` | 对比两份模型输入 |
| 提示词报告 | `/evals/prompt-reports` | 查询报告、成本、格式化内容 |
| 智能体任务 | `/evals/agent-runs` | 运行详情、时间线、工具输入输出 |
| 会话 | `/evals/sessions` | 评测集、活动会话、运行矩阵 |
| 对比 | `/evals/compare` | 会话或模型结果对比 |

小规模评测流程：选一个测试集、一个文件、一个已配置模型和 HTML+CSS，保持差异运行，开始后记录总任务/完成/失败/跳过数；查看结果和工具时间线；重跑时检查跳过已完成任务；评分仅记录人工判断，不当成生产生成合格标准。

当前评测 API 多是不带 `/api/` 的实例级路径，门户 middleware 仅保护 `/api/`，handler 未见用户过滤。未登录/A/B 访问报告的拒绝及归属属于重点待验证风险；不要把诊断数据当成已隔离的用户私有库。

## 12. 故障、隔离与计费

分别阻断 WebSocket、设计规范保存、ScreenshotOne、Replicate、Chromium 截图工具和导出请求。确认错误变体、取消任务、代码保留、重新生成和新建都可理解；取消不代表已经发生的模型费用被撤销。

A/B 用相同截图和规范名称，比较生成、资产 URL、余额和用量。浏览器内存/设置可能残留上个账号状态，换号后不要假定已清空；设计规范/诊断报告当前隔离缺口需给出具体路径和状态码。

余额读取应带 no-store，充值跳公开主站 `/purchase`；门户不得向浏览器返回服务凭据。创建有 4 个变体、更新/视频 2 个，费用可能按多个模型调用累计，不能按“一次点击=一次调用”断言。

## 13. 执行记录与缺陷

## 14. 测试结束清理

先下载代码和资源、保存版本截图、Agent/评测运行 id 及费用证据，再查看仍在运行的生成或评测。只取消本人测试任务；关闭共享录屏并确认浏览器共享指示消失。自己的测试设计规范/评测记录有明确归属后才能删除；实例共用数据不做批量 prune。刷新会清空内存作品，先下载再清空，保留失败输入供复测。
