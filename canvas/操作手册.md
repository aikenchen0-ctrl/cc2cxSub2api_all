# infinite-canvas 操作手册

## 1. 项目定位

infinite-canvas 是一个浏览器端无限画布工作台，主要用于：

- 管理画布项目、节点、连线和素材；
- 文生图、图生图/改图；
- 文生视频、图生视频；
- 文本问答、图片问答和文本节点生成；
- 文本转语音；
- 通过模型脚本适配非标准接口。

当前前端直接请求用户配置的 AI 服务，API Key 不经过本项目后端。

## 2. 启动与入口

本地开发：

```bash
cd infinite-canvas/web
bun install
bun run dev
```

当前项目端口为 `3522`，访问 `http://localhost:3522/`。

主要页面：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 首页 | `/` | 工作台入口 |
| 图片工作台 | `/image` | 文生图、图生图/改图 |
| 视频工作台 | `/video` | 文生视频、图生视频 |
| 无限画布 | `/canvas`、`/canvas/:id` | 节点式创作和编排 |
| 素材 | `/assets` | 查看本地生成素材 |
| 提示词 | `/prompts` | 管理提示词来源 |
| 配置 | `/config` | 渠道、模型和偏好设置 |

## 3. 首次配置渠道

打开右上角配置，新增或编辑一个渠道，填写：

1. **接口地址（Base URL）**：填写服务根地址，不要重复填写 `/v1`。项目的标准请求会自动补 `/v1`。
2. **API Key**：填写 sub2api 或其他兼容网关发放的密钥。
3. **调用格式**：选择 `OpenAI` 或 `Gemini`。
4. **模型列表**：可点击读取模型，也可以手工填写模型 ID。
5. **模型能力**：为每个模型指定 `文本`、`生图`、`视频` 或 `音频`。自动识别只是初始建议，必须以服务商实际能力为准。
6. **默认模型**：在偏好设置中分别指定图片、视频、文本、音频默认模型。

渠道模型的实际标识包含“渠道 + 模型名”，因此同名模型可以存在于多个渠道。

## 4. sub2api 一键填充

### 4.1 当前已经支持的 URL 格式

应用启动时会读取查询参数：

```text
http://localhost:3522/?baseUrl=<URL编码后的BaseURL>&apiKey=<URL编码后的APIKey>
```

参数名同时兼容大小写写法：`baseUrl`/`baseurl`、`apiKey`/`apikey`。

例如（仅示例，不要使用真实密钥）：

```text
http://localhost:3522/?baseUrl=https%3A%2F%2Fsub2api.example.com&apiKey=sk-demo
```

导入行为：

- 写入第一个渠道的 Base URL 和 API Key；
- 同步更新旧版顶层配置字段；
- 自动清理地址栏中的密钥参数；
- 打开配置面板并提示配置已导入。

### 4.2 一键跳转的实际边界

当前代码只负责“从 infinite-canvas 的 URL 接收配置”，并不会：

- 自动打开 sub2api 管理后台；
- 从 sub2api 查询或创建 API Key；
- 自动点击 sub2api 页面控件；
- 校验 sub2api 是否支持全部媒体接口。

因此可先由 sub2api 或外部门户生成跳转链接，再跳转到上面的 URL。若需要从 sub2api 页面点击按钮后自动返回并填充，后续需要新增集成按钮、回调 URL 或浏览器扩展逻辑。

### 4.3 安全要求

URL 中的 API Key 可能出现在浏览器历史、代理日志、服务器访问日志、Referer 或截图中。生产环境不要长期使用明文查询参数传递密钥。更稳妥的方案是：

- 使用一次性短期授权码，由 infinite-canvas 再交换 API Key；
- 使用同源后端生成短期配置令牌；
- 由用户在配置面板手工粘贴密钥；
- 至少使用 HTTPS，并避免把完整链接复制到聊天和工单系统。

## 5. 模型能力矩阵

| 能力 | UI 选择 | OpenAI 格式原生接口 | Gemini 格式原生接口 | 参考输入 |
| --- | --- | --- | --- | --- |
| 文本 | 文本模型 | `POST /v1/responses`，支持流式输出和推理强度 | `POST /v1beta/models/{model}:generateContent` | 文本消息，可包含图片用于图片问答 |
| 文生图 | 图片模型 | `POST /v1/images/generations` | `generateContent`，返回 `IMAGE` 模态 | 无参考图 |
| 图生图/改图 | 图片模型 | `POST /v1/images/edits`，multipart 文件上传 | `generateContent`，图片放入 `parts` | 参考图，可选蒙版（Gemini 不支持蒙版） |
| 文生视频 | 视频模型 | `POST /v1/videos` 创建任务，再轮询任务 | 原生路径不支持 | 无参考图 |
| 图生视频 | 视频模型 | `/v1/videos` 的 `input_reference` 文件或 JSON base64/data URI；数量和模式以模型能力为准 | 需模型脚本调用 Veo 等接口 | 参考图片 |
| 音频/TTS | 音频模型 | `POST /v1/audio/speech` | 原生路径不支持 | 文本输入 |

模型的“名称”不能代表真实能力。必须在渠道编辑器中手工确认能力；例如某些网关会使用自定义模型名。

## 6. 图片工作台

### 文生图

1. 进入 `/image`；
2. 输入提示词；
3. 选择图片模型；
4. 设置质量、尺寸/比例、透明背景和生成数量；
5. 点击生成。

OpenAI 兼容请求主要字段：`model`、`prompt`、`n`、`quality`、`size`、`background`、`output_format`。普通模型还会请求 `response_format=b64_json`，`gpt-image` 模型不发送该字段。

### 图生图/改图

把参考图片拖入参考区后生成，项目会改用 `/images/edits`。参考图以 multipart 的 `image` 字段上传；蒙版使用 `mask` 字段。Gemini 格式支持参考图，但当前不支持蒙版编辑。

尺寸限制：

- 宽高必须为正整数；
- 标准化尺寸宽高是 16 的倍数；
- 最长边不超过 3840px；
- 宽高比不超过 3:1；
- 总像素在 655,360 到 8,294,400 之间。

## 7. 视频工作台

### 文生视频

进入 `/video`，输入提示词并选择视频模型。时长、分辨率和比例应以 `GET /v1/models` 返回的模型能力为准，不要固定假设 6 秒或 20 秒上限。常用字段为 `seconds`/`duration`、`size`、`resolution`、`ratio`/`aspect_ratio`。

OpenAI 兼容接口支持 JSON 或 multipart。JSON 文生视频主要字段：

```text
model 或 model_id
prompt
seconds 或 duration
size
resolution
ratio / aspect_ratio
```

创建成功后轮询 `/videos/{taskId}`；完成时读取返回 URL，或从 `/videos/{taskId}/content` 下载内容。

### 图生视频

向视频工作台添加参考图片即可。原生接口可使用 `input_reference`、`reference_images` 或 `image`；multipart 上传文件，JSON 上传 base64/data URI，不要传公网 URL。需要首尾帧时设置 `reference_mode=frame`（最多 2 张），普通参考图使用 `asset`。参考图数量、音频输入（`input_audio`/`reference_audios`/`audio`）和时长必须遵循模型能力。网关必须真正支持视频创建、任务查询和结果下载三个环节，只有支持创建接口通常还不够。

## 8. 文本和图片问答

文本模型用于：

- 文本节点生成；
- 图片工作台中的图片问答；
- 画布助手和 Agent 对话。

文本请求使用 OpenAI Responses 或 Gemini `generateContent`，支持系统提示词；OpenAI 还可设置 `reasoning.effort` 为 `low`、`medium`、`high`、`xhigh`。图片问答会把图片作为 `image_url`/`input_image` 或 Gemini 图片 part 发送，因此 sub2api 的文本模型需要支持多模态时才能正常处理图片。

## 9. 音频/TTS

音频模型用于文本转语音。OpenAI 格式请求字段包括：`model`、`input`、`voice`、`response_format`、`speed`，可选附加指令。默认音色为 `alloy`，默认格式为 `mp3`。

Gemini 调用格式在原生实现中会明确提示不支持音频；如 sub2api 暴露的是 Gemini 或自定义音频接口，应为该模型配置模型脚本。

## 10. 非标准 sub2api 接口：模型脚本

当 sub2api 的路径、参数或返回值与上述协议不一致时，可在渠道编辑器中为模型编写脚本。脚本按模型能力保存，运行在浏览器中。

脚本可使用：

| 变量 | 说明 |
| --- | --- |
| `prompt` | 当前提示词 |
| `images` | 脚本运行时的参考图 data URL 数组；原生 `/v1/videos` 请求请映射到 `input_reference`/`reference_images` |
| `messages` | 文本对话消息数组 |
| `params` | 生成参数；视频含 `seconds`/`duration`、`size`、`resolution`、`ratio`/`aspect_ratio`、音视频参考等 |
| `model` | 不含渠道前缀的模型名 |
| `baseUrl` | 原样填写的渠道地址 |
| `apiKey` | 当前渠道 API Key |
| `http` | 自动附带 Bearer 鉴权的便捷请求 |
| `request` | 不自动加鉴权的原始请求 |
| `poll` | 异步任务轮询工具 |
| `onDelta` | 文本流式输出回调 |

脚本必须返回当前能力可识别的结果：图片为 URL/data URL 数组，视频为 URL 或 Blob，音频为 Blob/base64/URL，文本为字符串。

## 11. 配置和数据保存

- AI 配置保存于浏览器本地存储，键名为 `infinite-canvas:ai_config_store`；
- 画布、素材和生成记录主要保存在浏览器本地；
- 配置页支持 JSON 导入导出；
- WebDAV 同步是可选能力，不等于 sub2api 服务端托管；
- 清理浏览器站点数据会导致本地配置和未同步内容丢失。

## 12. 常见故障排查

| 现象 | 优先检查 |
| --- | --- |
| 401/403 | API Key、套餐权限、模型权限 |
| 404 | Base URL 是否多写或少写 `/v1`，路径是否被网关改写 |
| 无图片 | 模型是否真的支持图片输出，返回是否含 `data[].b64_json` 或 `url` |
| 视频一直等待 | 创建、查询、下载接口是否都可用；任务状态字段是否兼容 |
| Gemini 视频/音频不可用 | 当前原生实现明确不支持，改用 OpenAI 格式或模型脚本 |
| 模型列表为空 | `/v1/models` 或 `/v1beta/models` 是否需要鉴权，返回是否含 `data[].id` |
| 画布模型选择不到 | 模型能力标签是否标错，默认模型是否已分别指定 |
