# 01 业务边界与目标

## 1. 业务目标

AgentAPI 用于让代理快速开出一个独立品牌和独立域名的服务入口。代理不需要复制或维护 Sub2API 的核心代码，只需要管理自己的用户和预充值额度。

目标闭环：

```text
开站 → 分配域名 → 部署代理 → 用户注册 → 主站创建用户
    → 代理预充值 → 用户获得可消费额度 → 本地预授权
    → 主站唯一扣费 → 对账后代理查看余额和用量
```

## 2. 系统边界

### AgentAPI 内负责

- 代理站品牌、域名和页面配置；
- 代理管理员登录和管理；
- 代理用户注册入口；
- 代理用户与主站用户的 ID 映射；
- 充值页面、支付配置和充值订单镜像；
- 用户额度分配和展示；
- 调用主站受控接口；
- 代理侧审计和运营报表。

### Sub2API 主站负责

- 创建真实主站用户；
- 用户级身份、API Key 和 SuperKey 解析；
- 模型上游选择；
- 实际请求执行；
- 真实请求用量和成本；
- 代理主站预存额度；
- 按已拍板的桥接方案执行唯一的主站余额扣减、退款和冲正；
- 全局风控、封禁和系统审计。

### 明确不做

- 不在 AgentAPI 复制 Sub2API 的上游账号；
- 不在 AgentAPI 建立第二套模型网关；
- 不在浏览器传递管理员 Key、SuperKey 或主站用户 API Key；
- 不建立佣金、分成、佣金提现系统；
- 不允许代理直接修改主站数据库；
- 不允许通过修改前端余额绕过主站扣费；
- 第一版不实现任意自定义域名和复杂 DNS 托管。



## 3. 角色

| 角色           | 权限范围                                                 |
| -------------- | -------------------------------------------------------- |
| 平台超级管理员 | 创建/暂停代理、充值代理主站额度、撤销凭据、查看全局审计  |
| 代理管理员     | 管理自己的代理用户、分配允许范围内的额度、查看自己的用量 |
| 代理用户       | 使用代理站提供的模型能力、查看自己的余额和用量           |
| AgentAPI 服务  | 通过服务凭据调用主站控制接口和 `/v1`                     |
| 支付渠道       | 只通过签名回调改变订单状态，不直接操作余额               |



## 4. 关键业务规则

### 4.1 开站

- 域名必须全局唯一并经过规范化。
- 一个开站请求必须有幂等键。
- 开站只有在主站代理账户、代理服务、域名和健康检查全部成功后才进入 `active`。
- `failed` 的开站可以重试，不得重复创建主站账户或重复扣费。

### 4.2 注册

- 注册由 AgentAPI 接收，真实用户由主站创建。
- 创建成功后才写入 `agent_users` 映射。
- 主站创建成功、代理映射保存失败时，必须通过幂等重试或对账任务修复。
- 第一版同一个 `main_user_id` 不能绑定多个代理。

### 4.3 消费

- 用户请求必须同时能够解析 `agent_id` 和 `main_user_id`。
- 本地预授权与主站真实扣费必须有明确的桥接关系；方案 A 的主站扣费由代理管理员账户承担，方案 B 才由主站原子转移后按代理用户承担。
- 流式、异步、图片批处理等请求必须有冻结、结算或释放策略。
- 请求重试不得重复扣费。

### 4.4 停用

- 代理暂停后，新请求、充值和用户注册按策略拒绝。
- 已存在的用量和流水只读保留。
- 代理恢复后，不得恢复已撤销的凭据。

## 5. 数据归属原则

| 数据             | 权威系统                   | AgentAPI 是否缓存 |
| ---------------- | -------------------------- | ----------------- |
| 主站用户身份     | Sub2API                    | 只保存 ID 映射    |
| 代理用户映射     | AgentAPI                   | 是                |
| 代理域名状态     | 控制面/AgentAPI            | 是                |
| 代理管理员主站额度 | Sub2API 账务               | AgentAPI 保存可核对镜像 |
| 用户可消费子余额 | AgentAPI 预授权账本（最终扣费以主站为准） | 是 |
| 请求用量和成本   | Sub2API                    | 查询/报表缓存     |
| 支付订单         | 支付服务与主站订单         | 保存镜像          |
| 页面品牌         | AgentAPI                   | 是                |
