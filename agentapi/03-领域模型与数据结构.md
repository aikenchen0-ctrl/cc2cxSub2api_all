# 03 领域模型与数据结构

本文描述逻辑模型，不要求第一版严格使用同名物理表。主站真实扣费和用量始终属于主站账务边界；AgentAPI 的钱包表只承担方案 A/B 所需的预授权、分配和归属，不能凭空创造主站可消费额度。身份桥接见 [17-账务权威与主站扣费桥接](17-账务权威与主站扣费桥接.md)。

## 1. Agent

表示一个代理站和它在主站中的代理计费账户。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID/字符串 | 内部主键 |
| `code` | 字符串 | 稳定代理编号，全局唯一 |
| `name` | 字符串 | 展示名 |
| `owner_main_user_id` | 主站用户 ID | 发起开站或代理所有者 |
| `main_account_id` | 主站账户 ID | 代理预充值账户 |
| `status` | 枚举 | `pending/provisioning/active/suspended/failed/revoked` |
| `plan_id` | 字符串 | 允许的价格、模型和额度规则 |
| `created_at`/`updated_at` | 时间 | 审计字段 |

约束：`code` 唯一；`revoked` 不可复活；暂停和撤销必须写审计事件。

## 2. DomainBinding

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID | 主键 |
| `agent_id` | UUID | 所属 Agent |
| `hostname` | 字符串 | 规范化后的完整域名 |
| `kind` | 枚举 | `platform_subdomain/custom_domain` |
| `tls_status` | 枚举 | `pending/ready/failed/expired` |
| `status` | 枚举 | `pending/active/disabled` |
| `verified_at` | 时间 | 域名验证时间 |

约束：`hostname` 全局唯一；自定义域名必须完成所有权验证后才能激活。

## 3. AgentUserMapping

AgentAPI 用户与主站真实用户的一对一映射。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID | 代理侧主键 |
| `agent_id` | UUID | 所属 Agent |
| `main_user_id` | 主站用户 ID | 真实业务身份 |
| `proxy_user_id` | UUID | AgentAPI 本地映射 ID |
| `status` | 枚举 | `pending/active/disabled/deleted` |
| `provision_request_id` | 字符串 | 创建幂等键 |
| `created_at`/`updated_at` | 时间 | 审计字段 |

推荐唯一约束：

```text
unique(agent_id, main_user_id)
unique(agent_id, proxy_user_id)
```

第一版还应在主站或控制面保证一个 `main_user_id` 不归属于多个 Agent。

## 4. AgentWallet

代理管理员主站预存额度的 AgentAPI 镜像账户；主站余额是最终权威。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `agent_id` | UUID | 一个 Agent 一个主账户 |
| `currency` | 字符串 | 例如 `CNY` |
| `available` | 十进制定点 | 可消费额度 |
| `frozen` | 十进制定点 | 流式/异步请求冻结额度 |
| `status` | 枚举 | `active/frozen/closed` |
| `version` | 整数 | 乐观锁版本 |

金额必须使用定点整数（例如分）或数据库 Decimal，不使用浮点数。

## 5. AgentUserWallet

代理用户在代理额度中的本地预授权子余额；主站实际扣费仍按已拍板的桥接身份执行。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `agent_id` | UUID | 所属 Agent |
| `main_user_id` | 主站用户 ID | 用户身份 |
| `available` | 十进制定点 | 可消费余额 |
| `frozen` | 十进制定点 | 已预留但未结算金额 |
| `status` | 枚举 | `active/frozen/closed` |
| `version` | 整数 | 并发控制 |

业务约束：

```text
agent_user_wallet.available >= 0
sum(agent_user_wallet.available) <= agent_wallet.available + 已分配冻结额度
```

如果第一版不需要独立分配用户余额，可以将用户余额作为 AgentWallet 的带用户维度子账本，但仍必须保留用户维度的流水。

## 6. WalletLedger

所有充值、消费、退款、调整必须追加流水，不直接覆盖历史金额。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID | 流水 ID |
| `agent_id` | UUID | 所属代理 |
| `main_user_id` | 可空 | 用户维度流水；代理充值时为空 |
| `type` | 枚举 | `agent_recharge/user_recharge/reserve/consume/release/refund/adjustment` |
| `amount` | 定点数 | 正数代表入账，负数代表扣减，或使用 debit/credit 两列 |
| `balance_before`/`balance_after` | 定点数 | 账前账后快照 |
| `request_id` | 字符串 | 消费幂等键 |
| `order_id` | 字符串 | 充值/退款订单号 |
| `external_id` | 字符串 | 支付渠道或上游引用 |
| `status` | 枚举 | `pending/posted/reversed/failed` |
| `created_at` | 时间 | 写入时间 |

唯一约束建议：`(agent_id, type, request_id)` 或单独的业务幂等表。

## 7. RechargeOrder

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID | 内部订单 ID |
| `order_no` | 字符串 | 对外订单号，全局唯一 |
| `agent_id` | UUID | 收款代理 |
| `main_user_id` | 主站用户 ID | 充值用户，可空（代理预存时为空） |
| `amount` | 定点数 | 应付金额 |
| `currency` | 字符串 | 货币 |
| `provider` | 字符串 | 支付渠道 |
| `status` | 枚举 | `created/pending/paid/failed/closed/refunded` |
| `provider_trade_no` | 字符串 | 渠道交易号 |
| `idempotency_key` | 字符串 | 创建幂等键 |
| `paid_at` | 时间 | 支付确认时间 |

## 8. UsageAttribution

主站现有用量记录需要能够关联代理来源：

```text
usage_id
agent_id
proxy_user_id
main_user_id
billing_main_user_id
api_key_id（如有）
request_id
model
quantity/token/media_usage
charged_amount
provider_cost
status
```

不建立佣金字段；`charged_amount` 是本次实际扣减，`provider_cost` 用于主站成本分析。

## 9. ServiceCredential

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID | 凭据 ID |
| `agent_id` | UUID | 所属代理 |
| `kind` | 枚举 | `control/model_relay` |
| `secret_ref` | 字符串 | 密钥管理系统引用，不保存明文 |
| `scopes` | JSON | 允许接口列表 |
| `status` | 枚举 | `active/revoked/expired` |
| `last_used_at` | 时间 | 最近使用时间 |
| `expires_at` | 时间 | 过期时间 |

全局管理员 Key 不应写入该表；过渡阶段可以只存密钥引用和轮换记录。

## 10. AuditEvent

所有高风险操作至少记录：

```text
actor_type
actor_id
agent_id
operation
target_type
target_id
request_id
result
reason
created_at
```

日志中不得写入管理员 Key、支付密钥、SuperKey、用户密码或完整 Authorization 头。
