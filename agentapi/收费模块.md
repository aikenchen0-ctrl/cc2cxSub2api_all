# 代理站收费模块

日期：2026-10-04。

本文按当前代码记录。站长收费配置、渠道、套餐和订单都存在本站数据库，并且每条记录都带 `agent_id`。

## 谁收费

用户在代理站付款，钱进入该站站长自己配置的支付渠道。支付确认后，额度记入该用户在本站的钱包。之后这个用户调用模型时，主站从站长账户扣实际费用，不从该用户的主站余额再扣一笔。

站长没有开通收费时，充值页不能创建订单。

## 站长配置

站长入口是系统设置里的「支付设置」，地址 `/admin/settings?tab=payment`。界面沿用 Sub2API 支付设置：支付开关、限额、手续费、汇率、取消频率、支付宝选项、帮助图文，以及可拖拽的服务商实例。接口在 `/api/v1/agent/admin/billing`，只接受当前租户的站长 Session。

收费设置包括：开关、最低和最高金额、每日限额、订单超时、待支付上限、手续费率、余额到账倍率、订阅美元兑人民币、渠道分配、商品名、开放的支付方式、支付宝显示开关、说明文字和说明图片。

支付渠道支持 `easypay`、`alipay`、`wxpay`、`stripe`、`airwallex`。每个渠道保存名称、启用状态、支付模式、排序、支持的支付方式、限额 JSON、退款开关和渠道密钥。密钥加密后只存在服务端，列表接口不返回密钥明文。

套餐保存名称、价格、原价、币种、有效期、特性和是否在售。订单保存金额、支付方式、渠道、状态和所属用户。取消和退款只作用于本站订单。

另一个站长读取渠道、套餐或订单时，看不到本站记录。

### 支付设置功能范围

| 区域 | 已接入功能 |
| --- | --- |
| 总开关与展示 | 启停本站支付、商品名前后缀及预览、帮助图片和说明文字、配置指南 |
| 金额与到账 | 充值最低/最高金额、每用户每日限额、余额充值倍率、订阅 CNY 换算汇率、手续费率 |
| 订单与分配 | 支付超时、每用户待支付订单上限、轮询/最小当日交易额渠道选择 |

| 支付宝选项 | 强制二维码、移动端当面付唤起；移动端唤起优先，失败保留二维码及重试入口 |
| 服务商管理 | 五类服务商开关、新增/编辑/删除/刷新、启停实例、支持方式、退款/用户退款、拖拽排序 |

| 支付宝官方 | App ID、商户私钥、支付宝公钥、默认扫码/跳转模式 |

### 数据隔离与下单规则

- 租户和用户由本站 Session 决定，忽略请求体/查询参数中的 `agent_id`、用户或付款人选择；跨租户渠道 ID 返回 404。匿名和普通成员不能修改管理配置。
- 支付配置、加密商户凭据、订单、实例限额、取消次数和钱包记录均按 `agent_id` 隔离。回调路径由服务端生成 `/api/v1/agent/billing/webhook/{agent_id}/{provider}`，复制另一站的配置也不会保留其租户路径。
- 每用户每日额度按「本站 + 当前用户」统计，跨支付方式合并；实例每日额度按「本站 + 实例 + 支付方式」统计，Stripe 共用实例额度。到期未付款订单不占额度。当前日界线按服务端 UTC 零点计算。
- 下单和支付配置变更使用本站独立的数据库租约，串行执行限额检查和订单预留。先记录订单，再请求服务商，避免快速回调找不到订单；创建失败保留失败订单且不回传 SDK 内部错误或密钥。
- 全局充值金额限制应用于输入充值金额；实例限额应用于含手续费的应付金额。手续费按币种最小单位向上取整（如 JPY/KRW 为整数）。订阅汇率仅在所选服务商币种为 CNY 时应用。
- 多实例同一方式允许轮询或最小交易额选择。同一方式币种冲突时采用首个排序实例的币种，不在支付过程中静默切换币种。Stripe 收银台使用本次选中实例的公开密钥。
- 存在有效待支付或处理中订单时，禁止删除渠道、替换商户凭据或移除订单需要的支付方式；名称、排序和停用新单等安全操作仍可执行。
- 回调校验签名、商户身份（SDK 提供时）、本站订单、渠道实例、金额和币种。跨站通知不入账，重复通知幂等；Stripe/Airwallex 签名头兼容 HTTP 大小写规范。
- 浏览器不共享可变回调路径。切换站点/用户或退出会话时清理旧付款恢复信息；SVG 上传预览经过净化。

自动化验证覆盖两个站长和普通成员的访问边界、配置局部更新、密钥保留/加密、未完成订单保护、并发待支付上限、每用户限额、汇率/币种手续费、五类表单、自定义方式、早到/重复/跨站回调及带签名的 Stripe/Airwallex 通知。外部服务商实际支付和退款仍需各站长使用自己的测试商户联调；本次不产生真实交易。

## 用户付款

充值页读取 `GET /api/v1/agent/payment/checkout-info`。返回的支付方式和套餐来自当前站点，不读取主站收银台。

创建订单走 `POST /api/v1/agent/payment/orders`。浏览器不能指定用户或站点。EasyPay 会按该站保存的 `pid`、`pkey` 和 `apiBase` 生成支付地址。回调地址是 `/api/v1/agent/billing/webhook/{agent_id}/easypay`，签名用该站自己的密钥校验。验签通过后，只给这笔订单所属用户增加本站钱包额度，重复通知不会再次入账。

支付宝、微信、Stripe、Airwallex 和易支付都使用该站自己保存的密钥发起支付和校验回调。回调地址带当前 `agent_id`，验签失败不会入账。

## 模型扣费

本站收费开通后，模型请求仍带当前用户的 `X-Sub2API-On-Behalf-Of`，另外带站长的 `X-Sub2API-Payer`。主站只从站长余额扣实际费用。用户本站钱包不大于 0 时，请求直接拒绝。
