# 代理站规划

## 不变的业务边界

Sub2API 是唯一上游与真实用户、余额、计费记录的数据源。AgentAPI 是独立中间服务，记录本站用户归属、本站 API Key、品牌配置及主站用量副本。站长是主站普通用户，只在自己的代理站具有管理权限；不得获得主站管理员权限。

代理站不承载主站全局运维能力。分组管理、账号管理、代理管理、兑换码管理、插件管理、安全审计（风险控制与提示词审计）和上游核验不属于 AgentAPI 产品范围，前后端均不得暴露对应入口或 API。普通用户兑换功能可保留，但代理站站长没有兑换码发行与管理权限。

注册先在主站创建普通用户，再保存本站归属。客户端通过代理站 URL + 代理 Key 调用，代理站解析真实用户身份并转发主站，费用由主站记入对应用户。站点之间的用户列表、Key、品牌和调用记录互相隔离。每站支持独立 logo/title。

## 执行计划与验收证据

1. 注册可靠性：管理员接口固定普通用户权限；限流；主站创建与本地映射部分失败可恢复，不重复建号、不冒领已有主站用户。检查接口测试和故障注入测试。
2. 本站管理：用户列表、状态、品牌、模型权限、下属用户 Key 创建/撤销、操作日志。检查非管理员、外站用户和跨站 Key 的拒绝测试及界面，并检查被排除的主站模块不存在路由、菜单和服务端端点。
3. 模型与计费：验证代理 Key → 对应主站用户 → 主站计费；本地只记录主站事实；流式和异步任务使用同一身份；同步失败不重复调用或重复扣款。
4. 中间层查询：余额、请求明细和统计明确来源及覆盖范围，缺失数据不显示为零；管理员凭据不出现在浏览器、响应和日志。
5. 部署与文档：现有 SSO、三天 Session、公开 LINK 充值地址、可信服务端密钥管理、幂等升级策略和配置一致。
6. 完整验收：后端全套、前端全套、构建、主站接口契约、真实环境端到端及浏览器操作。逐项验证后才宣布可正式使用。
