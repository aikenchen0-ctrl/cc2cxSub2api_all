# 00 设计基线与决策

## 1. 核心定义

AgentAPI 是“代理站中间层”，不是 Sub2API 的副本，也不是一个在主站内部复制出来的第二套账务系统。

```text
用户
  ↓
AgentAPI（页面、代理运营、支付入口、用户映射）
  ↓ HTTPS API
Sub2API 主站（真实用户、模型、额度、用量、账务）
```

代理站的域名是用户访问入口；主站的用户 ID、模型网关和账务流水是事实来源。

## 2. 已锁定的决策

### 2.1 部署和代码边界

- AgentAPI 作为独立项目和独立 Docker 服务运行。
- 构建一个通用 AgentAPI 镜像，通过环境变量或密钥文件绑定代理身份。
- 不复制 Sub2API 的后端、数据库和上游账号。
- AgentAPI 通过主站 API 完成用户创建、用户设置、额度和用量查询。
- 主站不直接读取 AgentAPI 数据库；AgentAPI 不直接读写主站数据库。

### 2.2 用户身份

- 用户注册入口在 AgentAPI，但真实用户记录创建在 Sub2API 主站。
- AgentAPI 保存 `main_user_id` 映射。
- 第一版规定一个主站用户只能归属于一个代理站，避免跨代理计费歧义。
- 用户密码、SuperKey、主站 JWT、用户 API Key 不复制到 AgentAPI 数据库。

### 2.3 账务

- 采用“代理预充值额度”方案：代理先向主站预存额度。
- 代理用户拥有代理侧的可消费子余额，但子余额不能超过代理主站额度。
- 用户请求时先从代理用户子余额预授权并记录本地流水；本版本已冻结为 [17-账务权威与主站扣费桥接](17-账务权威与主站扣费桥接.md) 的方案 A：由 `agent_owner_main_user_id` 承担主站唯一真实扣费，本地流水按主站 usage 对账。
- 不建立佣金、分成、差价和佣金提现业务。
- 主站仍记录实际成本和请求用量，但这些记录不转换成佣金。

### 2.4 凭据

- 全局管理员 Key 只在受控的 AgentAPI 服务端使用，不能进入浏览器、URL、日志或镜像层。
- 生产环境应逐步替换为每个代理独立、可撤销、限权限的服务凭据。
- 模型请求使用仓库公共层规定的服务凭据和用户身份头，不使用管理员 Key。

### 2.5 协议

- 不新增一套浏览器 SSO 或 API Key 传递协议。
- 若 AgentAPI 接入主站菜单，沿用公共 HMAC SSO 和 3 天 Session 约束。
- 模型公开名遵循 `docs/卫星公开模型.md`。

## 3. 重要术语

| 术语 | 含义 |
| --- | --- |
| 主站 | 当前 Sub2API，负责真实用户、模型网关和账务 |
| AgentAPI | 独立代理站应用 |
| Agent | 一个代理站及其主站账户、域名、额度配置 |
| `agent_id` | AgentAPI 与主站之间的代理唯一标识 |
| `main_user_id` | Sub2API 主站真实用户 ID |
| `proxy_user_id` | AgentAPI 自己的用户映射 ID，不替代主站 ID |
| 代理主站额度 | 代理预存给主站、允许实际消费的额度 |
| 代理用户子余额 | 代理分配给某个用户的可消费额度 |
| 主站服务凭据 | AgentAPI 服务端调用主站 API 的凭据 |
| 管理员 Key | 主站全局控制凭据，只能服务端保管 |

## 4. 不可违反的账务不变量

```text
代理用户子余额 >= 0
代理可用额度 >= 0
所有消费必须有唯一 request_id
所有充值必须有唯一 order_id
消费总额不得超过用户子余额和代理可用额度
主站真实扣费只能发生一次，并且必须能与本地 request_id/usage_id 对账
退款必须通过反向流水，不得修改历史流水
```

## 5. 尚未锁定的决策

以下事项在实现前必须拍板，文档中的默认建议是第一版取值：

| 事项 | 第一版建议 | 影响 |
| --- | --- | --- |
| 用户支付是否自动增加代理主站额度 | 不自动；代理先预存，用户支付作为代理侧收款记录 | 避免外部支付回调直接形成主站额度 |
| 代理部署形态 | 一个通用镜像，每个代理独立实例 | 隔离清晰，运维略复杂 |
| 自定义域名 | 首版只支持平台分配的子域名 | TLS 和域名验证更简单 |
| 用户是否允许直连主站 | 默认不允许或只读 | 防止绕过代理额度 |
| 价格策略 | 使用主站统一价格 | 没有佣金和差价歧义 |
| 支付渠道 | 先接一个可验证回调的渠道 | 减少支付状态分支 |
| 主站扣费身份 | 已冻结为方案 A：代理管理员主站账户 | 若未来要求主站按代理用户原生统计，必须单独立项切换方案 B |
