# AgentAPI 接手文档

最后更新：2026-10-27

本文面向继续维护 AgentAPI 前端界面的开发者，记录当前视觉体系、页面入口、验证方式和不能突破的业务边界。修改前同时阅读仓库根目录 `AGENTS.md`、[README.md](README.md) 与 [收费模块.md](收费模块.md)。

## 1. 当前定位

- AgentAPI 是 Sub2API 的共享多租户代理站，不是每个站点独立容器。所有租户共用同一套前端、后端和数据库。
- 浏览器只使用本站 HttpOnly 会话和个人 `sk-*` Key；不得接触 SuperKey、主站 JWT、应用凭据或运行时控制凭据。
- 当前 Compose 为单副本 SQLite 部署。收费、余额和真实用量以 Sub2API 同步结果为准，前端不得用估算值冒充实际值。
- `sub2api-cost-console/` 仅作代码参考，不属于 AgentAPI 部署范围，也不应把它的 PostgreSQL / Redis 引入本项目。

## 2. 技术栈与启动

- Vue 3 + TypeScript + Vue Router + Pinia
- Vite 5 + Tailwind CSS 3 + driver.js
- 入口：`frontend/src/main.ts`
- 路由：`frontend/src/router/index.ts`
- 开发：`cd agentapi/frontend && pnpm dev`
- 生产构建：`pnpm build`，输出到 `agentapi/backend/web/`

依赖安装使用仓库现有 `pnpm-lock.yaml`，不要单独更换包管理器或批量升级依赖。

## 3. 白金视觉体系

界面的目标风格是“暖白 + 金色、浅色、深色”，不是冷蓝灰后台。

### 3.1 颜色与层次

- 浅色画布：暖白 `#fbfaf7`；卡片使用白色或 `white/75` 到 `white/90`。
- 深色画布：暖黑 `#0e0c09`；卡片使用 `dark-900` / `dark-900/70`，边框使用暖金低透明度。
- 金色主色：`primary-300` 到 `primary-600`；高亮按钮使用金色渐变，文字保持深色以保证对比度。
- 中性色：优先使用 `accent-*` 和 `dark-*`。新代码不要继续引入 `slate-*` 冷灰。
- 状态色只表达语义：成功用 emerald、警告用 amber、错误用 red；不要把状态色当作装饰主色。

设计令牌定义在：

- `frontend/tailwind.config.js`
- `frontend/src/style.css`

### 3.2 主题切换

- 主题由 `<html class="dark">` 控制，Tailwind 使用 `darkMode: 'class'`。
- 实现在 `frontend/src/agent/theme.ts`。
- 偏好统一保存到 `localStorage.theme`；旧键 `localStorage.agentapi_landing_theme` 与 `sessionStorage.agentapi_theme` 会在读取时一次性迁移并删除，避免历史首页与控制台主题冲突。
- `frontend/public/theme-init.js` 在应用脚本前应用主题，防止首屏浅色闪烁；新增页面不得再创建独立主题键。
- 未手动选择时跟随系统 `prefers-color-scheme`。
- 同步更新 `meta[name="theme-color"]`：浅色 `#fbfaf7`，深色 `#0e0c09`。
- 侧栏、控制台顶部栏、营销首页和认证页都提供主题切换；新增独立页面时不要只做浅色。
- 首页、登录页和控制台共用 `localStorage.theme`，不得再引入独立的落地页主题键。`ReferenceLanding.vue` 直接读取 `frontend/src/agent/theme.ts` 的 `isDark` / `toggleTheme`。2026-10-27 17:27 公网版本已实测首页、登录页与控制台浅深主题一致，toolbar 切换后进入 `/keys` 仍保持。

### 3.3 常用视觉组件

- `btn btn-primary`：金色主操作。
- `btn btn-secondary`：白底/暖黑底描边操作。
- `card`、`card-body`、`card-header`：统一圆角、边框和阴影。
- `input`、`input-label`、`input-hint`：统一表单层级。
- `badge badge-primary`：金色轻量状态标签。
- 新手引导样式：`frontend/src/styles/agent-onboarding.css`，弹窗按钮也必须是金色，不能回退到默认蓝紫。

## 4. 页面结构与入口

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 默认营销首页 | `frontend/src/components/home/ReferenceLanding.vue` | 默认长首页，包含能力、计费、下载、FAQ 等区块 |
| 简洁首页 | `frontend/src/views/AgentHomeView.vue` | 租户开启简洁首页时使用；支持自定义 URL / HTML 的沙箱 iframe |
| 认证布局 | `frontend/src/components/layout/AuthLayout.vue` | 登录、注册、找回密码等共用；右上角有主题切换 |
| 控制台外壳 | `frontend/src/components/layout/AppLayout.vue` | 侧栏、顶部栏和内容区 |
| 顶部栏 | `frontend/src/components/layout/AgentAppHeader.vue` | 页面标题、余额、公告、主题切换、用户菜单 |
| 侧栏 | `frontend/src/components/layout/AgentAppSidebar.vue` | 用户/站长菜单、主题切换、折叠状态 |
| 用户总览 | `frontend/src/views/AgentDashboardView.vue` | 白金欢迎区、余额统计、用量分析、最近用量、快捷操作 |
| 站长仪表盘 | `frontend/src/views/admin/dashboard/AgentAdminDashboardView.vue` | 本站请求、令牌、费用与结算快照 |
| 用量记录 | `frontend/src/views/AgentUsageView.vue` | 请求明细、费用来源、结算状态 |
| API 密钥 | `frontend/src/views/user/AgentAPIKeysView.vue` | 个人 Key 管理与调用地址 |

首页模式优先级：

1. 租户配置了合法的外部 URL 或完整 HTML 时，使用隔离 iframe。
2. 否则若 `compact_home_enabled` 为真，使用简洁白金首页。
3. 否则使用 `ReferenceLanding.vue`。

自定义 HTML 必须在无 `allow-same-origin` 的沙箱中运行；外部 URL 只允许 `http:` / `https:`，不得带用户名或密码。

- 用户总览已改为不重复页面标题的白金欢迎区，并统一了统计卡、最近用量、空状态和计费说明。
- 简洁首页已升级为带金色光晕、网格、品牌徽章、双 CTA 和移动端适配的落地页。
- 认证页已加入显式浅色/深色切换。
- 首页、登录页和控制台已统一使用全局主题状态；控制台顶部栏可直接切换浅色/深色，切换后跨页面保持。营销首页不再维护独立主题键。
- 共享入口已恢复主站邮箱密码表单，同时保留主站 SSO；登录页按 `registration_enabled` 显示或隐藏注册入口。
- 站长域名通过 `AGENTAPI_ENTRY_TENANTS=host=agt_...` 绑定。绑定域名的未登录请求解析到该站长的租户；注册用户在主站写入 `agent_shared_tenant_members`（角色固定为 `member`），在本站写入 `agent_users`，不会获得站长权限。主站 SSO 对已有成员优先返回其所属租户。
- 用量页、API 密钥页和未知平台标签已清理 `slate-*` 冷色。
- driver.js 新手引导弹窗使用白金配色，并同时覆盖深色模式。

## 6. 验证方式

### 6.1 类型、测试与构建

在 `agentapi/frontend/` 执行：

```powershell
pnpm typecheck
pnpm test:run
pnpm build
```

2026-10-27 最近一次结果：

- `pnpm typecheck`：通过。
- `pnpm test:run`：67 个测试文件、337 项测试全部通过。
- `pnpm build`：通过，产物写入 `agentapi/backend/web/`。

### 6.2 隔离视觉验收

前端自带一套只用于视觉检查的本地 fixture，不连接生产数据库或上游：

```powershell
cd agentapi/frontend
node scripts/preview-home.mjs
```

另开终端：

```powershell
node scripts/capture-home-preview.mjs
```

默认地址为 `http://127.0.0.1:18419`。脚本会检查横向溢出，并输出首页、设置页和移动端截图到临时目录。需要本机 Chrome。

手工验收至少覆盖：

- 1440px 桌面浅色与深色。
- 390px 移动端浅色与深色。
- 首页、登录页、用户总览、站长仪表盘。
- 侧栏折叠与移动菜单。
- 新手引导弹窗在其首次出现时不再显示蓝紫按钮。

## 7. 修改约束

- 不要为了界面改动新增容器、端口、数据库或部署单元。
- 不要移除租户品牌、SSO 入口、中文文案或已有 `data-testid` / `data-tour` 语义，除非同步修复测试和无障碍替代。
- 不要在前端拼接、打印或持久化服务端凭据。
- 不要把待确认费用显示成 0，也不要用余额差估算冒充真实单次费用。
- 不要用 `sub2api-cost-console/` 的部署配置覆盖 AgentAPI 现有配置。
- 保留已有租户数据、菜单权限和 404 退役路径行为。

## 8. 建议的后续工作

- 逐页检查剩余业务页的浅色/深色对比度，尤其是表格、支付弹窗和站长设置。
- 为图表补充金色、香槟色、暖棕色的可访问配色，避免只靠颜色区分数据系列。
- 若新增主题令牌，先改 `tailwind.config.js` 与 `style.css`，再在页面中使用，避免散落硬编码色值。
- 每次完成可见改动后更新本文的“最后更新”和“当前界面状态”，并重新执行完整验证。
