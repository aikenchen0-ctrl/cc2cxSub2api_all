# 主站前端迁移计划

> 2026-09-30 边界修订：AgentAPI 定位为代理站，分组管理、账号管理、代理管理、兑换码管理、插件管理、安全审计（风险控制与提示词审计）和上游核验已从当前产品中删除。本文后续批次中关于这些模块“已迁入”的内容仅保留为历史实施记录，不代表当前版本能力，也不得作为恢复入口的依据。普通用户 `/redeem` 仍保留，站长兑换码管理不保留。

## 目标与权限边界

以本仓库 sub2api/frontend 为界面来源，迁入首页、左侧菜单、顶部栏、右侧面板、组件与页面交互，而非另做一个简化代理控制台。站点 logo/title 读取当前代理站品牌数据。

前端复用不意味着复制主站权限：代理站管理员只管理本站配置和本站用户，不获得主站管理员身份。主站账号、渠道、支付、系统安全等全局配置不得通过代理站修改。所有写接口须在服务端验证代理站与对象归属；不能只靠隐藏菜单。

用户注册先在主站创建普通用户，再记录本站归属；模型请求上游只有主站，余额、扣费、用量事实以主站为准。代理站记录和同步事实，不建立第二套计费。主站管理员凭据仅部署端持有，不能复制主站浏览器 JWT 客户端实现。

### 当前剩余工作（2026-09-30）

- **部署与真实联调**：自动化测试、类型检查和生产构建不能替代生产域名、反向代理、Cookie、OAuth/支付回调、真实主站余额与计费回写的端到端验证。
- **浏览器视觉验收**：第 109 批已通过本机无头 Chrome 完成简洁首页、系统设置及自定义 HTML 的局部截图和真实表单保存检查；仍需对主站与代理站逐页并排检查深浅主题、长文案、输入法、弹层、分页、窄屏和加载/错误状态。局部测试数据验收不等于整站真实数据验收。
- **资金规则**：优惠码真实发行、扣账与核销仍没有已确认的代理站资金协议，当前只展示租户安全的只读状态和禁用入口，不伪造本地余额或订单事实。
- **国际化**：主站式语言切换需要先完成全站文案 i18n 化，当前不能只放一个无效切换按钮冒充迁移完成。
- **权限边界复核**：账号、插件、代理池、主站全局支付配置等页面只可展示授权后的本站运行事实；没有租户隔离写接口的能力继续保持只读或明确禁用。

## 实施顺序

1. 迁入公共布局、首页、图标、认证外框；建立品牌、路由权限和菜单回归测试。
2. 逐页迁移用户总览、Key、用量、资料与站长用户管理，复用主站原生组件，替换数据适配层。
3. 为尚缺的本站管理能力补充租户隔离服务端接口，再接入原生前端页面；不复制全局管理员 API 客户端。
4. 逐项处理模型、订阅、订单及其他页面，明确来源和权限。不以隐藏未实现菜单作为全部迁移完成的证明。
5. 主站/代理站并排浏览器视觉验收；双站长测试 logo/title、用户、Key、记录及配置互不影响。再验证注册→Key→代理 URL→主站扣费→本站同步完整链路。
