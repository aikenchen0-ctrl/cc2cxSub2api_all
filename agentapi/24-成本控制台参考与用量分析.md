# 成本控制台参考与用量分析

更新日期：2026-09-28。

## 已落地的复用

参考 `sub2api-cost-console/frontend/src/features/cost-center/` 的 `dataState.ts`、`usageWindow.ts`、`modelCostAnalysis.ts`，按 AgentAPI 的安全边界重新实现，不复制主站管理员控制台和浏览器管理员凭据。

- 新增 `GET /api/v1/agent/usage/insights?window=24h`，支持 1h、24h、7d、30d 滚动窗口；同一响应所有维度共用精确的 `[start,end)` 窗口。
- 服务端按实例 agent_id 限定；普通用户再按 Session 对应的 proxy_main_user_id 限定；本站管理员只能汇总本站，不能传入其他用户或站点扩大权限。
- 汇总请求、输入/输出/缓存令牌、标准费用、已报告实际费用，按模型和时间分桶，提供已观测路由不一致计数。
- 金额累计保留主站整数纳美元，不按模型价格重新推算收费。实际费用未报告时不使用标准费用伪装实际费用；余额差额估算不进入实测统计。
- 区分无记录、实测、部分可用、读取失败；展示缺失记录数、缺失实际费用数、待确认数。窗口切换采用请求序号保护，旧请求不能覆盖新窗口。
- 余额读取失败时首页显示“暂不可用”，不显示本地钱包余额作为主站余额。

## 数据来源与覆盖范围

当前来源明确为 `local_main_usage_snapshots`：AgentAPI 请求通过现有服务端 MainClient 查询主站单次请求用量后留存的安全字段。聚合查询不分页、不截断记录，不是只统计当前列表页。

该统计**不是实时查询主站全部历史**，时间按本站请求创建时间，不按主站入账时间。主站目前公共卫星 usage 接口要求 request_id，因此不宣称覆盖用户在主站直连、其他代理站或未留存的历史请求。刷新统计只重读已有快照，不强制触发结算或全量同步。未取得主站明细的请求明确保留为未观测。

## 尚未完成，不应宣称全量复用

- 管理员 API 创建主站用户、全量历史分页同步、按用户查询远程统计，需要明确授权范围并沿用现有服务端鉴权；不能直接复制参考项目的浏览器主站管理员 JWT。
- 参考项目的上游账号采购、库存、封禁损失、全站调度、利润预测属于主站管理，不向代理站站长开放，也不以用户费用冒充供应商成本或代理利润。
- 旧版结算预留上限、跨用户幂等键冲突、注册策略和代理站管理员管理下属用户 Key 等此前审查问题仍需单独处理；本次统计实现不代表整个代理站逻辑已完善。

## 验证

新增后端测试覆盖实例/用户隔离、窗口起点包含/终点排除、缺失实际费用、真实零费用与估算区别；前端测试覆盖部分数据提示、失败不显示零总额和窗口响应乱序保护。上线还需真实 Sub2API 联调与浏览器验收。
