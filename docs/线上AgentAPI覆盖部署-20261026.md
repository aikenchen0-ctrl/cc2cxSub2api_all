## 回滚

只回退应用镜像和 Compose：

```bash
docker compose -p cc2cx-source \
  -f /opt/cc2cx-production/release-20261009/agentapi.compose.json \
  up -d --no-deps --no-build --force-recreate agentapi
```

旧镜像也可通过 `cc2cx-backup/agentapi:20261026-1103` 使用。本次新版本已执行数据库列迁移；如果业务需要恢复到部署前状态，应在维护窗口评估并恢复 `agentapi-before-20261026-1103.db` 或数据卷快照。不要用直接覆盖正在运行的 SQLite 文件代替一致性恢复。
