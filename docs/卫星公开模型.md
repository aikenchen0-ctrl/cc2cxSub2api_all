# 卫星公开模型

给后续 AI / 开发者用。卫星调 Sub2API **只发这里的公开模型名**，不要发明第三套名字。

对照：

- 接入协议：`docs/卫星应用接入公共层.md`
- 上游适配原料：`docs/模型适配.md`
- 代码目录：`sub2api/backend/internal/domain/satellite_models.go`

SuperKey 仍在网关内部跨分组选号。卫星进程里出现的只是公开名。

## 运行身份约束（八个卫星统一）

公开模型请求必须由卫星服务端从当前 HttpOnly Session 得到 Sub2API 用户身份，再携带 `SUB2API_APP_CREDENTIAL`、`X-Sub2API-On-Behalf-Of` 和 `X-Sub2API-Satellite` 调用 `/v1`。不得在浏览器、URL、localStorage、请求体或普通 `Authorization` 中传递 SuperKey/用户 API Key；没有 Session 身份时不得回退到共享 Key 或默认用户。

## 1. 三个默认（点菜单就能用）

| 能力 | 接口 | 默认公开名 |
| --- | --- | --- |
| 文本 | `POST {LINK}/v1/chat/completions` 或 `/v1/responses` | `gpt-5.5` |
| 图片 | `POST {LINK}/v1/images/generations`、`/v1/images/edits` | `gpt-image-2` |
| 视频 | `POST {LINK}/v1/videos`，轮询 `GET {LINK}/v1/videos/{id}` | `grok-imagine-video-1.5` |

鉴权三个头（见公共层）：

```http
Authorization: Bearer <SUB2API_APP_CREDENTIAL>
X-Sub2API-On-Behalf-Of: <Sub2API 用户 ID>
X-Sub2API-Satellite: <slug>
```

## 4. 各项目现在发什么

| slug | 文本 | 图片 | 视频 | 说明 |
| --- | --- | --- | --- | --- |
| canvas | `gpt-5.5` | `gpt-image-2`、`grok-imagine-image-1.5` | `grok-imagine-video-1.5`、`seedance-2.0`、`kling-v3` | 画布同时做对话、生图、生视频 |
| ju | `gpt-5.5` | `gpt-image-2` | `grok-imagine-video-1.5`、`seedance-2.0`、`kling-v3` | 剧场以视频为主，图只用默认档 |
| livart | `gpt-5.5`（仍允许 `gpt-5.4-mini`） | `gpt-image-2` | — | 产品是对话 + 生图，没有视频工作台 |
| ppt | `gpt-5.5` | `gpt-image-2` | — | 幻灯片生成；图片走 OpenAI 兼容 `/v1/images` |
| aicut | LLM 走 `/v1`，默认目录文本 | 映射后的公开图 | 映射后的公开视频 | 网关开启后厂商 Key 不再用于门户流量 |
| screen2code | `gpt-5.5`（含 thinking 档，API 名仍是 `gpt-5.5`） | 工具出图走同一 OpenAI 会话 | 门户模式下视频输入也改走 `gpt-5.5`，不再要 Gemini Key | 截图/视频转代码 |
| aiexcel | `gpt-5.5` | — | — | 表格 Copilot，只有文本规划 |
| qrcode | — | `gpt-image-2`（`/v1/images/edits`） | — | 艺术二维码扩图 |

没有该能力的产品不要硬造视频/图片入口；有该能力的必须走上表公开名。

## 5. 环境变量（模型名）

未写时用第 1 节默认值：

```env
LINK=localhost:18080                 # 云端 https://api.cc2.cx
SUB2API_RELAY_MODELS=gpt-5.5
SUB2API_RELAY_IMAGE_MODELS=gpt-image-2
SUB2API_RELAY_VIDEO_MODELS=grok-imagine-video-1.5
SUB2API_RELAY_MODEL=gpt-5.5          # aiexcel 单模型
CUSTOM_MODEL=gpt-5.5                 # ppt
QR_IMAGE_MODEL=gpt-image-2           # qrcode
LIVART_DEFAULT_CHAT_MODEL=gpt-5.5
LIVART_DEFAULT_IMAGE_MODEL=gpt-image-2
```

canvas 预设图/视频会多几个公开名；ju 视频会多 `seedance-2.0`、`kling-v3`。未写 env 且配了 `SUB2API_APP_CREDENTIAL` 时，代码按项目自动填这些预设。

地址仍只改 `LINK` / `{slug}_link`。

## 6. 新项目怎么选模型

1. 先接公共层（SSO + 三个头）。
2. 文本默认 `gpt-5.5`，图片默认 `gpt-image-2`，视频默认 `grok-imagine-video-1.5`。
3. UI 若保留厂商选项，出站按第 3 节映射。
4. 不要把 `sk-super-` 或用户 Key 放进浏览器。
5. 改目录时同步：`satellite_models.go`、本文、该卫星的默认 env。
