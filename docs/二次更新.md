## 超级 API Key

- 固定名称：`Sub2API Super Key`
- 保留凭证前缀：`sk-super-`
- `GET /api/v1/keys/super` 要求 JWT 登录，会懒创建并复用当前用户的唯一超级 Key。
- 普通自定义 Key 禁止使用保留前缀，避免伪造超级 Key。
- 超级 Key 只绕过“Key 固定绑定分组”限制，不绕过用户状态、IP ACL、余额、Key 状态、订阅额度、分组状态或正常计费。

目标分组支持请求头 `X-Sub2API-Group-ID` 或查询参数 `group_id`。未指定时选择当前用户第一个可用 active 分组；指定分组仍必须通过用户权限检查。

## 安全与兼容说明

按需求使用 URL 查询参数传递 Key。查询参数可能出现在浏览器历史、代理或访问日志中；无限画布初始化后会清理地址栏，Presenton 需保留参数以便后续请求生成请求头。生产环境建议改为一次性短 token 或 URL fragment。

Presenton 的兼容中间件按请求写入进程级 `os.environ`。这适合当前本地单机验收，但多个用户并发请求时可能发生配置竞争；生产部署应改为请求上下文传递配置，避免不同用户的 Key 或模型设置互相覆盖。
