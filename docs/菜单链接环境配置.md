# Sub2API 菜单项目链接

以仓库根目录 `本地链接.txt` 为准。本地和云端只改两类环境变量，不要为每个项目再写一套地址。

## 1. 所有项目访问模型：`LINK`

卫星项目调大模型一律走 Sub2API：

```env
# 本地
LINK=localhost:18080

# 线上
LINK=https://api.cc2.cx
```

无协议的本地值会自动补 `http://`。Docker 里容器互访仍可用 `SUB2API_RELAY_BASE_URL=http://sub2api:8080/v1`，未设置时回退到 `LINK`。

## 2. 左侧菜单 / SSO 跳转：`{项目}_link`

```env
# 本地
aicut_link=http://localhost:5199
aiexcel_link=http://localhost:4173
canvas_link=http://localhost:3522
ju_link=http://localhost:3000
livart_link=http://localhost:8080
ppt_link=http://localhost:8341
qrcode_link=http://localhost:5221
screen2code_link=http://localhost:5173

# 线上
aicut_link=https://aicut.cc2.cx
aiexcel_link=https://aiexcel.cc2.cx
canvas_link=https://canvas.cc2.cx
ju_link=https://ju.cc2.cx
livart_link=https://livart.cc2.cx
ppt_link=https://ppt.cc2.cx
qrcode_link=https://qrcode.cc2.cx
screen2code_link=https://screen2code.cc2.cx
```

SSO 回调默认是 `{项目}_link` + `/api/auth/sso/callback`（PPT 为 `/api/v1/auth/sso/callback`）。只有路径和 origin 不一致时才需要单独设 `*_SSO_CALLBACK_URL`。

8 个快捷项目都从左侧菜单走 SSO，点进去即可用；模型请求不把 SuperKey 暴露给浏览器。
