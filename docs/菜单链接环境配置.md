# Sub2API 菜单项目链接

左侧快捷项目（Canvas、影策、Super Canvas、PPT、AI Cut、Screen2Code、AI Excel、QRCode）会根据当前环境自动选择地址：

- 本地开发（`localhost`、`127.0.0.1`，或 Vite 开发模式）：使用本地端口。
- 生产环境：使用云端默认域名。

这些项目中除 QRCode 外默认走 Sub2API 的 SSO 接口，SSO 接口会自动跟随当前 Sub2API 域名切换本地/云端。所有项目访问模型时使用同一个 Sub2API 链接，可统一设置 `LINK`（前端构建时对应 `VITE_LINK`）：

```env
LINK=https://api.example.com
# Sub2API 前端构建变量名
VITE_LINK=https://api.example.com
```

本地开发使用 `LINK=http://localhost:18080`（也可写成 `localhost:18080`）；线上使用 `LINK=https://api.cc2.cx`。QRCode 服务会优先使用 `QR_API_BASE_URL`，未设置时自动读取 `LINK`。

如果 SSO 接口不在当前 Sub2API 域名下，再额外设置对应的 `VITE_*_SSO_URL`（`.env.example` 已列出全部 7 个项目）。

这些变量只影响前端菜单跳转，不包含数据库密码或 API Key。修改后重新构建前端即可生效；本地开发无需设置，避免把云端地址带入本地。
