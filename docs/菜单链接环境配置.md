# Sub2API 菜单项目链接

左侧快捷项目（Canvas、影策、Super Canvas、PPT、AI Cut、Screen2Code、AI Excel、QRCode）会根据当前环境自动选择地址：

- 本地开发（`localhost`、`127.0.0.1`，或 Vite 开发模式）：使用本地端口。
- 生产环境：使用云端默认域名。

这些项目中除 QRCode 外默认走 Sub2API 的 SSO 接口，SSO 接口会自动跟随当前 Sub2API 域名切换本地/云端。所有项目访问模型时使用同一个 Sub2API 链接，可统一设置 `LINK`（前端构建时对应 `VITE_LINK`）：

```env
LINK=https://api.example.com
# Sub2API 前端构建变量名
VITE_LINK=https://api.example.com
```

本地开发使用 `LINK=localhost:18080`；线上使用 `LINK=https://api.cc2.cx`。各项目服务端会把无协议的本地值自动补成 `http://`。

菜单目标变量使用项目名小写加 `_link`，例如：

```env
aicut_link=http://localhost:5199
aiexcel_link=http://localhost:4173
canvas_link=http://localhost:3522
ju_link=http://localhost:3000
livart_link=http://localhost:8080
ppt_link=http://localhost:8341
qrcode_link=http://localhost:5221
screen2code_link=http://localhost:5173
```

线上只需把这 8 个值替换为 `本地链接.txt` 中对应的 `https://*.cc2.cx`。如果未设置，Sub2API 会继续使用各项目原有的本地默认回调地址。

如果 SSO 接口不在当前 Sub2API 域名下，再额外设置对应的 `VITE_*_SSO_URL`（`.env.example` 已列出全部 7 个项目）。

这些变量只影响前端菜单跳转，不包含数据库密码或 API Key。修改后重新构建前端即可生效；本地开发无需设置，避免把云端地址带入本地。
