# 版本更新记录 2026-09-01

## 更新目标

本次以当前定制版 `sub2api` 为基线，参考官方下载包 `sub2api-0.1.185` 的实现，只移植不会改变现有定制行为的稳定性、观测性和兼容性优化。

本次更新不采用官方目录覆盖方式，不删除当前定制代码，不改变现有数据库数据卷。

## 定制功能保护边界

以下功能属于当前定制版核心能力，本次更新必须保持行为一致：

- 用户级 Superkey 跨分组调用，不要求用户选择分组。
- Canvas、QRCode、PPT 的统一调用入口。
- 文本、图片、视频协议自动适配。
- 计算万物 OpenAI-compatible 调用兼容。
- 现有文本调用方式、模型路由、余额扣减和计费金额。
- 控制面板保留版本提示，但不执行在线更新和回滚。
- 当前暗色主题和 Docker 数据卷隔离方式。

## 参考官方版本的优化内容

### 计划移植

1. 数据库初始化瞬时失败重试，避免 PostgreSQL 尚未 ready 时服务直接退出。
2. 新增 `usage_logs.native_compaction_v2` 观测字段及配套迁移，不改变计费金额。
3. usage log 请求类型、上游模型和媒体字段的记录与查询优化。
4. OpenAI WebSocket 入口容量保护、会话生命周期和错误分类优化。
5. Codex 模型目录缓存、过滤和模型清单稳定性优化。
6. 后台用量统计、频道监控和配额管理的查询及校验优化。
7. Anthropic Responses 兼容性修复，以及官方新增回归测试。

### 仅允许手工移植的文件

以下文件同时包含当前定制逻辑和官方优化，禁止整文件覆盖：

```text
backend/internal/handler/openai_gateway_handler.go
backend/internal/service/billing_service.go
backend/internal/service/gateway_usage_billing.go
backend/internal/service/api_key_service.go
```

### 明确不移植

- 官方删除当前 `mediaadapter`、`protocoladapter` 和 `account_media_profile` 的变更。
- 任何恢复在线更新、回滚或自动更新的代码。
- 任何重新绑定 Superkey 分组的逻辑。
- 任何改变现有文本计费公式、余额扣减时机或默认调用协议的重构。

## 验证要求

- 后端：受影响包的 Go 单元测试必须通过。
- 已验证：`go test ./internal/repository -run 'Test(IsTransientDatabaseInitializationError|InitializeDatabaseWithRetry)' -count=1` 通过。
- 已验证：`go test ./migrations -count=1` 通过。
- 已验证：`go test ./internal/service/mediaadapter ./internal/service/protocoladapter ./internal/service -run 'Test(DetectModelPlatform|.*Media.*|.*Protocol.*)' -count=1` 通过。
- 发现环境问题：完整 `go test ./internal/repository -count=1` 在 `http_upstream` 测试触发 Go 386 的未对齐 64 位原子操作 panic（`http_upstream.go:720`），与本次改动无关，需后续在 amd64/CI 环境复核。
- 前端：类型检查、版本提示测试和 Superkey 表单测试必须通过。
- 适配器：文本、图片、视频及 Canvas/QRCode/PPT 相关测试必须通过。
- 数据库：新迁移只在副本中演练，确认幂等后才允许进入部署流程。
- 部署：本次代码完成后先停在本地构建验证，不自动发布 Docker。

## 后续版本规则

后续官方版本更新时，必须先阅读本文件，保留上述定制边界和适配器行为；任何可能影响这些特性的上游改动都必须改为手工移植并补回归测试，不得直接覆盖。
