# 本地开发配置提醒

## 不可混用的规则

本地开发和线上部署使用两套地址。只要是本地开发、Docker 本地运行或 Vite 开发模式，默认必须使用 `localhost`，不能把线上域名写入默认配置。

## 本地默认地址

| 功能 | 本地地址 |
| --- | --- |
| Sub2API 管理端和 API | `http://localhost:18080` |
| Canvas | `http://localhost:3522` |
| QRCode | `http://localhost:5221` |
| PPT | `http://localhost:8341` |

Canvas、QRCode、PPT 连接 Sub2API 时使用的 Base URL 统一为：

```text
http://localhost:18080
```

OpenAI 兼容接口路径由客户端补充 `/v1`，例如视频接口为：

```text
http://localhost:18080/v1/videos
```

## Sub2API 左侧菜单

本地开发模式下，左侧快捷菜单必须打开：

- Canvas：`http://localhost:3522`
- PPT：`http://localhost:8341`
- QRCode：`http://localhost:5221`

菜单传递给这些应用的 `baseUrl` 必须是 `http://localhost:18080`。

## 线上地址仅限线上环境

只有线上域名部署时才使用：

- Sub2API：`http://api.cc2.cx`
- Canvas：`http://canvas.cc2.cx`
- PPT：`http://ppt.cc2.cx`
- QRCode：`http://qrcode.cc2.cx`

修改默认地址时，先确认当前是本地开发构建还是线上构建；不要用访问页面的 hostname 单独判断开发环境。Vite 开发模式应优先判定为本地。
