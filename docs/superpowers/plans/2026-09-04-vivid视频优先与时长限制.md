# Vivid 视频优先与 Seedance 时长限制实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Canvas Seedance 视频时长不兼容，并确保视频生成优先走 Vivid。

**Architecture:** 前端由视频设置组件根据当前模型过滤合法时长，并在请求前归一化时长；后端沿用现有 OpenAI 兼容视频调度，在 Seedance 模型请求中优先选择 Vivid 账号，失败后使用现有 failover。

**Tech Stack:** React/TypeScript、Vitest、Go、Gin、Testify。
