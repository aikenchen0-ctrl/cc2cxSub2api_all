# CCSwitch 加强版下载引导设计

## 目标

在 Sub2API 公开首页提供 CCSwitch 加强版入口，并新增独立下载页。下载页根据浏览器系统信息突出推荐安装包，同时允许用户手动选择全部平台版本。

## 版本映射

- Windows：`cc-launch_3.20.0_x64-setup.exe`，备用 `cc-launch_3.20.0_x64_en-US.msi`
- macOS Apple Silicon：`cc-launch_3.20.0_aarch64.dmg`
- macOS Intel：`cc-launch_3.20.0_x64.dmg`
- Linux/未知系统：展示全部版本，不做错误推荐

## 页面与数据流

- 新增公开路由 `/downloads`，懒加载下载页。
- 首页导航和主视觉区域增加到下载页的入口。
- 下载链接作为前端常量维护，使用 GitHub Release 固定地址。
- 客户端检测仅影响推荐排序和提示文案，不阻止其他系统下载。

## 验证

- 下载页路由可匿名访问。
- 四个下载链接存在且目标地址正确。
- Windows、macOS Intel、macOS ARM、未知系统推荐逻辑有单元测试覆盖。
- 前端类型检查、测试和生产构建通过。
