# 格知 AI Excel 使用指南

格知是一个用聊天方式处理 Excel 的工具。打开表格后，把要做的事说清楚，再检查并确认 AI 给出的计划，就能批量处理数据。

**基本流程：打开文件 → 说出需求 → 检查计划 → 确认执行 → 导出 Excel。**

## 一、开始前准备什么

- 一个 Excel 文件，支持 .xlsx 和 .xls。页面建议文件不超过 50 MB。
- 使用 AI 时，需要能连接 AI 服务的网络，以及可用的 DeepSeek 配置。
- 重要表格先保留原文件备份，尤其是在删除数据、替换内容或修改公式之前。

如果别人已经提供了应用网址，直接在浏览器打开即可。需要自己启动项目时，查看本文最后一节。

## 二、第一次使用

### 1. 设置 AI 连接

点击右上角的齿轮按钮，打开“连接设置”。在 API Key 中填写自己的 DeepSeek 密钥，再点击“保存设置”。密钥可以理解为“调用 AI 的通行证”，不是账号登录密码。

如果应用提供者已经配置了默认密钥，可以先留空尝试。纯静态版本必须在页面中填写密钥。

密钥保存在当前浏览器中。换浏览器、换电脑或清除网站数据后，可能需要重新填写。公共电脑上用完后，请在设置中点击“清除自定义密钥”。不要把密钥写进表格或发到聊天框。

### 2. 打开 Excel 文件

在首页点击“选择文件”，或者把文件拖到上传区域，等待解析完成。

打开后，左侧是表格预览，右侧是 AI 助手。一个文件可以有多个工作表，也就是 Excel 中常见的 Sheet。点击页面底部的工作表名称，就能切换查看。

### 3. 告诉 AI 要做什么

在右侧输入需求，按 Enter 或点击发送按钮。需要换行时，按 Shift + Enter。

例如，表格里有“数量”和“单价”两列，可以这样说：

> 在当前工作表新增“金额”列，用数量乘以单价，并填充所有数据行。

请使用表格中真实存在的列名。本文示例中的工作表名称、列名和行号，都需要换成你自己的。

### 4. 检查计划，再确认执行

AI 会先生成“操作计划”。发送聊天指令后，不会立即修改表格，需要你点击“确认执行”。

确认前重点检查：

- 工作表是否正确？
- 列名、行号和修改范围是否正确？
- 有没有准备删除或覆盖需要保留的数据？
- 涉及公式时，引用的列和起始行是否正确？

符合要求就点击“确认执行”。不符合要求就点击“取消”，重新描述需求。

### 5. 检查结果并导出

执行后，抽查几条数据，确认结果符合预期。最后点击右上角“导出 Excel”，到浏览器的下载位置查找文件。

修改后的文件通常叫“原文件名-AI优化.xlsx”。大文件如果还处于快速预览、没有加载完整数据并执行修改，直接导出可能下载的是原文件。

**网页中的修改不等于已经保存到电脑。刷新、关闭页面或返回首页前，务必先导出。操作历史不能代替文件备份。**

## 三、常见需求怎么说

### 修改、填空和替换

| 想做什么 | 可以这样说 |
| --- | --- |
| 修改一个格子 | 把当前工作表 B2 的内容改为“已完成”。 |
| 清空一个格子 | 清空当前工作表 D5，其他单元格不变。 |
| 批量填空 | 第 2 行是表头，把“电话”和“地址”列的所有空白单元格填为“待补充”。 |
| 替换文字 | 把当前工作表中的“待处理”替换为“处理中”。 |
| 删除连续几行 | 删除当前工作表第 5 行到第 7 行，共 3 行。 |
| 新增普通列 | 在当前工作表新增一列，列名为“备注”。 |

只想处理空格时，请明确说“空白单元格”，并说明已有内容不要修改。

### 生成公式、关联其他工作表

> 在“销售明细”表新增“金额”列，金额等于数量乘以单价，填充所有数据行。

> 根据“销售明细”表的“商品编号”，匹配“商品资料”表的“商品编号”，用公式把对应的“商品名称”带到销售明细中。

跨表关联时，两张工作表需要在同一个文件中。请说明用哪个字段匹配，以及取回哪一列。生成成功不代表公式一定正确，仍需检查结果。

### 排序、筛选和标颜色

> 第 2 行是表头，按“金额”从高到低排序，整行数据一起移动。

> 只显示“金额”大于 1000 的记录。

> 清除当前工作表的筛选，重新显示全部数据。

> 把“状态”为“已完成”的记录整行标为浅绿色。

筛选是隐藏不符合条件的行，不是删除这些数据。

如果希望自己点击表头操作，可以先告诉 AI：

> 第 2 行是表头，请为当前工作表添加排序和筛选按钮。

执行后，点击表头旁的筛选图标即可操作。**表头菜单中的排序、筛选会直接执行，不再经过聊天中的计划确认步骤。** 操作不合适时可以撤销。

### 美化和生成报表

> 帮我美化当前工作表，突出表头，让列宽更适合阅读。

> 按“地区”汇总“销售额”，在新的工作表中生成报表，包含样本数、平均值、最低值、最高值和柱状图。

生成交互式报表后，可以在网页中切换指标、调整排序、悬停查看数值，或者点击柱状条查看分组详情。导出到 Excel 的图表是静态图片，不保留网页里的点击交互。

右侧的“美化报表”“智能分析”“检查公式”是快捷入口，点击后会把示例需求填入输入框。可以先修改文字，再发送；按钮本身不会立即修改文件，也不代表已经完成公式检查。

## 四、怎样描述得更准确

可以套用这个句式：

> 在【工作表名称】中，第【几】行是表头，对【哪一列或哪一段数据】做【具体操作】，其他内容保持不变。

例如：

> 在“客户名单”中，第 3 行是表头，把“联系电话”列所有空白单元格填为“待补充”，已有电话号码不要修改。

- 不要只说“处理一下”，要说清楚结果应该是什么。
- 如果第一行是标题，第二行或第三行才是列名，请说明表头所在行。
- 一次先完成一类操作，检查后再继续。
- 对重要公式和金额，抽查几行，必要时在 Excel 中重新计算并核对。

## 五、常用工具

| 工具 | 用途 |
| --- | --- |
| 工作表标签 | 在页面底部切换工作表。 |
| 单元格和公式栏 | 点击格子查看内容或公式，不是直接编辑入口。 |
| 搜索框 | 查找当前已加载预览中的内容，不是全工作簿搜索。 |
| 翻页按钮 | 查看更多预览行；大文件快速预览时可能暂时不能翻页。 |
| 缩放按钮 | 调整表格在网页中的显示大小。 |
| 撤销 | 回退到上一个可用的操作记录。 |
| 重做 | 恢复刚才撤销的操作。 |
| 历史 | 查看本次打开文件后的操作记录，选择可用记录恢复。 |
| 导出 Excel | 把当前文件下载到电脑。 |

操作历史数量有限，也不能保证刷新后恢复文件。完成重要步骤后及时导出。

## 六、常见问题

### 提示无法连接 AI 怎么办？

检查密钥有没有填错、网络能否连接服务，再根据具体错误提示处理。使用默认配置时，可以联系应用提供者检查服务端配置。

纯静态版本还可能受到浏览器跨域限制，也就是浏览器不允许网页直接访问该接口。可以请应用提供者检查部署方式。

即使页面显示“DeepSeek 已连接”，也应以实际请求结果为准。AI 暂时不可用时，仍可预览和导出已打开的文件。

### 为什么只看到前 500 行？

应用会分批显示表格，避免一次显示太多行导致卡顿。较大的 .xlsx 文件会先进入快速预览模式，确认执行修改时再加载完整数据。

预览行数不等于操作范围。填空、排序和筛选等操作可以处理完整数据区，确认前仍需核对计划中的范围。

### 能不能直接双击格子修改？

当前页面主要用于预览和 AI 操作，不提供完整的 Excel 手动编辑体验。可以告诉 AI“把 B2 改为 100”，或者导出后在 Excel 中继续编辑。

### 改错了，或者执行失败怎么办？

改错后可以使用“撤销”或“历史”恢复。执行失败时先检查表格，不要假设完全没有变化。必要时回到之前的历史记录，或重新打开备份文件，再把需求拆成更小的步骤。

### 格式和公式一定能完整保留吗？

应用会读取和处理常见公式与样式，但复杂工作簿、特殊格式或兼容模式转换后的结果仍需检查。不要把它当作 Excel 的完整替代品，也不要依赖它保留所有高级功能。

### 数据会发给 AI 吗？

原始 Excel 文件在浏览器中解析和修改，不会作为完整文件上传给 AI。但应用会发送工作表名称、行列数量、表头候选行、少量样例数据、你的指令以及近期聊天内容，帮助 AI 理解需求。

**“文件在本地处理”不等于“任何数据都不联网”。** 表头和样例可能包含真实信息，聊天中主动粘贴的内容也会发送。敏感数据请先脱敏，并确认符合所在单位的数据使用要求。

非静态版本的 AI 请求经过应用服务端转发；静态版本由浏览器直接请求 AI 服务。

## 七、需要自己启动项目时

已经能打开应用的人可以跳过本节。

项目声明需要 Node.js 22.13.0 或更高版本，以及 npm。在项目文件夹打开终端，安装依赖：

```bash
npm install
```

安装完成后启动：

```bash
npm run dev
```

按终端显示的地址在浏览器中打开，通常是 http://localhost:3000。运行期间保持终端开启，停止服务可按 Ctrl + C。

如果 Windows 提示 WRANGLER_LOG_PATH 不是命令，这是项目启动脚本的环境变量写法与默认终端不兼容。可以在 PowerShell 的项目目录中运行：

```powershell
$env:WRANGLER_LOG_PATH = '.wrangler/wrangler.log'
npx vinext dev
```

打开页面后，在设置中填写密钥即可。需要配置服务端密钥或部署静态网站时，参阅项目的 README.md。
