# PRD：AI Excel 智能操作助手（纯前端版）

## 1. 产品概述

### 产品名称

AI Excel Copilot

### 产品定位

一个完全运行在浏览器端的 AI 驱动 Excel 智能编辑工具。

用户上传 Excel 文件后，通过自然语言与 AI 沟通，让 AI 自动：

- 理解 Excel 数据结构
- 生成 Excel 公式
- 创建跨 Sheet 关联
- 批量填充公式
- 调整格式
- 添加颜色规则
- 创建统计分析
- 最终导出保持公式、格式、颜色的 Excel 文件

无需安装 Excel，无需服务器上传文件。

---

# 2. 产品目标

## 核心目标

让不会 Excel 公式的人，也可以通过聊天方式完成复杂 Excel 操作。

例如：

用户：

> 帮我计算销售额 = 数量 × 单价，并生成总销售额排名


AI：

自动：

1. 创建销售额列
2. 写入公式：

```
=C2*D2
```

3. 填充所有行
4. 创建排名公式：

```
=RANK(E2,E:E)
```

5. 设置颜色


---

# 3. 产品特点

## 3.1 纯前端架构

特点：

- Excel 文件不上传服务器
- 所有解析浏览器完成
- AI 请求只发送：
  - 表结构
  - 用户需求
  - 必要数据摘要

不发送完整 Excel 数据。
