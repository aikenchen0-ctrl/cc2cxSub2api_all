# Ju 与 Sub2API SSO

- 两端同时部署新版本，并完成 Ju 数据库版本 11 迁移。
- 从已登录 Sub2API 点击智能剧场，检查同源交换后进入目标页，URL 无票据，交换 Cookie 被清除。
- 使用两个隔离测试账号检查项目、资源、任务和浏览器缓存隔离；Relay Key 不出现在客户端。
- 调用 Sub2API 撤销所有会话，检查 Ju 既有会话和尚未交换的登录失效；Ju 不可达时全局撤销明确失败并可重试。
- 检查 HTTPS、反向代理 Host/协议、网关日志脱敏、多副本共用数据库及重启后的会话行为。

协议、配置与自动化检查入口见 [Sub2API 接入](../backend/sub2api-integration.mdx)。历史部署结果不替代本次升级验收。
