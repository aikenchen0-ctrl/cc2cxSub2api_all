# 影策使用手册

这份手册写给第一次使用影策的创作者，不需要懂编程。

你可以把影策理解为一个“AI 创作工作台”：写故事、整理角色、制作分镜、生成图片和视频，再把镜头剪成作品。

> 本手册按当前仓库中的页面编写。站点名称、模型、价格和功能入口可能由管理员调整，以实际界面为准。本文不是运行验收报告，不代表每个部署站点都已配置好全部服务。

## 一、先选一种使用方式

| 你想做什么 | 从哪里开始 |
| --- | --- |
| 写文案，生成一张图片或一段视频 | 创作页面 |
| 把文字、参考图和视频放在一起反复尝试 | 画布 |
| 把小说或故事做成连续镜头 | 短剧项目 |
| 查找已经保存的图片、视频或提示词 | 素材库 |
| 查看生成进度和失败原因 | 任务中心 |
| 配置自己的模型服务 | 设置 → 个人渠道 |

新手建议先生成一张图片，成功后再尝试画布和短剧项目，不要第一次就批量生成整部作品。

## 二、第一次使用前的准备

### 1. 登录账号

打开管理员提供的站点地址，按页面提示登录。

- 有注册入口时，可以按提示注册；没有入口时，向管理员申请账号。
- 忘记密码时，使用页面提供的找回入口；无法找回时联系管理员。
- 站点接入统一登录时，使用站点提供的登录方式。

不要把密码、验证码或模型密钥发到公开群聊中。

### 2. 确认有模型可以使用

“模型”就是实际帮你写文字、画图或生成视频的 AI。不同模型擅长的事情不同。

| 使用方式 | 你需要做什么 |
| --- | --- |
| 管理员提供的系统模型 | 在模型选择器里选择可用模型，不用自己填写密钥 |
| 自己购买或申请的模型服务 | 在“设置 → 个人渠道”中填写服务信息 |

如果模型列表为空，可能是管理员尚未配置模型，或你的个人渠道还没有设置完成。

### 3. 设置个人渠道（按需）

已有可用系统模型的用户可以跳过本节。

1. 打开“设置 → 个人渠道”，点击“新增渠道”。
2. 给渠道取一个容易辨认的名称。
3. 按服务商提供的信息填写 Base URL、API Key 等字段。
4. 按页面要求选择连接类型和协议，不要只凭名称猜选项。
5. 点击“拉取模型”，或填写服务商提供的准确模型名。
6. 到“模型选择”中设置需要的默认模型，再返回创作页面小规模尝试。

| 字段 | 通俗解释 |
| --- | --- |
| 渠道名称 | 你给这家服务起的备注名 |
| Base URL | AI 服务的接口地址，不一定是服务商的网页首页 |
| API Key | 使用 AI 服务的凭证，要像密码一样保管 |
| Secret Key | 部分服务另外要求的密钥，不需要时留空 |
| 模型名 | 服务商规定的模型编号，不能随意改写 |

能拉取模型列表，不代表其中每个模型都支持图片、视频或参考图。实际可用参数以当前模型面板为准。

只在可信站点填写真实密钥，远程使用时确认站点采用 HTTPS。使用个人渠道时，还要留意服务商账户的余额和账单。

## 三、完成第一次生成

### 生成图片

1. 打开创作页面，切换到“图片”。
2. 选择可用的图片模型。
3. 输入想要的画面描述。
4. 需要参考已有图片时，通过附件或素材入口添加参考图。
5. 在模型支持的范围内选择比例、质量等参数。
6. 查看费用提示（如有），确认后发送。
7. 等待结果，预览图片。满意后下载，或点击“添加到画布”继续制作。

可以先试这段描述：

> 一位穿深绿色外套的年轻女主角站在雨后的公交站旁，手里拿着一封信。中景，平视角度，傍晚柔和光线，写实电影风格，横向构图，画面不要文字。

“提示词”就是你写给 AI 的要求。不必堆很多专业词，先说清楚：谁、在哪里、做什么、画面是什么感觉。

### 生成文本

切换到“文本”，选择文本模型，直接描述要求。例如：

> 请写一个适合一分钟短片的故事。主角是一位修表师，主题是与过去和解，场景不超过两个。先给故事梗概，再列出六个镜头。

拿到结果后，先检查人物关系、剧情逻辑和篇幅，再继续修改。AI 生成内容不等于最终定稿。

### 生成视频

1. 切换到“视频”，选择视频模型。
2. 输入镜头内容；模型支持时，可以添加参考图片或其他参考素材。
3. 选择当前模型提供的时长、比例和分辨率。
4. 发送后等待，也可以到任务中心查看进度。
5. 完成后播放检查，再下载或加入画布。

视频描述尽量只安排一个清楚的动作，例如：

> 女主角站在公交站旁，缓慢展开手中的信，低头阅读。镜头缓缓推近，保持人物外貌和服装一致，背景车辆轻微移动。

不是所有模型都支持首尾帧、多张参考图、声音或相同的视频时长。没有对应选项时，不要强行套用其他模型的操作方法。

## 四、使用画布整理创作过程

画布像一张可以不断扩展的工作桌。上面的文字块、图片、视频等内容，称为“节点”。

### 1. 新建画布

打开画布列表，点击“新建画布”。进入后，通过工具栏的“添加节点”放入需要的内容，也可以从素材库选择已有素材。

建议按用途命名，例如“第一集参考图”“女主角造型测试”，以后更容易找。

### 2. 常用操作

| 操作 | 做法 |
| --- | --- |
| 选择内容 | 点击节点；使用“区域选择”在空白处拖动框选多个节点 |
| 移动画布视野 | 切到“抓手工具”后拖动；按住空格或鼠标中键也可临时平移 |
| 调整视野大小 | 使用画布缩放控件 |
| 修改名称 | 使用名称旁的铅笔入口 |
| 撤回刚才的编辑 | 点击“撤销”；需要恢复时点击“重做” |
| 整理排布 | 使用“自动整理节点”；多选时可使用对齐、等距等工具 |
| 修改背景和网格 | 打开“画布外观” |

只显示图标的按钮，可以把鼠标停在上面查看名称。删除或清空前，先确认选中了哪些内容。

### 3. 用参考素材生成内容

例如，你想让同一个角色出现在不同镜头中：

1. 把角色参考图放到画布上，并取一个明确的名称。
2. 添加用于生成的节点。
3. 把参考素材连接到目标生成节点，检查目标面板中是否出现该素材。
4. 写清楚要保留的外貌、服装，以及这次要改变的动作和场景。
5. 选择模型和参数后生成。

把图片放在旁边，不等于 AI 已经收到参考图。应检查连接、参考素材是否启用，以及模型是否支持这种输入。

提示词面板的“智能引用”可以帮助引用已连接并启用的素材：输入素材名或“图1”等指代后，按 Tab 或点击候选项插入引用。“一键引用全文”会尝试转换全文中能够匹配的指代。

参考图有助于保持一致，但不能保证每次人物细节完全相同，仍然需要人工筛选。

### 4. 导入、导出和分享

- 画布列表提供导入和导出入口，可用于转移或备份画布。
- 导入时选择有效的画布压缩包，不要把普通图片当作画布包导入。
- 导入后检查节点、媒体和云端同步提示，不能只看画布名称是否出现。
- 分享画布是只读查看，不是共同编辑。分享前检查是否包含私人资料。

画布包、单独下载的媒体和服务器备份用途不同，不能互相替代。重要作品建议同时保留原始文本和最终媒体。

## 五、把故事做成短剧项目

适合已有小说、剧本，或者需要连续制作多个镜头的用户。没有短剧入口时，先向管理员确认是否开启。

推荐顺序：**建立项目 → 整理章节 → 确认资产 → 制作分镜 → 预演 → 生成视频 → 剪辑成片。**

### 第一步：建立项目

项目页面提供故事生成、导入小说等创建方式。

- 已有小说：选择“导入小说”，按页面提示提供正文。
- 只有想法：填写一句话故事，选择文本模型和章节数量等设置，点击“AI 生成章节”。

AI 生成后先检查故事，不要马上批量做视频。

### 第二步：整理剧情章节

进入项目的“剧情章节”，查看和修改正文，也可以添加章节。

章节中的“导入小说”支持选择 TXT 或粘贴正文，并预览识别出的章节。确认标题和拆分结果后再导入；这里会追加到已有章节，避免重复导入同一份内容。

检查人物称呼是否统一、章节是否重复、故事顺序是否正确，以及每章是否有明确的动作和场景。

### 第三步：确认角色与资产

“资产”不是财务概念，而是作品会反复使用的角色、场景、道具等资料。

1. 使用章节提供的提取功能，提取角色、场景和道具。
2. 打开“角色与资产”，检查待确认结果。
3. 修正名称和设定，确认需要使用的资产及版本。
4. 制作镜头时，将对应资产绑定到镜头。

先确定主角的发型、服装和随身物品，再制作多个镜头，比每次只写一个“年轻女子”更容易保持连贯。

### 第四步：制作分镜

“分镜”就是把一段故事拆成一个个具体镜头。

进入“分镜制作”，选择章节，按页面中的阶段推进：

| 阶段 | 主要做什么 |
| --- | --- |
| 剧情与章节 | 核对作为制作依据的章节正文 |
| 资产拆分 | 确认镜头要使用的角色、场景和道具 |
| 分镜脚本 | 检查每个镜头拍什么、动作是什么、时长如何安排 |
| 黑白动作预演 | 在正式视频制作前检查构图和动作 |
| 视频生成 | 生成镜头视频，检查并选用合适结果 |
| 交付与打包 | 查看镜头视频是否就绪、是否存在过期产物 |

先做少量镜头，确认风格和参数合适，再扩大制作范围。

产物被标记为“过期”，意味着它可能不再对应当前制作版本，不一定是文件打不开。检查相关设定和分镜变更，再决定是否重新生成。

> 当前“交付与打包”只做交付前检查，没有生成整套交付包的入口。不要把页面列出的计划交付内容当作已经可以下载的文件。

### 第五步：剪辑成片

打开项目中的“剪辑成片”，把已就绪的镜头视频编排到时间线上。

“时间线”可以理解为播放顺序表：片段放在哪里，就安排在什么时间播放。

1. 从素材面板选择需要的镜头。
2. 调整片段顺序和时长，按需要移动、拆分或修剪。
3. 播放预览，检查衔接、声音和字幕。
4. 需要语音转字幕时，使用“转写”相关入口。
5. 在“导出”面板按提示提交成片导出任务，等待结果。

转写和导出需要管理员配置对应后台服务。能打开编辑器，不等于服务器已经具备转写和导出能力。AI 编辑助手还需要可用的文本模型。

项目归档后不能继续创建画布和生成任务；需要继续制作时，先恢复项目。

## 六、管理素材和生成任务

### 素材库

素材库用于集中管理文字、图片、视频、音频等创作资料。

- 使用容易辨认的名称，例如“女主正面参考”，不要都叫“图片1”。
- 使用分类和标签区分角色、场景、道具或不同项目。
- 按类型筛选，或搜索标题、内容、标签和来源。
- 删除前检查是否被项目、画布或任务使用。提示存在引用时，先确认引用来源，不要强行删除底层文件。

### 任务中心

点击生成后，系统需要时间处理。任务中心可以查看状态、结果和失败原因。

| 状态含义 | 建议做什么 |
| --- | --- |
| 等待或排队 | 等待处理资源，不要重复提交 |
| 正在执行 | 等待结果，必要时查看任务详情 |
| 已成功 | 预览结果，确认内容符合要求 |
| 失败或取消 | 先查看原因，再决定是否重试 |
| 提交结果尚未确认 | 先核对服务商或官方状态，避免重复生成和计费 |

重试前先修正问题：余额不足先处理余额，模型不支持参考图就调整输入或更换模型。

取消能力取决于具体服务。页面停止等待不一定表示服务商已经停止生成，也不代表一定退款。删除本机任务记录不等于删除已经生成的素材。

## 七、保存、费用和隐私

### 本地保存不等于服务器保存

**看到“已保存在本地”，不能直接认为“服务器已经保存成功”。**

遇到“云端同步失败”“稍后重试”等提示时：

1. 暂时不要清理浏览器数据或更换设备。
2. 检查网络和登录状态。
3. 等待同步恢复，重要内容先通过可用的导出或下载入口备份。
4. 一直失败时，把错误提示交给管理员排查。

浏览器缓存不是长期备份。换浏览器、清除站点数据或切换账号后，不应假定原来的本地内容还在。

### 积分和费用

站点开启积分功能时，可以在钱包相关页面查看余额和流水。充值、兑换等入口是否可用，由站点配置决定。

生成前留意费用提示。批量生成和重试可能带来额外费用，参数变化也可能影响价格。最终扣费和退款以账单记录为准，不要只看预估数字。

### 隐私提醒

- 不要在提示词、截图或问题反馈中放入密钥和登录凭证。
- 提交素材前，确认你有权使用这些内容，并了解素材会发送给所选的模型服务。
- 在共享电脑使用完后退出账号，不要替他人保存密钥。
- 分享或导出前，检查是否包含不应公开的剧本、人物照片或私人资料。

## 八、常见问题

| 问题 | 先检查什么 |
| --- | --- |
| 找不到项目、钱包或某些功能 | 站点是否开启功能，账号是否有权限 |
| 模型列表为空 | 是否配置系统模型或个人渠道，是否完成模型选择 |
| 能生成文字，不能生成图片 | 当前模型是否支持图片，协议是否正确 |
| 生成按钮不能用 | 提示词、模型、附件上传和必填参数是否准备好 |
| 视频一直没出来 | 任务中心是否仍在排队或执行，是否显示错误 |
| 不同镜头的人物变了 | 是否使用同一套角色参考，参考是否连接并启用 |
| 提示已保存，另一台电脑却看不到 | 是否只有本地保存，云端同步是否成功，账号是否相同 |
| 素材不能删除 | 是否仍被项目、画布或任务引用 |
| 分享链接打不开 | 链接是否有效，分享是否已撤销或失效 |
| 不能转写字幕或导出成片 | 管理员是否配置后台服务，任务详情是否有错误 |
| 交付页面没有打包按钮 | 当前只做交付检查，尚未开放整套交付包生成 |

反馈问题时，说明“在哪个页面、点了什么、希望出现什么、实际出现什么”，附上检查过的错误截图和相关任务编号。

设置中的“问题诊断”可以导出诊断资料。发送前检查内容，只交给可信的维护人员，不要公开上传原始日志或私人资料。

## 九、开工和收工清单

- [ ] 已登录正确的账号。
- [ ] 已选好模型，并完成一次小规模生成。
- [ ] 已确认费用和可用余额。
- [ ] 已准备故事、角色或参考素材。
- [ ] 批量生成前，已检查少量样片。
- [ ] 离开前，已检查保存和同步提示。
