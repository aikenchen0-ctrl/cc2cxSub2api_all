# 手动剪裁功能使用说明

## 改进内容

### 1. **默认显示，无需勾选**
- 上传二维码后，Canvas框选区域会自动显示
- 不再需要手动勾选复选框

### 2. **更清晰的视觉反馈**
- Canvas边框加粗，颜色更醒目
- 悬停时有阴影效果提示可交互
- 框选区域外的部分会变暗（50%透明度）
- 框选区域内保持原图亮度
- 虚线边框 + 四个角点标记，清晰显示选择范围

### 3. **默认全选**
- 上传图片后，默认选中整个图片区域
- 你可以直接点击生成，或者重新框选需要的区域

### 4. **实时坐标显示**
- 框选时实时显示X、Y坐标和宽高
- 坐标自动转换为原始图片尺寸，确保精确

### 5. **操作提示**
- 添加了👆图标和操作说明
- 状态栏会提示"请在下方框选需要保留的区域"

## 使用步骤

1. **上传二维码图片**
   - 点击"选择水墨二维码图片"按钮
   - 选择你的二维码图片文件

2. **查看Canvas区域**
   - 上传后会自动在"二维码手动剪裁"区域显示图片
   - 默认已选中整个图片（橙色虚线框）

3. **框选需要的区域**
   - 在Canvas上按住鼠标左键
   - 拖动鼠标绘制矩形框
   - 松开鼠标完成框选
   - 可以多次调整，直到满意为止

4. **查看坐标信息**
   - 框选完成后，下方会显示：
     - X: 左上角横坐标
     - Y: 左上角纵坐标  
     - 宽: 框选区域宽度
     - 高: 框选区域高度

5. **继续其他设置**
   - 上传空白盘模板
   - 调整二维码位置（X、Y、大小）
   - 设置Prompt

6. **点击生成**
   - 系统会使用你框选的区域进行后续处理
   - 自动生成预览和最终结果

## 技术细节

### 坐标转换
Canvas显示时会按比例缩小（最大600px宽），但发送给后端的是原始图片的坐标：

```javascript
// 例如：
// Canvas显示尺寸: 600x400
// 原始图片尺寸: 1200x800
// 缩放比例: 2倍
// 
// 用户在Canvas上框选 (100, 100, 200, 200)
// 实际发送给后端: (200, 200, 400, 400)
```

### 后端处理流程
1. 接收前端发送的裁剪坐标
2. 使用sharp库的extract方法按坐标裁剪
3. 将裁剪后的二维码放入模板中
4. 调用AI生成最终图片

## 常见问题

**Q: 为什么看不到Canvas？**
A: 确保已经上传了二维码图片，Canvas会在上传后自动显示。

**Q: 框选不准确怎么办？**
A: 可以多次重新框选，每次都会覆盖之前的选择。

**Q: 可以不框选直接生成吗？**
A: 可以，默认会选中整个图片。如果想裁剪特定区域，再手动框选。

**Q: 框选后可以修改吗？**
A: 可以，直接在Canvas上重新拖动框选即可。
