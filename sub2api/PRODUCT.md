# Product

## Register

product

## Users

Sub2API 的主要用户是管理 AI API 网关的运营人员、管理员和 API 消费用户。他们在仪表盘、数据表格和设置页中完成高频、信息密集的操作。

## Product Purpose

提供 AI API 账户、密钥、渠道、用量、订阅、支付和系统设置的统一管理界面。成功标准是信息易于扫读、状态容易辨认、重复操作高效且结果可预期。

## Brand Personality

克制、专业、科技感。科技感主要通过深色中性表面、冰青主色和少量紫色辅助色表达，不干扰业务内容。

## Anti-references

不做高饱和霓虹赛博朋克、满屏渐变、重度玻璃拟态、装饰性粒子动画或牺牲文字对比度的暗色界面。

## Design Principles

1. 信息可读性优先于装饰。
2. 强调色只用于操作、选中和状态。
3. 保持现有熟悉的交互与布局，视觉更新不改变工作流。
4. 使用全局 token 统一多页面视觉，避免逐组件特例。

## Accessibility & Inclusion

保持正文、次级文字、按钮文字与背景的可辨识对比度。不仅依赖颜色表达成功、警告和错误状态，不在本次配色更新中新增动效。
