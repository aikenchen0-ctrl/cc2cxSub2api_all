# 上游 SVG 测试台

这是一个独立的管理员工具，不修改 Sub2API 的网关、调度器和数据库。

它有两种来源：

- 粘贴一个 `http(s)` URL 和明确标记的 API Key。Key 加密保存在工具自己的 `data` 目录。
- 粘贴来源时可填写分组；分组会随任务和结果保存，并显示在定时任务、结果画廊及站点快捷详情中。
- 选择已有 OpenAI API Key 上游。每轮使用管理员密钥读取指定账号和该账号的受保护导出接口，生产 Key 只在内存短暂使用，不传浏览器、不写入本工具磁盘。若站点的二次认证策略拒绝管理员 Key 导出，测试会显示权限错误，可改用粘贴模式；工具不会关闭或绕过该策略。

创建时可同时勾选以下提示词，批量生成相互独立的任务，每个任务保存全文快照：

- AK47：`Write an AK47 SVG at the same scale as reality`
- 复合提示词：用户提供的完整多对象 SVG 插画要求，原文保存在 `lib/prompts.mjs`。

管理员可通过“新建提示词”增加选项，通过“编辑原文”修改内置或自定义提示词的名称和全文。每个选项有独立版本号；并发编辑发生冲突时提示刷新确认。保存只影响随后新建的任务，已有任务及历史结果继续保留创建时的原文快照。最多保存 100 个选项，单个原文最多 32000 个字符，每批可选 16 个选项。

所有提示词测试共用以下配置：
- 模型：`gpt-6.1-sol`、`gpt-6-astra`
- 思考程度可选：`low`、`medium`、`high`、`max`。
- OpenAI Responses 请求体，不使用重试、换模型或换账号。

单次上游成功响应按实际接收的 UTF-8 字节计数，最多接收 `64 * 1024 * 1024` 字节（64 MiB，界面简称 64 MB），包括流事件开销。超过上限会取消读取，记录 `local_response_limit`、已接收字节数和上限；不把本地限制误报成上游错误。

输出预算默认 `65536` token，可通过 `LAB_MAX_OUTPUT_TOKENS` 配置；每次请求和结果记录实际预算。`max_output_tokens` 表示模型达到了该输出预算，不是等待时限或响应字节上限。

默认总等待上限为 1200 秒（`LAB_TIMEOUT_SECONDS`），连续未收到数据上限为 280 秒（`LAB_IDLE_TIMEOUT_SECONDS`）。持续有数据返回时不会因总耗时达到 280 秒而终止；总等待仍有上限。完成事件收到后结束读取，无需等待上游关闭连接。本地计时器取消归类为 `timeout`，并用 `timeout_kind` 区分总时限与连续无数据，保留 HTTP 状态和已接收字节；真实上游断流继续显示上游错误，不自动发起第二次收费请求。

SSE 错误兼容顶层、嵌套对象、字符串及 `incomplete_details.reason`，JSON 未提供事件类型时读取 `event:` 字段。普通错误留出最多一秒的恢复窗口；有实际输出恢复则继续读取，明确的完成、失败、未完成事件直接收尾，不发起重试。正文按输出项和内容索引合并，完成片段替换对应增量，避免遗漏或重复。

成功和失败结果均可由管理员点击“查看原始响应”。正文单独保存在私有产物目录，通过管理员接口读取，不随公开画廊列表返回；旧错误记录若从未保存正文，将明确提示无法恢复。只有文字而无 SVG 根标签归类为 `upstream_no_svg`，空输出归类为 `upstream_empty_output`，有 SVG 开始标签但无法闭合才归类为 `local_svg_validation`。超时与中断保留已经收到的部分正文用于诊断，仍判失败，不补写图形或伪造完成事件。

启动：

```powershell
Copy-Item .env.example .env
# 编辑 .env，填写 SUB2API_BASE_URL 和 SUB2API_ADMIN_API_KEY
npm start
```

浏览器打开 `http://127.0.0.1:9876`。服务只绑定本机地址，可经 HTTPS 反向代理公开。公开部署必须设置 `LAB_PUBLIC_ORIGIN`、`LAB_BASE_PATH` 和至少 3 个字符的 `LAB_ACCESS_TOKEN`。访客只能查看结果画廊；管理口令才能查看账号、配置连接及启停计划。管理员 Key 可从环境变量提供，也可在管理连接页验证后加密保存。

创建计划可选择现有上游账号、粘贴一个 URL 和 Key，或从已保存/测试来源中快捷复用站点凭据。来源按 URL 去重，复用该 URL 最近任务的加密 Key 或账号关联，页面显示来源指纹与引用关系，不返回密钥明文。

快捷测试将来源和提示词独立选择：选站点后可直接使用默认凭据，也可指定历史任务的凭据。快捷区列出全部内置及自定义提示词，可同时勾选并与上方选项同步；切换历史凭据不会改变选定的提示词和模型。

同时勾选 AK47、复合提示词时，一次创建两个任务。“创建并立即测试”保存成功后立即启动两种测试；满额任务在内存队列等待空位。同一任务、同一来源的 A/B 模型同时发起请求，各自记录耗时和结果；一个模型失败不会阻止另一个模型完成。多账号任务按账号逐一推进，同账号的模型全部收尾后才开始下个账号。每个任务最多支持 8 个模型。

默认最多 6 个不同任务并行，管理页可调为 1 至 16 并持久化；`LAB_MAX_PARALLEL_JOBS` 仅作为没有已保存设置时的初始值。“任务并行数”是任务数上限：每任务两个模型时，6 个任务最多 12 路模型请求，16 个任务最多 32 路。页面同时显示活动任务数和模型运行数。同一任务不重叠，降低并行数不终止正在执行的请求，只限制后续启动。所有模型及结果保存结束后才释放任务名额；等待队列不跨服务重启恢复，重启后可手动重试。

计划和下次执行时间持久化，服务重启后补执行一轮已到期计划。失败不自动换模型、换号或重试。支持暂停和手动运行；保留最近 1000 条结果。提示词类别和全文随结果保存，旧任务兼容 AK47，不会因页面切换而改变历史。并行完成的 SVG 写入和清理串行提交，避免互相删除产物。

原始 SVG 保存在 `data/artifacts`，由独立 iframe 预览，支持原始尺寸和下载。提取器忽略前后说明文字及 Markdown 围栏，可识别嵌套 SVG、大小写标签、CDATA 和自闭合根节点，并从响应文本中提取第一个完整 SVG。画廊的成功只表示请求完成且获得标签结构完整的 SVG，不代表已经确认模型身份或判定“降智”。屏幕物理尺寸需要单独校准。代理、影子凭据和 OAuth 账号暂不支持。

结果画廊按结果编号保留已有预览节点，十秒轮询只更新变化的卡片，每秒计时仅更新耗时文字。搜索通过隐藏卡片筛选，新增结果通过显示顺序排序，不卸载已有 SVG 或重启动画；没有 SVG 的失败记录不请求预览文件。浏览器稳定性回归可运行 `node verify_gallery_stability.cjs`。

浏览器回归是可选检查，需要单独安装 Playwright：`npm install --no-save --package-lock=false playwright`。脚本默认使用本机 Edge；可用 `PLAYWRIGHT_CHANNEL` 指定其他已安装的浏览器，用 `PLAYWRIGHT_MODULE_PATH` 指定现有 Playwright 包的位置。常规 `npm test` 不需要 Playwright，也不会请求真实上游。

本目录基于 `aikenchen0-ctrl/cc2cxSub2api_all` 的 `talent` 分支（`61aa73e`）接口核对实现，无第三方运行依赖，不改 Sub2API 核心文件和数据库。测试命令为 `npm test`。

Key 解析要求 URL 显式带 `http://` 或 `https://`，Key 使用 `api_key=...`、`key: ...`、`Authorization: Bearer ...` 或 `sk-...`。裸 IP 加 SSH 登录口令不会被当作 API 凭据。

支持 Key 在前、URL 在后、空行、HTTP IP 加端口、不换行空格和行首行尾零宽字符。服务更新后旧页面收到明确的会话失效响应时，会自动刷新防跨站令牌并重试一次；其他认证错误和网络错误不会重放请求。
