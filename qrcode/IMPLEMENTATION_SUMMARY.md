## 🔧 技术实现细节

### 依赖库
```json
{
  "qrcode": "^1.5.4",
  "sharp": "^0.34.4",
  "node-fetch": "^3.x"
}
```

### API端点
```
POST /api/url-to-qr
Content-Type: application/json

Request Body:
{
  "url": "https://example.com"
}

Response:
{
  "imageDataUrl": "data:image/png;base64,...",
  "mimeType": "image/png",
  "filename": "qr-timestamp.png"
}
```

### 二维码配置
- **尺寸**: 512x512 像素
- **边距**: 4 模块
- **颜色**: 黑色 (#000000) / 白色 (#ffffff)
- **容错率**: H (High, ~30%)
- **格式**: PNG

## 🎯 使用流程

1. **选择模式**: 点击"我有URL"选项
2. **输入URL**: 输入完整URL（含协议）
3. **转换**: 点击"转换为二维码"按钮
4. **预览**: 查看生成的二维码
5. **继续**: 像普通二维码一样进行艺术化处理

## 📝 使用说明

### 基本要求
- URL必须以 `http://` 或 `https://` 开头
- 建议使用较短的URL以获得更好的二维码效果
- 确保服务器正在运行

### 启动服务
```bash
npm start
```

### 访问应用
打开浏览器访问: http://127.0.0.1:3100
