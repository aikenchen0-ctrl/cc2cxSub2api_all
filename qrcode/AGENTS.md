# AGENTS.md

## QRCode 项目代码冻结保护

本目录 `qrcode/` 已完成版本回退和旧版艺术二维码生图服务恢复，自 **2026-09-30** 起视为冻结项目。

### AI 强制规则

1. **禁止修改本目录中的任何现有代码、配置、测试、依赖、提示词、页面或部署文件。**
2. 禁止重构、格式化、升级依赖、自动修复、清理文件或进行“顺手优化”。
3. 禁止修改艺术二维码生图链路，包括但不限于：
   - 生图 URL：`https://open-qr.mewx.art/api/v1/images/generate`
   - 详情 URL：`https://open-qr.mewx.art/api/v1/images/detail`
   - 模型：`67`
   - `src/config.js` 中的服务端密钥
   - `src/qr-app.js` 中的 `stylizeQrImage` 默认调用
4. 禁止把旧艺术二维码链路替换为 `gpt-image-2`、`/v1/images/edits` 或其他模型、URL、供应商。
5. 禁止把服务端密钥迁移到环境变量、浏览器代码、URL、请求参数、日志或前端存储。
6. 可以执行只读检查、测试和故障诊断，但不得因此写入或生成项目文件。
7. 如果其他任务会间接修改 `qrcode/`，必须跳过本目录，并明确说明这里受到冻结保护。

### 唯一例外

只有当用户在当前对话中明确表示“解除 qrcode 冻结保护”或明确要求修改 `qrcode/` 中的具体文件和具体内容时，AI 才可以修改。普通的“修复项目”“统一配置”“升级全部项目”“运行格式化”等宽泛指令，不构成解除保护。

即使用户明确解除保护，修改前仍必须：

1. 读取根目录 `AGENTS.md`、`docs/卫星应用接入公共层.md` 和 `docs/卫星公开模型.md`。
2. 说明将修改的文件及原因。
3. 只做用户指定的最小修改。
4. 修改后运行相关测试，并确认旧艺术二维码链路未被意外替换。
