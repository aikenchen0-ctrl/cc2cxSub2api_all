# 提示词优化说明

## 📋 问题诊断

### 原提示词的问题
```
延展盘子空白处周围荷花纹理，严格锁定中心方形内全部像素与四角定位图形，不移动、不重绘、不改对比度；仅延展盘子空白处周围荷花纹理、色调与光影，让非定位区域边缘自然融合、无缝衔接不要有白边。
```

**问题分析：**
1. ❌ **过于简略** - 只有60个字，无法传达复杂的编辑需求
2. ❌ **缺乏细节** - 没有具体说明如何"延展"、如何"融合"
3. ❌ **指令模糊** - AI不知道什么是"自然"、什么是"无缝"
4. ❌ **缺少约束** - 没有明确列出禁止事项
5. ❌ **无技术细节** - 没有提到笔触风格、光影分析等关键点

---

## ✅ 新提示词的优势

### 结构化设计（共8个部分）

#### 1️⃣ 【核心指令】- 明确任务背景
```
这是一张青花瓷盘上的荷花图案，中心区域包含一个需要保持原样的二维码。
```
✅ 告诉AI这是什么场景，建立上下文

#### 2️⃣ 【必须严格遵守的约束】- 保护关键区域
```
1. **绝对保护区域**（严禁任何修改）：
   - 中心方形区域内的所有像素必须100%保持原样
   - 二维码的三个角定位图形绝对不能移动、重绘或改变对比度
   - 二维码内部的所有黑白模块必须完全保留
   - 这些区域的每个像素都必须与输入图像完全一致
```
✅ 使用"100%"、"绝对"、"完全"等强语气词
✅ 具体列举要保护的对象
✅ 强调"每个像素"都要一致

#### 3️⃣ 【允许编辑区域】- 明确操作范围
```
- 仅处理盘子空白处周围的荷花纹理区域
- 重点是边缘过渡区域，需要自然融合
```
✅ 划定边界，防止AI过度编辑

#### 4️⃣ 【具体编辑要求】- 详细说明怎么做

**纹理延展：**
```
- 将现有的荷花花瓣纹理向空白区域自然延伸
- 保持荷花的颜色渐变：从粉色到白色的过渡
- 延续荷叶的绿色脉络和纹理走向
- 模仿现有笔触的风格和密度
```

**光影一致性：**
```
- 分析现有光源方向，在新延展区域保持一致的光影效果
- 保持青花瓷的高光反射特性
- 阴影部分要柔和过渡，不要突兀
```

**色彩协调：**
```
- 严格匹配原有荷花的色调（粉红、淡紫、白色）
- 荷叶的绿色要与现有部分色相、饱和度一致
- 青花瓷底色的蓝色调要保持统一
```

**无缝衔接：**
```
- 边缘过渡必须平滑自然，不能有明显分界线
- 消除所有白边或硬边
- 纹理密度要从中心向边缘逐渐变化，避免突变
- 让新生成的部分看起来像是原本就存在的
```

✅ 每个要点都有具体的执行标准
✅ 使用专业术语（色相、饱和度、高光反射）
✅ 提供可衡量的目标（"平滑自然"、"逐渐变化"）

#### 5️⃣ 【技术细节】- 艺术风格指导
```
7. **笔触风格**：
   - 模仿中国水墨画的笔触特点
   - 保持写意风格的松散感，不要过于规整
   - 花瓣边缘要有自然的晕染效果

8. **构图平衡**：
   - 延展后的荷花要保持视觉平衡
   - 不要在一侧过度填充导致失衡
   - 留白要有意境，不要填满所有空间
```
✅ 指定艺术风格（中国水墨画、写意风格）
✅ 给出美学原则（视觉平衡、意境留白）

#### 6️⃣ 【禁止事项】- 明确的红线
```
- ❌ 不得改变二维码区域的任何像素
- ❌ 不得添加新的元素（如蝴蝶、蜜蜂等）
- ❌ 不得改变整体构图比例
- ❌ 不得使用与原图不符的颜色
- ❌ 不得产生明显的拼接痕迹或白边
```
✅ 使用❌符号增强视觉警示
✅ 列举具体禁止的行为
✅ 给出反面例子（蝴蝶、蜜蜂）

## 🎯 预期改进效果

### 1. 二维码保护更可靠
- 原提示词：只说"严格锁定"，但AI可能不理解有多严格
- 新提示词：多次强调"100%"、"绝对"、"完全"，并使用"严禁"等强语气词

### 2. 纹理延展更自然
- 原提示词：只说"延展纹理"，没说怎么延展
- 新提示词：详细说明要模仿笔触、保持渐变、延续脉络

### 3. 色彩匹配更准确
- 原提示词：只说"色调"，太笼统
- 新提示词：具体到"粉红、淡紫、白色"和"色相、饱和度"

### 4. 边缘融合更平滑
- 原提示词：只说"无缝衔接"
- 新提示词：要求"纹理密度逐渐变化"、"消除白边"、"无明显分界线"

### 5. 风格一致性更好
- 原提示词：完全没有风格指导
- 新提示词：明确要求"中国水墨画"、"写意风格"、"晕染效果"

## 🔧 使用方法

1. **重启服务器**（如果正在运行）：
   ```bash
   npm start
   ```

2. **测试生成**：
   - 上传二维码图片
   - 上传模板图片
   - 点击"开始生成"
   - 观察结果是否符合预期

3. **微调提示词**（如果需要）：
   - 如果某些方面还不够好，可以在对应章节增加更多细节
   - 如果AI忽略了某个约束，可以加强语气或重复强调

## 💡 进一步优化建议

如果效果仍不理想，可以考虑：

1. **添加负面提示词**（defaultNegativePrompt）：
   ```javascript
   defaultNegativePrompt: "模糊、失真、像素化、二维码损坏、定位点变形、颜色溢出、硬边、白边、拼接痕迹"
   ```

2. **提供参考图片**：
   - 上传1-2张完整的荷花青花瓷图片作为参考
   - 帮助AI学习正确的风格和配色

3. **调整mask透明度**：
   - 当前是0.85，可以尝试0.7-0.9之间的值
   - 较低的值给AI更多自由度
   - 较高的值更严格保护二维码

4. **分步生成**：
   - 先生成小范围的延展
   - 检查结果后再逐步扩大范围

## 📝 提示词编写最佳实践

1. **结构化** - 使用清晰的章节和标题
2. **具体化** - 避免模糊词汇，给出具体标准
3. **重复强调** - 重要约束要多处提及
4. **正反结合** - 既说要做什么，也说不做什么
5. **技术术语** - 使用领域专业词汇提高精度
6. **示例说明** - 必要时给出具体例子
7. **语气强度** - 根据重要性调整用词强度
