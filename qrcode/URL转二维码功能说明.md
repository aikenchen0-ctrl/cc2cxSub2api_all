# URL转二维码功能使用说明

## 功能概述

本项目新增了URL转二维码功能，用户可以直接输入URL地址，系统会自动将其转换为二维码图片，然后可以继续进行艺术化处理。

## 使用方法

### 1. 选择输入模式

在页面顶部的"普通二维码"区域，你会看到两个选项：
- **我有二维码图片**：上传已有的二维码图片文件
- **我有URL**：输入URL地址生成二维码

### 2. 使用URL模式

1. 点击"我有URL"选项
2. 在输入框中输入完整的URL地址（必须以 `http://` 或 `https://` 开头）
   - 正确示例：`https://www.example.com`
   - 错误示例：`www.example.com`（缺少协议）
3. 点击"转换为二维码"按钮
4. 系统会自动生成二维码并显示在预览区

### 3. 后续操作

生成的二维码可以像普通上传的二维码一样进行以下操作：
- 在Canvas上框选需要保留的区域
- 调整二维码位置和大小
- 点击"艺术化二维码"进行艺术处理
- 设置模板和参考图
- 最终生成艺术化二维码

## 技术实现

### 前端部分

- **位置**：`public/index.html` 和 `public/app.js`
- **功能**：
  - 添加输入模式切换界面
  - URL输入框和转换按钮
  - 调用后端API生成二维码
  - 将生成的二维码集成到现有流程中

### 后端部分

- **位置**：`src/url-to-qr.js` 和 `src/qr-app.js`
- **依赖**：使用 `qrcode` 库生成二维码
- **API端点**：`POST /api/url-to-qr`
- **参数**：
  ```json
  {
    "url": "https://example.com"
  }
  ```
- **返回**：
  ```json
  {
    "imageDataUrl": "data:image/png;base64,...",
    "mimeType": "image/png",
    "filename": "qr-1778663702626.png"
  }
  ```

### 配置选项

生成的二维码默认配置：
- **尺寸**：512x512像素
- **边距**：4个模块
- **颜色**：黑色前景，白色背景
- **容错级别**：H（高容错率，适合艺术化处理）

## 注意事项

1. **URL格式**：必须包含完整的协议前缀（http:// 或 https://）
2. **URL长度**：过长的URL会生成更复杂的二维码，可能影响扫描效果
3. **特殊字符**：URL中的特殊字符会被自动编码
4. **容错率**：使用高容错率（H级别），即使部分被艺术化处理仍可扫描

## 故障排除

### 问题：提示"无效的URL格式"
**解决**：确保URL以 `http://` 或 `https://` 开头

### 问题：生成的二维码无法扫描
**解决**：
1. 检查URL是否正确
2. 避免使用过长的URL
3. 艺术化处理时不要过度修改二维码核心区域

### 问题：转换按钮无响应
**解决**：
1. 检查网络连接
2. 确认服务器正在运行
3. 查看浏览器控制台错误信息
