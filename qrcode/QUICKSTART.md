# 🚀 快速开始 - URL转二维码功能

## 5分钟上手指南

### 1️⃣ 启动服务

```bash
npm start
```

服务将在 http://127.0.0.1:3100 启动

### 2️⃣ 打开应用

在浏览器中访问: http://127.0.0.1:3100

或者点击预览按钮（如果可用）

### 3️⃣ 使用URL转二维码功能

#### 步骤1: 选择输入模式
在页面顶部找到两个选项：
- ⭕ 我有二维码图片
- ⭕ **我有URL** ← 点击这个

#### 步骤2: 输入URL
在出现的输入框中输入完整的URL，例如：
```
https://www.baidu.com
```

⚠️ **重要**: 必须包含 `http://` 或 `https://`

#### 步骤3: 转换
点击 **"转换为二维码"** 按钮

#### 步骤4: 查看结果
生成的二维码会显示在"普通二维码输入"预览区

#### 步骤5: 继续处理
现在可以像普通二维码一样：
- 在Canvas上框选区域
- 调整位置和大小
- 点击"艺术化二维码"
- 设置模板和参考图
- 生成最终效果

## ❓ 常见问题

### Q: 提示"无效的URL格式"？
**A**: 确保URL以 `http://` 或 `https://` 开头

❌ 错误: `www.baidu.com`  
✅ 正确: `https://www.baidu.com`

### Q: 生成的二维码能扫描吗？
**A**: 是的！使用了高容错率，完全可以扫描

### Q: 可以自定义颜色吗？
**A**: 当前版本是黑白二维码，未来会支持自定义

## 💡 小贴士

1. **短URL更好**: 过长的URL会生成复杂的二维码
2. **使用短链接**: 对于长URL，建议先用短链接服务
3. **测试扫描**: 生成后用手机扫码测试
4. **高容错率**: 即使部分被艺术化处理仍可扫描

## 🔧 技术信息

- **依赖**: qrcode, sharp
- **API**: POST /api/url-to-qr
- **格式**: PNG, 512x512px
- **容错**: H级别 (30%)
