# OpenChatCut 使用指南

OpenChatCut 是一款视频剪辑工具：你可以自己剪，也可以用文字告诉 AI 怎么剪。它会保留可以继续修改的工程，最后再导出视频。

本指南根据当前项目代码编写，适合第一次使用的人。界面名称如有变化，以实际显示为准。

## 一、先认识几个词

| 名称 | 通俗解释 |
| --- | --- |
| 工程 | 剪辑工作档案，记录素材、片段顺序、字幕和效果 |
| 素材 | 视频、照片、音乐、录音等文件 |
| 素材池 | 存放素材的地方，导入这里不代表已经加入成片 |
| 时间线 | 排列片段的工作区，从左到右就是播放顺序 |
| 轨道 | 时间线上的一行，用来分别放画面、声音或字幕 |
| 播放头 | 时间线上表示当前播放位置的竖线 |
| Agent | 能理解文字要求并操作剪辑工具的 AI 助手 |
| 转写 | 把录音或视频里的讲话识别成文字 |
| 导出 | 把剪辑结果制作成可以播放的视频文件 |

**不配置 AI，也可以用本地素材手动剪辑。** 聊天、生成图片、生成视频和云端转写是不同功能，需要分别配置对应服务。

## 二、启动软件

### 已安装桌面版

直接打开 OpenChatCut 即可，不用执行下面的命令。安装包入口见项目根目录的 README_ZH.md。

### 从当前源码启动

以下以 Windows PowerShell 为例。

**1. 检查环境**

项目要求 Node.js 24.x，并需要 npm。默认开发启动还需要 Git 来识别工作区。

```
node -v
npm -v
git --version
```

Node 版本应以 v24. 开头。提示找不到命令时，先安装对应工具，再重新打开终端。

**2. 进入项目目录，安装依赖**

```powershell
cd "C:\Users\kodesh\Desktop\sub2api\aicut"
npm install
```

换电脑后，把路径改成实际项目目录。安装依赖通常只需首次执行；更新代码后如果依赖发生变化，也需要重新执行。

**3. 准备配置文件**

下面的命令仅在配置文件不存在时复制示例，避免覆盖已有配置：

```powershell
if (-not (Test-Path .env.local)) {
    Copy-Item .env.example .env.local
}
```

先体验手动剪辑，可以不填写服务密钥。需要 AI 时再按第四节设置。

**4. 启动服务**

```powershell
npm run dev
```

启动成功后，在浏览器打开：

```text
http://localhost:5199
```

如果终端显示了其他端口，以终端中的地址为准。首次启动可能需要准备附加资源，请等待完成。

使用期间不要关闭这个终端。结束时先确认保存和导出完成，再按 Ctrl+C 停止服务。下次使用，进入项目目录后重新运行 npm run dev 即可。

**其他启动方式**

桌面开发版使用：

```powershell
npm run desktop:dev
```

如果源码来自压缩包，默认启动因为没有 Git 仓库而失败，可以使用共享开发模式：

```powershell
npm run dev:shared
```

注意：默认开发模式和共享开发模式的数据位置不同。切换后看不到工程，不一定是工程被删除，不要随意来回切换。

## 三、先做出第一条视频

建议先用一段短视频练习，不必一开始导入大量素材。

### 1. 新建工程

在首页点击“新建工程”，起一个容易识别的名字，例如“旅行短片练习”。

根据用途设置画幅：横屏通常用 16:9，手机竖屏通常用 9:16，方形内容可以用 1:1。画幅是宽高比例，不是清晰度。

### 2. 导入素材

通过素材区的上传或导入入口选择视频、图片、音乐，也可以将文件拖入素材区。等待处理完成，确认能看到缩略图或音频信息。

桌面版还支持部分直接访问本地目录的功能；浏览器版优先使用文件选择或拖入文件。

### 3. 放到时间线

把视频从素材池拖到时间线。多个片段从左到右排列，就是成片的播放顺序。

背景音乐放到音频轨道。只导入素材池、没有加入时间线的素材，不会自动出现在成片里。

### 4. 剪掉多余内容

- 去掉开头或结尾：拖动片段的左右边缘，缩短保留范围。
- 去掉中间一段：在该段起点和终点分别切分，再删除中间片段。
- 调整顺序：把片段拖到新位置。
- 删除后有空白：把后面的片段前移，或使用波纹编辑功能，让后面的内容跟着前移。
- 操作错了：使用撤销；撤销过头了，再使用重做。

把鼠标停在图标上可以查看提示。顶部“编辑快捷键”入口可查看当前快捷键，不必死记。

### 5. 调整声音

播放一遍，确认人声清楚、音乐不会盖过讲话。选中对应片段，在属性面板里调整音量。

先做好内容和声音，再加转场、特效，方便发现问题。

### 6. 导出试片

点击顶部“导出”，选择 MP4 (H.264)，先用 1080p 和默认码率导出一份。打开成片，检查画面、声音和结尾。

## 四、让 AI 帮你剪辑

### 配置聊天模型

打开“设置 → Agent 模型”，选择服务商，填写对应配置并保存。

| 配置项 | 填写内容 |
| --- | --- |
| API Key | 服务商提供的调用密钥，可以理解成使用服务的凭证 |
| Base URL | 服务商提供的接口地址，使用默认服务时通常保留默认值 |
| 模型 | 你的账号实际能够调用的模型名称 |

如果界面提供连接测试，可以先测试再保存。测试成功不代表尚未保存的配置已经生效。然后在聊天区选择对应模型，发送一句简单的话确认连接正常。

优先使用界面设置。默认隔离开发模式有自己的配置存储，首次启动后，再修改根目录的 .env.local 不一定会覆盖已经保存的设置。

不要把密钥发给别人，也不要放进截图或公开代码中。第三方服务可能计费，使用前请查看自己的服务额度。

### 把需求说具体

比起“帮我剪好看一点”，说明时长、画幅、保留内容和不能修改的部分，更容易得到可检查的结果。

可以这样说：

> 请把当前时间线剪成约 30 秒的竖屏短片，保留人物讲话，删掉开头等待和结尾空白。先说明怎么改，不要生成新素材。

> 把已导入的音乐铺到视频下面，降低音乐音量，让讲话更清楚。不要改变画面顺序。

> 请给这段口播生成中文字幕。如果需要配置转写服务，先告诉我缺什么。

建议一次只处理一类事情：先剪内容，再加字幕，最后做音乐和效果。

### 检查修改结果

出现提案时，先查看修改、预览效果，再应用或拒绝。是否需要确认取决于当前审批设置，不要默认所有操作都会等待批准。

应用后仍要播放检查。不满意可以继续提出要求，或撤销时间线修改。生成、上传、导出等任务不等同于可撤销的剪辑操作；撤销剪辑也不代表第三方调用费用会退回。

### 生成新素材

图片、视频、语音、音乐生成和在线素材搜索需要各自的服务配置。需要什么再配置什么，不必全部填写。

提示“缺少 Key”时，先看缺的是哪项功能的密钥，不要反复替换聊天模型密钥。

## 五、添加字幕

### 自动识别讲话

1. 把带有人声的视频或音频放到时间线上。
2. 在设置中选择本地转写模型或已配置的云端转写服务。
3. 使用本地模型时，先完成模型下载；下载完成后，识别可以在本机进行。
4. 打开文字稿面板，选择要处理的轨道，执行转写。
5. 核对人名、数字和专业词语，避免直接使用识别错误的文字。
6. 在字幕工作区创建或选择字幕轨道，使用对应转写内容，调整字号、颜色、位置和样式。
7. 确认字幕显示已开启，再播放检查是否与人声同步。

云端转写会把相应音频发送给服务商，敏感素材请先确认是否适合上传。

**文字稿中的“点词删除”可能会同时剪掉对应音频，不是单纯改错别字。** 修改文字时，请确认使用的是文字修正或字幕编辑操作。

### 手动输入字幕

只想加几句说明时，可以用手动字幕，不需要 AI。

在字幕工作区创建字幕轨道，进入“手动字幕”，新建字幕车道，再输入文字、设置出现时间和持续时长。

字幕尽量简短，不要遮住人物脸部或重要画面。需要单独交付字幕时，可以在导出窗口选择字幕并导出 SRT 文件。

## 六、导出成片

| 你想得到什么 | 选择什么 |
| --- | --- |
| 可以直接播放或发送的视频 | MP4 (H.264) |
| 只有声音的文件 | 音频导出 |
| 单独的字幕文件 | 字幕导出，选择 SRT |
| 交给其他剪辑软件继续处理 | 按对方要求使用 FCPXML 等交换格式，并确认素材可用 |
| 在 OpenChatCut 中继续修改 | 回到工程首页，导出 .ccproj 工程 |

初次导出可以先选择 1080p、“均衡”画质策略和自动码率。帧率尽量与主要素材一致，没有特殊要求时可先用 30 fps。

分辨率越高，通常越耗时、文件越大。把低清素材导出成 4K，不会自动补出原本没有的细节。

导出期间保持软件和本地服务运行。多个任务可能排队，不一定是卡住了。完成后可以在“导出历史”查看记录。

发送前检查：开头和结尾是否黑屏、人声是否清楚、字幕是否完整、横竖屏是否正确。

## 七、保存和备份

### 日常保存

项目具备本地持久化和自动版本保存机制。重要修改前，可以打开版本历史，点击“保存当前版本”，命名为“加字幕前”等，方便之后查找。

自动保存不是独立备份，不要在保存或导出过程中强行关闭服务。

### 备份工程或换电脑

在工程首页找到对应工程，通过导出按钮生成 .ccproj 文件。当前工程导出格式会打包素材，适合备份或换电脑后导入。

导出前确认素材可访问。重要工程建议再试着导入一次，确认素材和时间线完整。备份验证完成前，不要随意移动或删除仍被工程引用的原文件。

**MP4 是成片，.ccproj 是可继续修改的工程，建议重要作品两种都保留。**

### 数据位置

默认开发启动按 Git 工作区隔离数据，Windows 下位于：

```text
%USERPROFILE%\.openchatcut\dev-profiles\
```

启动日志会显示当前配置的具体目录。普通运行模式的工程库默认位于用户目录的 .openchatcut 下，素材目录还可能在设置中单独指定。

以当前启动日志和设置为准，不要随意删除这些目录，也不要把浏览器缓存当成唯一备份。

## 八、常见问题

| 问题 | 先检查什么 |
| --- | --- |
| 找不到 node 或 npm | 安装 Node.js 24.x 后重新打开终端 |
| PowerShell 禁止运行 npm.ps1 | 可改用 npm.cmd install、npm.cmd run dev，无需直接放宽全局脚本策略 |
| 默认启动提示 Git 或仓库错误 | 检查 Git 是否可用、源码是否在 Git 仓库中；压缩包源码可参考共享模式说明 |
| 浏览器打不开页面 | 查看终端是否启动成功、服务是否仍在运行、地址是否一致 |
| AI 没有响应 | 检查模型、接口地址、密钥、网络和账号额度，查看具体错误提示 |
| 缺少图片、视频或语音配置 | 单独配置对应服务，聊天服务配置不能代替它们 |
| 无法转写 | 确认片段有人声、本地模型下载完整或云端服务配置正确 |
| 素材在列表里但成片没有 | 确认已加入时间线，轨道没有隐藏，当前播放位置在片段范围内 |
| 字幕看不到 | 检查字幕轨道是否有内容、显示是否开启、当前时间是否在字幕范围内 |
| 素材缺失 | 检查原文件是否移动、外接盘是否断开，在“我的素材”中尝试重新链接 |
| 导出慢或失败 | 检查任务排队、磁盘空间和素材可读性，尝试较低分辨率或较短内容定位问题 |
| 换启动方式后工程不见了 | 检查是否切换隔离模式、共享模式或工作区，回到原启动方式确认 |

排查问题时，保留错误原文，记录“做了什么操作、何时失败、用了什么素材”。分享截图或日志前，遮住密钥和私人信息。

## 九、最简单的上手顺序

**启动软件 → 新建工程 → 导入视频 → 拖入时间线 → 剪掉多余内容 → 调整声音 → 添加字幕 → 导出 MP4 → 备份工程。**

先跑通这一遍，再尝试 AI 剪辑、生成素材、转场和特效。更多配置说明见 README_ZH.md 和 .env.example。
