# livart 使用手册

这份手册面向第一次使用 livart 的用户，不需要编程基础。你可以把它理解成一张很大的工作桌：把图片放上去，用文字告诉 AI 想画什么、改哪里，再把满意的作品下载到电脑。

本文根据本项目当前界面和代码整理。如果管理员修改过部署配置，请同时留意站点公告。

> **先看这一条：及时下载作品。** 当前版本会在每周一北京时间（Asia/Shanghai）00:00 清理所有用户的全部项目和关联图片。自动保存不等于永久备份，请在清理前下载需要的图片。

## 1. 第一次使用

### 打开网站并登录

1. 在浏览器打开管理员提供的 livart 地址。
2. 已有账号就登录；没有账号就切换到注册，填写用户名和密码，显示名称可以不填。
3. 阅读数据清理公告。
4. 如果弹出“中转站配置”，按下面的说明填写。

自己用默认 Docker 配置部署时，通常在浏览器地址栏输入 `http://localhost:8080`。如果修改过端口，使用实际端口。

### 填好 AI 配置

“中转站”就是帮这个工具连接 AI 的服务。livart 账号和 AI 服务的 API Key 不是同一个东西。

| 字段 | 通俗解释 | 怎么填 |
| --- | --- | --- |
| 中转站 Base URL | AI 服务的接口基础地址 | 向服务提供方或管理员索取，例如 `https://example.com/v1/`，不要填网站登录页 |
| API Key | 调用 AI 的专用密钥 | 从服务提供方获取，不是 livart 登录密码 |
| 生图模型 | 负责画图和改图 | 当前界面可选 `gpt-image-2` |
| 对话模型 | 负责理解要求、整理描述和分析商品 | 当前界面可选 `gpt-5.4-mini` |

填写后点击“保存配置”。以后可以通过左上角“API 配置”图标修改。

- Base URL 只填基础地址，不要自己加 `images/generations`、`images/edits` 或 `responses`，系统会自动拼接。
- 服务提供方必须支持所选模型及对应接口，只支持普通聊天的服务不一定能用。
- 已保存密钥后，输入框提示“留空表示不修改”时，不必重复填写。
- 密钥会保存在站点后端，请只在信任的站点填写，不要发到聊天框、截图或公开文档里。
- 是否收费、如何计费，由你使用的 AI 服务提供方决定。批量提交前先确认额度。

### 五分钟完成第一张图

1. 点击顶部“新建项目”，输入名称，例如“保温杯宣传图”，再点“创建项目”。
2. 在右侧输入框写：

   > 生成一张白色保温杯的商品宣传图，杯子放在浅灰色桌面上，背景干净，柔和自然光，不要文字。

3. 画幅选 `1:1`，清晰度先选 `1K` 或 `2K`。
4. 点击提交，或按 `Ctrl + Enter`；Mac 使用 `Command + Enter`。
5. 等右侧出现结果、画布上的等待框变成图片。
6. 选中图片，再点击顶部“下载”。顶部下载会打包为 ZIP，解压即可查看图片。

## 2. 认识操作界面

| 位置 | 用来做什么 |
| --- | --- |
| 顶部 | 配置 AI、切换或新建项目、查看保存状态和清理倒计时、下载 |
| 中间大画布 | 摆放、选择、比较图片和文字 |
| 右侧对话区 | 输入生成或修改要求，查看进度和结果 |
| 底部工具栏 | 撤回、重做、移动、选择、上传、社媒导入、商品详情图、文字、排列、缩放 |
| 图片上方工具栏 | 选中图片后出现，用来裁剪、旋转、局部修改、擦除、去背景等 |
| 左下角画布工具 | 修改画布背景色、查找图片、打开小地图 |

不知道图标是什么意思时，把鼠标停在上面，通常会显示工具名称。

“缩放画布”只是看得更近或更远，不会让下载图片变清晰。清晰度要在生成前选择。

## 3. 用文字生成图片

### 怎么描述

按“画什么 + 放在哪里 + 什么风格 + 其他要求”来写即可。例如：

> 生成一张玻璃香水瓶的产品图，放在白色石台上，极简摄影风格，侧面柔光，保留瓶身完整，不要文字和水印。

需要图片中有文字时，把文字写清楚：

> 做一张咖啡店活动海报，标题必须是“周末咖啡时光”，画面包含一杯拿铁，绿色和白色为主，不要出现其他文字。

AI 生成的文字、数字和细节仍可能有误，发布前记得放大检查。

### 选择画幅和清晰度

| 选项 | 常见用途 |
| --- | --- |
| 自动 | 没有固定尺寸要求；编辑时通常沿用原图比例 |
| 1:1 | 方形商品图、头像素材 |
| 4:3 / 3:4 | 横向或竖向展示图 |
| 16:9 | 横版封面、演示配图 |
| 9:16 | 手机竖屏海报 |

`1K / 2K / 4K` 是清晰度档位，可以先用较低档位试方案。最终尺寸取决于上游服务。`4K` 不表示所有比例的长边都是 3840 像素，例如当前方形 4K 请求使用 `2880 × 2880`，请下载原图检查实际尺寸。

输入框里的 `Skill` 可以理解为“写图像要求时使用的指导规则”。当前提供 `GPT Image 2` 和 `Image Craft`，不是额外的生图模型。新手可以先保持默认。

### 等待生成

- 画布会出现等待框，右侧显示进度，不要因为暂时没出图就反复提交。
- 已提交到后端的图片任务通常可在刷新后继续跟踪；任务过期或服务重启等情况可能导致恢复失败。
- 失败时先看错误信息，再决定修改描述、检查配置或重试。

## 4. 上传图片，再让 AI 修改

### 上传和整图编辑

1. 点击底部“上传图片”，选择电脑里的图片；也可以把图片文件拖入画布。
2. 等上传完成，点击选中要改的图片。
3. 确认右侧输入框出现对应图片标签。
4. 输入要求并提交，例如：

   > 把背景换成浅灰色摄影棚，杯子的形状、颜色、标志和位置都保持不变。

也可以选中图片后按 `Tab`，或点击“快捷编辑”，输入要求后提交。

AI 编辑通常会在原图附近生成新图，方便对比。它不是逐像素锁定的修图工具，即使要求“其他不变”，也要检查主体、文字和边缘。

### 同时参考多张图片

在右侧输入框输入 `@`，从列表中选择画布图片。不要只手打图片名称，实际选中后会出现图片标签。

先引用两张图片，再说明：

> 把产品图中的杯子放进场景图的桌面上。以场景图为底图，保持背景不变，杯子的外观参考产品图。

说清楚“要改哪张”和“另一张提供什么参考”。找不到图片时，确认上传完成，再搜索图片名称。

## 5. 只改局部，或者删掉物体

### 局部重绘：把某个地方换掉

1. 选中图片，点击“编辑元素”。
2. 用画笔涂抹想改的区域，涂多了可用该工具中的橡皮修正。
3. 在右侧输入要求，例如“把涂抹区域的杯子改成蓝色，其他地方尽量保持不变”。
4. 点击“执行重绘”。
5. 检查新图和附近边缘。

涂抹范围也叫“蒙版”，意思是告诉 AI“主要修改这里”，不是直接把颜色画进原图。

### 删除物体：去掉内容并补上背景

1. 选中图片，点击“橡皮工具”。
2. 圈住或涂抹要删除的物体。
3. 点击“执行擦除”，等待 AI 删除内容并补全背景。

也可以选中图片后，直接在右侧输入“删除桌面左侧的杯子，补全桌面”。有多个相似物体时，用涂抹指定目标更清楚。

“编辑元素”和“橡皮工具”的涂抹范围分别保存，切换工具后看到不同范围是正常的。

### 去背景：得到白底图

选中图片，点击“去背景”，不需要再写要求。

**当前功能生成纯白背景，不是透明背景。** 它会尽量保留主体，但仍需检查轮廓、文字等细节。

## 6. 其他图片工具

| 工具 | 怎么用 | 注意事项 |
| --- | --- | --- |
| 裁剪 | 点“裁剪”，调整范围，再点“保存为新图” | 生成新图，保留原图 |
| 旋转 | 点“向左转”或“向右转”，再点“确定” | 每次 90 度；取消可放弃预览，确认会修改该图的图片资源 |
| 多角度 | 拖动球面或调整方位角、俯仰角、缩放，再点“应用” | 是 AI 重新生成视角，不是真正的三维扫描，隐藏结构可能不准确 |
| 改颜色、增强、放大 | 选中图片后使用对应入口，按面板提示操作 | 属于 AI 编辑，可能改变细节 |

“分层”入口在当前代码中默认隐藏，不要把它当作必须能找到的常规功能。

## 7. 制作商品详情图

1. 将清楚的产品照片上传到画布。
2. 点击底部“商品详情图”；没有可用产品图时，按钮可能无法点击。
3. 同一个商品的不同角度用“单品模式”，同系列的不同产品使用系列模式。
4. 选择图片。单品模式下，第一张是主图，其余是细节、侧面、包装等参考。
5. 在右侧对话中描述产品，例如：

   > 这是一款白色不锈钢保温杯，容量 500 毫升，适合办公室和通勤。希望制作 3 张简洁风格的详情图，突出便携、杯盖结构和日常场景。不要编造保温时长和认证信息。

6. 查看系统整理的信息，区分已确认信息和待确认建议，补充或纠正不准确的内容。
7. 检查数量和其他选项，点击“确认并生成详情图”。
8. 等各张图完成，检查产品外观、文字、规格和卖点。

只填写真实产品信息。AI 的分析和建议不等于产品事实，不要直接作为参数或效果承诺发布。

## 8. 导入社交媒体图片

1. 点击底部“社媒图片”。
2. 粘贴帖子链接，等待解析。
3. 勾选需要的图片并导入。
4. 导入后可在画布查看，也能通过 `@` 引用。

当前提供抖音、小红书、微博、哔哩哔哩和知乎链接的导入入口，实际能否解析取决于帖子和外部解析服务。

提示服务未配置时，需要管理员在服务端设置，不能用个人生图 API Key 替代。也可以先将有权使用的图片保存到电脑，再手动上传。

## 9. 整理画布和添加文字

- **移动图片：** 切换到选择工具，拖动图片。
- **移动工作区：** 切换到移动画布工具，或按住空格拖动。
- **多选：** 框选，或按住 `Shift` 逐个点击。
- **自动排整齐：** 点击底部“排列”。
- **找不到图片：** 打开左下角文件列表搜索，或用小地图定位，也可以尝试“重置视图”。
- **添加文字：** 点文字工具，再点画布位置输入；选中文字后可调整字体、字号、颜色和样式。
- **操作错了：** 用“撤回”；恢复刚撤回的操作用“重做”。

画布文字是独立元素。放在图片上方，不等于已经写进图片。当前图片下载不会自动把画布文字、背景色和排版合成一张海报。

## 10. 保存、下载与分享

### 自动保存不是永久备份

画布内容和对话会自动保存到服务器，并按账号区分。可以通过顶部“切换项目画布”继续已有项目。

关闭页面前留意保存状态，仍在保存或提示失败时先等待或排查连接。**即使显示已保存，仍然受每周一北京时间 00:00 的清理规则影响。**

### 下载范围怎么选

直接点顶部“下载”：选中了图片，就下载选中图片；没有选中图片，就下载项目交付包。顶部导出使用 ZIP 压缩包。

| 下拉菜单选项 | 实际包含什么 |
| --- | --- |
| 选中图 | 当前选中且已完成的图片 |
| 最终图 | 没有后续派生版本的图片，不代表 AI 自动选出的最佳作品 |
| 全部派生图 | 从其他图片编辑、重绘、裁剪等得到的新版本 |
| 项目交付包 | 当前项目中所有已完成、可下载的图片 |

下载单张原图时，也可以使用图片工具栏或大图预览中的下载按钮。下载后检查图片是否齐全、尺寸是否符合要求、文字和细节有没有错误。

**项目交付包不是完整项目备份。** 当前导出的是图片，不包含可恢复的完整画布布局、独立文字元素和聊天记录，不能据此保证一键还原项目。

### 分享图片

分享入口支持复制分享文案，并提供微信、朋友圈、微博相关入口。电脑端微信分享可显示二维码，手机端可能调用系统分享面板，仍需你按提示完成分享。

分享依赖站点和图片链接可访问，`localhost` 地址不能直接给其他人的手机使用。服务器清理图片后，旧链接也可能失效。重要交付请使用下载好的文件。

## 12. 常见问题

### 保存了配置，为什么不能生图？

保存不代表接口一定可用。检查地址、密钥、额度，以及服务是否支持所选生图模型和对话接口。右侧理解要求也要用到对话模型，只能生图但不支持对话的接口可能无法完成流程。

### 一直等待，要不要重复提交？

先不要。查看右侧进度和错误提示，避免重复任务。刷新后仍无法恢复时，把错误文字和发生时间发给管理员，不要附 API Key。

### 修改了错误的图片怎么办？

检查输入框的图片标签，移除不需要的引用，再选中正确图片。多图编辑时明确哪张是底图、哪张只是参考。

### 结果和描述不一致怎么办？

一次尽量只改一个重点，说清哪些要改、哪些不改；精确位置用涂抹指定。AI 不保证完全一致，重要细节要人工检查。

### 为什么去背景后不透明？

当前“去背景”生成纯白底，不是透明抠图。

### 为什么画布里看起来模糊？

画布会使用较小的预览图加快显示。先下载原图检查；原图也不清晰时，再检查生成档位和上游服务实际返回的尺寸。

### 为什么提示没有可下载图片？

只有已完成且有图片内容的结果才能下载。等待中的任务、失败图片框和独立文字元素不属于可下载图片。

### 为什么以前的项目不见了？

检查是否登录同一账号、是否选对项目，再确认是否已经过每周一零点清理。清理后不能靠刷新找回，重要作品应提前下载。

## 13. 附录：自己在电脑上启动

管理员已经提供网站地址时，可以跳过本节。以下以 Windows PowerShell 和项目自带 Docker Compose 文件为例。

1. 安装并启动 Docker Desktop，等待它准备就绪。
2. 在包含 `docker-compose.yml` 的项目根目录打开 PowerShell。
3. 如果没有 `.env`，从模板创建；已有文件不要覆盖：

   ```powershell
   if (-not (Test-Path -LiteralPath .env)) {
       Copy-Item -LiteralPath .env.example -Destination .env
   }
   ```

4. 检查 `.env`。对外提供服务前，更换数据库、消息服务、文件存储的默认密码和 `JWT_SECRET`，并请管理员检查访问控制。
5. 执行：

   ```powershell
   docker compose up -d --build
   ```

6. 首次构建需要下载依赖。完成后在浏览器输入 `http://localhost:8080`；配置了其他 `LIVART_PORT` 时，使用对应端口。

| 想做什么 | 命令 |
| --- | --- |
| 查看状态 | `docker compose ps` |
| 查看应用最近日志 | `docker compose logs --tail 100 livart` |
| 暂时停止 | `docker compose stop` |
| 启动已停止的服务 | `docker compose start` |
| 重启应用 | `docker compose restart livart` |

修改 `.env` 后需执行 `docker compose up -d` 应用新配置，仅 `restart` 不会重新加载容器环境变量。

不要随意删除 Docker 数据卷，也不要执行 `docker compose down -v`，这可能删除数据库和图片存储。自己部署同样包含每周清理逻辑，不会因为运行在本机就自动永久保存。

已有数据库、消息服务和文件存储的部署者，可参考项目 README 中的“Docker 复用模式”；普通使用者不必处理这些组件。
